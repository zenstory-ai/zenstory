# 常见问题排查

遇到异常时，第一步永远是**先保住编辑器里尚未保存的文字**。在确认本地稿件已经妥善复制或另存之前，不要急着刷新页面、清空浏览器站点数据或反复重发生成请求。

## 内容未保存或提示版本冲突

1. 先把编辑器里重要的新写段落复制粘贴到本地记事本或独立文档中。
2. 检查网络连接与编辑器底部状态栏提示，按 `Ctrl/Cmd + S` 或点击**保存**尝试手动提交。
3. 若弹出同时编辑冲突对比，先对照左右分栏确认服务端新内容与本地改动，逐处选择保留项后再点击**完成审阅**。
4. 若重新打开文件时顶部提示检测到未保存草稿，先核对云端现稿与草稿差异，再选择**采用草稿**或**丢弃草稿**。

如果浏览器提示本地存储不可用（例如处于受限隐私窗口或存储空间已满），请立即手动把全文复制到本地保存。确认稿件稳妥留存后，再尝试重新打开页面。详见[编辑器使用](../user-guide/editor.md)。

## AI 响应缓慢、连接中断或中途停止

先看消息列表是否仍在推进思考进度、工具卡片或正文流式写入。长章节起草与多文件核对耗时较长，没有“超过 30 秒就该刷新页面”的固定标准。

如果生成中途断开或已主动停止，先点击消息中的文件卡片（或在左侧打开目标章节）确认实际写到了哪一句，再发一条指明起止范围的续写指令，让 AI 只补后面的缺口，避免把整章从头重复追加一遍。若界面明确提示今日消息额度已满、权限受限或服务暂不可用，请按对应提示处理，详见[错误信息说明](error-messages.md)。

## 无法登录或收不到邮箱验证码

- 核对登录邮箱（或用户名）拼写，并留意密码大小写与全半角字符。
- 未收到验证码时，先翻看邮箱的「垃圾箱」或「广告邮件」文件夹，确认邮箱地址无误并等满 60 秒倒计时后再点**重新发送验证码**。
- 忘记密码可在登录页通过邮箱验证码在线重设；此前用 Google 登录且尚未单独设置密码的账号，同样可以通过忘记密码流程补设密码。
- 若使用 Google 登录时提示授权失败，请记下页面提示后返回登录页重新发起一次；若持续报错请联系支持团队。

退出或重新登录前，请先保存当前打开的稿件。排查登录问题无需开启全部第三方 Cookie，也不要随意清空浏览器 `localStorage`，以免清掉本地暂存的未保存草稿。详见[账号注册与登录](../getting-started/installation.md)。

## 项目或文件列表显示异常

先确认当前登录的是不是平时写作的那个账号、左上角是否进对了项目，再点击页面上的**重试**按钮。若搜索不到某个文件或项目，先清空搜索关键词并将类型筛选切回**全部**；若新建失败，请核对名称长度、套餐数量上限与弹窗报错说明。

批量导入 `.txt` / `.md` 章节时如果只有部分文件成功，先在左侧文件树核对已生成的章节，再单独补传失败的文件即可。想调整章节名称或排序时，直接在编辑器顶部改标题保存即可，不必删掉原文件再重建。

## 参考小说拆解失败或某栏为空

在**素材库**卡片上查看具体报错说明与剩余额度，确认上传的是包含独立章节标题（如 `第一章`、`Chapter 1`）的 `.txt` 纯文本，且文件体积与总字数未超出当前套餐上限。如果任务已完成但某个分类标签页为空，请先查看详情页顶部的实际截取范围——免费试拆仅处理前 3 个完整章节（最多 15,000 字），部分题材在前三章尚未展开的设定分类自然会留空。

Pro 账号遇到临时服务错误时，直接在任务卡片上点击**重试**即可，避免反复重传同一本书。详见[素材库](../user-guide/materials.md)。

## 导出下载无响应或打开乱码

先确认当前项目下确实有已保存的正文（`draft`）或剧本（`script`）文件，并检查浏览器右上角的下载拦截提示。工作台导出的 `.txt` 默认采用标准 UTF-8 编码；如果用旧版记事本或本地阅读器打开出现乱码，请在软件中手动切换为 UTF-8 编码读取，转换格式前先保留原始下载件。

注意：大纲、角色设定与项目素材不会进入**导出整本正文（TXT）**。如需备份大纲或角色卡，请在编辑器中打开该文档后点击顶栏**更多功能 → 下载当前文件（TXT）**。详见[导出正文](../user-guide/export.md)。

## 页面编辑卡顿

先保存当前稿件并关闭无关的高占用浏览器标签页，再观察是不是只有打开某一份超长单文件时才会卡顿——把几万字正文按章节拆成独立文件，编辑和自动保存都会顺畅得多。若拆分后依然卡顿，请记录大致字数、浏览器版本与复现步骤反馈给我们，无需清空全部浏览记录。

## 联系支持

可通过界面右上角的**反馈**入口，或发送邮件至 [support@zenstory.ai](mailto:support@zenstory.ai)，附上报错原文、发生时间、所在页面路径、操作步骤和浏览器版本。发送前请遮挡私人书稿内容，切勿在邮件或截图中透露密码、验证码或 API 密钥。
