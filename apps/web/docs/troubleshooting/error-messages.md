# 错误提示与处理

错误提示说明本次操作的状态。先读完整提示，再决定保存、等待、重试或联系支持。

## 保存与恢复

| 提示含义 | 下一步 |
| --- | --- |
| 内容已更新，保存冲突 | 保留本地文字，比较并合并服务端新稿 |
| 内容已保存，但未新增历史版本 | 当前正文已保存；检查历史额度，另存重要节点 |
| 本地草稿无法保留 | 立即复制重要文字，不假定刷新后能恢复 |
| 版本不存在 | 重载历史列表，核对文件与选定记录 |
| 无法备份恢复前内容 | 本次恢复未执行；保留现稿，再处理错误 |

见[编辑器](../user-guide/editor.md)和[版本历史](../user-guide/version-history.md)。

## 账号与用量

| 提示含义 | 下一步 |
| --- | --- |
| 登录过期或凭证无效 | 保留未保存稿件，再重新登录 |
| 用户名或密码错误 | 核对账号；需要时从忘记密码获取验证码 |
| 邮箱未验证 | 用注册邮件中的验证码验证 |
| 验证码错误或过期 | 核对新验证码，等待倒计时后重发 |
| 邀请码无效、过期或用完 | 核对完整码，或向邀请人获取新码 |
| 今日 AI 消息用完 | 等北京时间次日 00:00 恢复，或查看 Pro |
| 项目或自定义技能名额已满 | 查看当前用量；移除确实不再需要的条目或升级 |

不要为了释放名额删除尚需保留的稿件。见[订阅权益](../user-guide/billing-benefits.md)。

## 文件、上传和导出

| 提示含义 | 下一步 |
| --- | --- |
| 文件或项目不存在 | 检查账号、项目和删除状态；没有通用回收站入口 |
| 无权限 | 使用拥有该内容的账号，或检查当前套餐 |
| 类型、大小或文字超限 | 按上传入口的格式与限制准备文本 |
| 未识别章节 | 保留明确章节标题，再选择上传文件 |
| 没有正文可导出 | 检查已保存的正文或剧本类型文件 |

素材试拆和完整拆解范围不同，见[素材库](../user-guide/materials.md)。

## AI、语音和服务错误

服务暂不可用、连接中断或内部错误时，先检查是否已有文件写入。续写从当前内容继续；不要自动重复原生成请求。

语音失败时检查麦克风权限与录音状态，也可改用文字输入。付款处理中时等待确认；已扣款但权益未到账，保留订单信息联系支持。

## 反馈问题

复制错误原文，附发生时间、页面路径、操作步骤和浏览器版本，发送到 [support@zenstory.ai](mailto:support@zenstory.ai)，或用应用内反馈。错误持续出现时保留这些信息，不需要反复重试来证明问题。
