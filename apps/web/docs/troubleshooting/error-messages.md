# 错误信息说明

遇到界面报错时，请先看清提示说明的具体原因，保护好手头未保存的稿件，再决定是合并保存、稍候重试，还是联系支持。

## 保存与版本恢复

| 常见提示含义 | 原因与处理办法 |
| --- | --- |
| 文件内容已在别处更新（保存冲突） | 先保留本地刚写的文字，在分栏审阅中对照云端新版本合并后再提交 |
| 正文已保存，但未新增历史版本 | 当前正文已安全存入云端，只是该文件的手动历史版本数已满（免费版 10 个/文件，Pro 100 个/文件）；重要节点可顺手导出 TXT 备份 |
| 浏览器本地草稿无法暂存 | 当前浏览器的本地存储受限或空间已满；请立即手动复制重要文字并确保云端保存成功，切勿直接刷新页面 |
| 目标历史版本不存在 | 点击刷新版本列表，确认打开的是对应文件且所选版本编号有效 |
| 恢复前未能完成当前正文备份 | 为防止冲掉你尚未进历史的现稿，系统已自动中止本次恢复，当前正文完好无损；请先手动保存或另存现稿后再试 |

详见[编辑器使用](../user-guide/editor.md)和[版本历史](../user-guide/version-history.md)。

## 账号、登录与套餐额度

| 常见提示含义 | 原因与处理办法 |
| --- | --- |
| 登录已过期或凭证无效 | 先把编辑器里未保存的段落复制到本地，再重新登录账号 |
| 邮箱/用户名或密码错误 | 核对账号拼写与密码大小写；忘记密码可在登录页通过邮箱验证码重设 |
| 邮箱尚未完成验证 | 按页面引导输入注册邮件中的 6 位数字验证码（过期可点重发） |
| 验证码错误或已过期 | 以最新一封验证邮件中的 6 位数字为准；重发需等待 60 秒倒计时结束 |
| 邀请码无效、过期或次数已满 | 检查邀请码是否粘贴完整，或联系邀请人换领有效邀请码 |
| 今日免费 AI 消息已用完 | 免费版每日 3 条消息（及共享免费网络额度）于北京时间次日 00:00 自动重置；急需继续生成可升级 Pro |
| 项目数或自定义技能数已满 | 前往**我的项目**或**技能管理**查看当前数量；移除确实不再需要的旧条目，或升级 Pro 解锁更高上限 |

切勿为了腾出项目名额而草率删除还需保留的旧书稿——删除项目前请先导出 TXT 备份。详见[订阅权益](../user-guide/billing-benefits.md)。

## 文件、上传与导出

| 常见提示含义 | 原因与处理办法 |
| --- | --- |
| 项目或文件不存在 | 核对是否登错了账号、切错了项目，或该文件已被删除（聊天删除可在对应聊天卡片点**恢复**） |
| 没有操作权限 | 确认使用的是该作品所属账号，或检查当前功能是否需要 Pro 权益 |
| 文件格式不支持、体积或字数超限 | 对照上传入口说明（`.txt` / `.md` / `.zip`），控制在规定的单文件体积与字数上限内 |
| 未识别到有效章节标题 | 上传参考小说需包含独立成行的章节标题（如 `第一章`、`Chapter 1`），补齐标题后再重新选择文件 |
| 当前没有可导出的正文 | 整本导出仅合并已保存的正文（`draft`）或剧本（`script`）文件；请确认项目内已有保存好的章节 |

参考小说的免费试拆与 Pro 月度完整拆解在截取范围和重试规则上有所不同，详见[素材库](../user-guide/materials.md)。

## AI 对话、语音与支付服务异常

提示模型服务暂不可用、流连接中断或请求超时时，请先打开目标文件查看是否已有部分段落写入并保存。若已有写入，直接从断点处发指令续写缺失部分即可，不要盲目把刚才的整章生成请求原样重发一遍。

语音输入报错时，请检查浏览器的麦克风授权与系统输入设备，或直接改用键盘输入。支付宝付款返回后若显示正在确认支付结果，请稍等片刻刷新页面；如确认已扣款但 Pro 尚未生效，请保留订单号联系支持，不要重复下单。

## 提交问题反馈

若报错反复出现，请复制错误提示原文，连同发生时间、页面地址、操作步骤和浏览器版本，通过右上角**反馈**入口提交或发送至 [support@zenstory.ai](mailto:support@zenstory.ai)，无需反复点击重试来复现错误。
