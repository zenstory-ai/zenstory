# AI 创作助手

右侧 AI 助手可以讨论故事方向、起草正文、核对设定一致性，也可以直接读取、创建和修改项目文件。每一轮对话写清要做什么、依据哪些文件，以及写到哪里停止，能让生成结果更符合预期。

## 提出一项明确任务

一条清晰的请求通常包含目标文件、已确认事实、允许改动的范围和停止点（单条消息最长支持 20,000 个字符）。例如：

```text
先读取《第1场》和《三场景提纲》。
把第2场写入当前正文文件，采用林禾的有限视角。
包还在窗口，林禾不知道报错原因。
写到沈敏说“包不是我的”时停止，不继续写结局。
```

若本轮只想讨论故事方案，可在结尾写明“只给方案，不修改文件”；若需要直接写入正文文件，请说明是覆盖替换还是在末尾追加，避免把同一场重复写进文件。

## 提供上下文

| 资料类型 | 提供方式与上限 |
| --- | --- |
| **当前文件** | 在编辑器中打开目标文件；发送消息时 AI 会根据焦点感知当前打开的已保存文件 |
| **人物、提纲和旧章节** | 在消息中点名要求先读取，或在编辑器中选中关键段落点击**引用**（`Ctrl/Cmd + Shift + Q`，单条消息最多 **5 段**） |
| **项目素材** | 在左侧**项目文件 → 素材**文件夹中点击素材右侧的**添加到对话**（单条消息最多附加 **5 项**素材） |
| **参考小说库条目** | 在项目左侧**素材库**标签中展开已拆解的参考小说分类，点击条目上的**添加到对话**（与项目素材共享单条消息 **5 项**上限） |
| **长期背景与写作规则** | 在对话顶部的**AI 记忆**中维护**写作约定**（或在对话中直接要求 AI“记住……”） |

发送前请先确认刚手写修改过的设定或正文已保存。每次对话的上下文受长度预算约束，附加参考资料时只保留与本轮任务直接相关的条目即可；如果项目内存在同名文件，可让 AI 先列出候选再指定目标。

## 使用技能和生成模式

- **挂载写作技能**：在输入框输入 `/` 打开技能菜单，或在项目左侧**技能**标签点击技能旁的 `+` 添加。单条消息最多主动选择 **3 个**技能；选择技能后仍需在输入框写清本轮的具体任务。你未手动选择时，AI 也会根据技能名称和描述按需调用已启用的技能。
- **切换生成模式**：输入框左下角可在两种模式间切换：
  - **快速**（默认）：写完后不自动执行审稿，响应更快，适合讨论构思、搭建设定和快速试写。
  - **高质量**：写完后会自动审阅并在需要时修订，耗时更长，适合重头戏与正式定稿章节。

## 查看文件操作卡片与中途干预

- **核对文件操作卡片**：当 AI 读取、创建或修改项目文件时，回复中会展示对应的操作卡片。点击文件卡片可在中间编辑器直接打开该文件核对内容；如果对本轮某次文件修改不满意，点击该卡片上的**撤销**即可退回修改前的版本。若回复中仅在聊天正文里给出了候选文字而未生成文件修改卡片，说明该段文字尚未写入项目文件。
- **生成中途补充要求或停止**：同一账号同时只运行一项生成任务。AI 正在生成时，你可以在输入框（提示为**补充你的要求**）输入补充说明并点击**补充要求**，界面会提示是否已接收并融入当前生成；若需立刻中止，点击右下角的**停止生成**。停止生成会结束后续输出，停止前已完成的文件写入仍会保留。

## 中断后继续

如果生成因网络波动或主动停止而中断，先打开目标文件并查看本轮操作卡片，确认实际写到了哪一句，再发送带明确范围的续写请求：

```text
先读当前《第2场》，列出已完成与尚缺的部分。
保留已写段落，只补缺口，不重新追加整场。
```

只有在本轮尚未向文件写入任何内容且页面底部出现重试提示时，才直接点击重试原任务；连接状态不明时不要反复发送同一条请求。

## 开启新对话与消息额度

点击右侧面板顶部的**新对话**可开启一段全新的对话会话，不会删除项目文件或**AI 记忆**。切换会话前，请先把已采纳的方案保存到对应设定或大纲文件中；进入新对话后，重新打开目标文件并说明本轮任务与依据。
