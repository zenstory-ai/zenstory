# 版本历史

历史可以查看旧稿、比较修改或恢复内容。先选择需要恢复的范围：一句话，还是一份文件。

## 文件历史

编辑器中的历史保留一个文件的版本，可以查看旧文、比较两版、恢复文件。历史按文件保留：恢复只影响当前文件，不恢复已删除的文件或目录结构。

短时间内连续手动保存的改动可能合并到同一历史版本，包括小幅修改。额度按手动版本计数，AI 和系统备份不占用这部分额度。额度用满后仍可合并已有版本；无法合并时，正文照常保存，但不新增版本。

## 查看和比较文件版本

1. 打开目标文件，进入文件历史。
2. 点击版本的查看入口阅读旧文。
3. 选中两个版本，点击“比较”，查看增加、删除和替换的段落。

手机端查看或比较时会进入内容面板，返回后可以继续选择版本。列表还有更多记录时，使用加载更多。

只想取回一句话，复制旧文中需要的部分，关闭历史，放回现稿并保存。这样可以保留后来采用的其他修改。

## 恢复整份文件

选定版本，点击恢复并确认。恢复会替换当前文件正文；执行前先处理未保存修改。

服务端在覆盖前会为尚未进入历史的当前正文保留备份，备份失败则取消恢复。恢复后检查正文和历史，确认得到预期版本。历史仍不代替你独立保留的重要原稿。

## 历史里找不到想要的文字

先确认账号、项目和文件是否正确，再检查是否还有未保存草稿，或内容只出现在聊天里。新保存不一定新增历史记录；不要为了“试恢复”删除文件。

需要独立副本，见[导出正文](export.md)；未保存或冲突处理，见[编辑器](editor.md)。
