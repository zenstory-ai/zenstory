# 版本历史

编辑器底部状态栏的**历史**用于查看当前文件的旧稿、对比两个版本的差异或将文件恢复到指定版本。操作前先明确你要找回的是一句话，还是整份文件。

## 单文件版本记录规则

- **按文件独立保留**：版本历史以单个文件为单位记录；恢复某个版本只会替换当前打开文件的正文，不会影响项目内其他文件，也无法恢复已被删除的文件或文件夹结构。
- **合并与额度规则**：保存的正文改动会进入历史，短时间内连续手动保存的修改（包含小幅字词改动）会自动合并到同一历史版本中。版本额度按手动版本计数（免费版每个文件保留 **10 个**，Pro 每个文件保留 **100 个**），AI 编辑与系统自动备份不占用手动版本额度。当手动版本额度用满后，若新的手动保存可以与最近一条手动版本合并，仍会正常合并更新；若无法合并，当前正文照常保存，只是不再新增历史版本记录。
- **版本来源与统计**：历史列表中的每条记录都会显示版本号、保存时间、来源标签（**创建**、**编辑**、**AI 编辑**、**审阅后保存**、**恢复**；最新一条还会标注**当前内容**），以及该版本的总字数/词数和增删行数。

## 查看和对比文件版本

1. 在编辑器中打开目标文件，点击底部状态栏的**历史**打开版本历史面板。
2. 点击任意版本行上的**查看内容**，即可阅读该版本的完整旧文与创建时间。
3. **对比两个版本**：在列表中直接点击版本记录可选中（再次点击取消选中，最多选中 **2 条**）；选中两条版本后，点击顶部出现的**对比**按钮，即可在右侧（手机端为内容面板）查看两版之间新增、删除与替换的段落差异。

手机端点击**查看内容**或**对比**后会切入内容面板，点击面板右上角关闭按钮（`×`，**关闭预览**）即可回到列表继续选择其他版本；列表底部显示**加载更多**时可点击翻阅更早的记录。

如果只想从旧稿中取回某几句话，直接在**查看内容**中选中并复制所需句子，关闭历史面板后粘贴回当前正文并保存即可，这样不会冲掉你后来写好的其他段落。

## 恢复整份文件

在目标历史版本上点击**恢复到此版本**，并在确认弹窗中点击**恢复**。恢复操作会用该版本的文字替换当前文件正文；如果编辑器里还有未保存改动，请先保存或另存所需文字再执行恢复。

服务端在执行覆盖前，会先为尚未进入历史的当前正文创建一条自动备份版本；若备份未能完成，恢复操作会自动取消以保护现稿。恢复完成后请核对编辑器正文与历史列表，确认已回到预期版本。版本历史是单文件内的回退工具，不能替代你定期导出的本地备份副本。

## 历史里找不到想要的文字

如果打开历史后没看到某段文字，请依次排查：是否登错了账号或进错了项目、是否打开了同名或相邻的其他文件、该段文字是否还留在编辑器的未保存草稿中，或者当时 AI 仅在右侧聊天回复里给出了候选段落而并未写入文件。切勿为了“测试恢复”去删除文件。

需要导出本地独立副本见[导出正文](export.md)，未保存草稿恢复与保存冲突处理见[编辑器使用](editor.md)。
