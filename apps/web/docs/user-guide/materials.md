# 素材库

在 ZenStory 中，参考资料分为两类入口：

- **账号级「素材库」（参考小说库）**：位于工作台顶部导航的**素材库**，用于上传整本或前几章 `.txt` 参考小说，由 AI 自动拆解为章节梗概、角色、世界观、金手指、故事线、情节点与剧情条目，供所有项目跨书查阅和引用。
- **项目内「素材」文件夹**：位于单个项目左侧**项目文件 → 素材**（详见[文件树与文件类型](file-tree.md)），用于存放当前项目的纯文本参考笔记（单文件最大 2MB、20 万字，不触发 AI 拆解，所有套餐均可免费上传）。

注意：如果你是要把**自己写的章节正文**导入项目继续创作，请使用工作台首页的**有现成的稿子？导入进来（txt / md）**或项目内**正文**文件夹旁的 `+`，不要传到参考小说库。

## 免费试拆与 Pro 额度

参考小说拆解属于 Pro 权益，同时为免费版账号提供 1 次免费试拆体验：

- **免费版（免费试拆前 3 章）**：每个账号享有 **1 次**终身免费试拆机会（在素材库页面点击**免费试拆前 3 章**）。上传 `.txt` 小说后，系统仅截取并拆解**前 3 个完整章节**（合计不超过 **15,000 个字符**）。免费试拆提交后即永久消耗该名额（无论任务成功、失败或删除均不退还，免费试拆不提供免费重试；同一网络每天限 1 个账号使用免费试拆）。试拆生成的条目会长期保留在账号中，可随时查看和在项目对话中引用。
- **Pro（每月 5 次完整拆解）**：Pro 包含每月 **5 次**参考小说拆解额度（北京时间每月 1 日 00:00 重置），支持上传单本不超过 **20MB**、总字数不超过 **30 万字符**的 `.txt` 小说。每次发起上传或对失败任务点击**重试**均计 1 次当月额度；若因平台服务异常导致任务失败，系统会自动退还该次额度。即使当月 5 次拆解已用完，之前已拆解完成的参考小说仍可正常阅读和引用。

## 准备并上传参考小说

1. 在工作台顶部导航打开**素材库**，点击右上角**上传小说**（免费版首次可用时点击**免费试拆前 3 章**）。
2. 选择本地有权使用的 `.txt` 文件（支持 UTF-8 与 GBK 编码；不支持 PDF、Word 或 EPUB）。文件中需包含可独立成行的章节标题（例如 `第一章`、`第一回` 或 `Chapter 1`）。
3. 核对书名与页面提示的章节截取范围，确认后提交任务。

## 查看拆解结果

提交后，卡片会显示拆解进度（可随时离开页面，后台会继续处理）。拆解完成后点击卡片进入详情页，顶部标签页提供以下维度的结构化结果：

- **素材概览**：全书核心设定、题材亮点与整体结构摘要。
- **章节**：各章梗概，并可展开阅读该章对应的**原文内容**。
- **角色 / 剧情 / 情节点 / 故事线 / 世界观 / 金手指**：按分类整理的人物档案、主支线脉络、关键转折点、力量体系与核心卖点。

不同题材的小说拆出的侧重点不同；某个分类为空不代表原文没有相关描写。建议用分类摘要快速定位章节，再展开章节原文核对具体写法。若任务失败，可在卡片上查看原因；Pro 账号在有剩余月度额度时可直接点击**重试**。

## 在项目中引用或导入

打开任意项目，在左侧栏切换到**素材库**标签，即可浏览账号下所有已拆解的参考小说：

- **添加到当轮对话**：展开分类并点击某条角色、世界观或剧情条目查看详情，点击**添加到对话**即可将其挂载到右侧 AI 输入框上方（单条消息最多附加 **5 个**素材）。接着在输入框说明你想借鉴或分析的问题：

```text
参考已附加片段，分析人物在哪个动作上改变了目标。
分别列出原文事实和你的解读，暂不续写我的故事。
```

- **导入到当前项目长期留存**：点击条目详情中的**添加到项目**（或点击面板右上角勾选图标进入批量选择，勾选多条后一键导入），系统会将所选条目写入当前项目**项目文件 → 素材**文件夹中，方便你在编辑器里直接修改批注。

深度拆解与借鉴方法见[素材深度分析](../advanced/material-analysis.md)。
