# 素材库

素材库把参考小说拆为章节梗概、人物、设定等条目，供阅读和写作时引用。上传参考小说与导入自己的正文是不同操作。

## 免费试拆和 Pro

素材库拆解是 Pro 权益。页面提供免费试拆时，免费账号可按入口说明试拆一本书的前若干章；可用次数和章节范围以页面提示为准。上传整本时，页面会说明实际保留和拆解的章节范围。已拆出的试用结果可以继续查看。

Pro 每月可拆解 5 次，每本最多 30 万字符。当前机会和额度以素材库、订阅权益页显示为准。平台出错时查看退还提示，不要反复重传同一本书。

## 准备并上传

1. 在工作台打开素材库，点击上传（Pro）；页面提供免费试拆时也可选择免费试拆。
2. 选择有权使用的 TXT，检查标题和章节范围。
3. 确认后提交，等待任务处理。

文件不超过 20MB，需要可识别的章节标题，例如“第一章”“第一回”或“Chapter 1”。Pro 检查全书 30 万字符上限；免费试拆检查入口说明内实际保留的章节。此入口不接收 PDF、Word 或 EPUB。

## 查看结果

上传成功后仍需等待拆解。打开素材详情，展开章节、人物或设定等分类，选择条目阅读。不同材料和任务可能得到不同类别；空分类不代表原文没有对应内容。

章节摘要帮助定位，原文帮助核对。遇到解释不清或遗漏，回到相关原文，再把自己的阅读判断记录为笔记。

任务失败时先看错误原因和额度状态。页面提供重试时按提示操作；免费试拆结果重试可能需要 Pro，重试也会产生新的任务。

## 在项目中引用

打开项目的素材标签，选择与当前任务有关的条目并附加到对话。也可选中原文片段引用。说明你希望学习或解决什么：

```text
参考已附加片段，分析人物在哪个动作上改变了目标。
分别列出原文事实和你的解读，暂不续写我的故事。
```

附加条目受上下文预算约束，不会把全库自动放进每次请求。方法示例见[素材深度分析](../advanced/material-analysis.md)。

自己的稿件应从项目正文上传入口导入，见[文件管理](file-tree.md)。
