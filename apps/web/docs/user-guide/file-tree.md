# 文件树与文件类型

项目左侧栏的**项目文件**标签（移动端底部**文件**标签）按预设文件夹组织整部作品的大纲、角色、世界观、正文与参考素材。你和 AI 助手创建或修改的所有文档都会实时同步在这里。

## 一、预设文件夹与文件类型

新建项目后，系统会按作品类型自动生成根目录文件夹（根文件夹不支持重命名或删除，数字角标表示其下文件数量）：

| 根文件夹 | 对应文件类型 | 用途与特殊行为 |
| --- | --- | --- |
| **大纲 / 构思 / 分集大纲**（Outlines / Concept / Episode Outlines） | `outline` | 存放总纲、分卷大纲、构思或分集大纲；点击 `+` 新建空白大纲文档 |
| **角色 / 人物**（Characters） | `character` | 存放主角、反派与配角设定卡；点击 `+` 新建空白角色文档 |
| **设定**（World Building） | `lore` | 存放力量体系、势力分布、地理与特殊规则（长篇小说与短剧剧本预设）；点击 `+` 新建空白设定文档 |
| **正文**（Drafts） / **剧本**（Scripts） | `draft` / `script` | 存放小说各章正文或短剧各集剧本；**正文**文件夹旁的 `+` 用于直接上传本地 `.txt` / `.md` 章节稿件，**剧本**文件夹旁的 `+` 用于新建空白剧本文档 |
| **素材**（Materials） | `snippet` | 存放上传到当前项目的参考文本片段或从参考小说库导入的条目；点击 `+` 上传本地 `.txt` / `.md` 素材文件 |

当一个全新项目里还没有任何文件时，各空文件夹会保持简洁，不重复展示空状态提示；一旦项目内有了任意文件，尚未放入内容的文件夹展开后会显示**文件夹为空**（**素材**文件夹显示**暂无素材，点击 + 上传文件**）。

## 二、新建文件与导入稿件

### 1. 新建大纲、角色、世界观或剧本

- **在文件树中新建**：将鼠标悬停在**大纲**、**角色**、**世界观**或**剧本**文件夹行上（触屏设备直接显示），点击右侧 `+`，在展开的输入框中填写文件名（最多 255 个字符），按 `Enter` 创建（按 `Esc` 或点击外部取消）。
- **在空编辑器中新建**：未选中文件时，可在中间编辑区点击**新章节**（短剧项目为**新剧本**）、**新大纲**，或展开**更多选项**点击**新角色**、**新设定**，系统会自动归入对应文件夹并在编辑器中打开。

### 2. 导入本地章节稿件到「正文」

如果你有现成的 `.txt` 或 `.md` 小说稿件，可通过以下任一入口批量导入到当前项目的**正文**文件夹：

- 点击左侧文件树中**正文**文件夹右侧的 `+`（手机端该 `+` 按钮常驻可见）；
- 未打开文件时，点击中间空编辑器底部的**导入章节稿件（txt / md）**。

**导入规格与分章规则**：
- 单次最多可选择 **20 个** `.txt` 或 `.md` 文件，每个文件不超过 **5MB** 且不超过 **50 万字**，支持 UTF-8 与 GBK 编码（`.md` 文件按纯文本读取）。
- 系统会自动识别行首的章节标题（如 `第X章/节/回`、`卷X`、`序章`、`楔子`、`番外`、`Chapter X`、`Prologue`、`Epilogue` 或 `1. 标题`）并按顺序拆分为多个章节文件；若文件中没有可识别的章节标题，则整份文件会以原文件名存为一个章节。
- 导入过程纯文本处理，**不调用 AI，也不消耗每日 AI 消息额度**。

### 3. 上传项目参考文件到「素材」

点击**素材**文件夹右侧的 `+`，可上传一个 `.txt` 或 `.md` 参考文件到当前项目：

- 单个文件不超过 **2MB** 且不超过 **20 万字**，支持 UTF-8 与 GBK 编码。
- 当上传文本超过 **2 万字**时，系统会优先按换行边界自动切分为每份不超过 2 万字的多个素材文件，方便在对话中按需附加。
- **附加到 AI 对话**：鼠标悬停在**素材**文件夹下的任意文件上，点击对话气泡加号图标（**添加到对话**），即可将该素材挂到右侧 AI 输入框上方（单条消息最多同时附加 **5 个**素材，再次点击对勾图标可**从对话移除**）。

## 三、打开、搜索与键盘导航

- **打开文件**：在文件树中点击任意文件即可在中间编辑器打开；在手机端，点击文件后会自动从**文件**视图切到**编辑**视图。重新进入项目时，系统会自动展开并恢复你上次打开的文件。
- **搜索项目文件（`Ctrl/Cmd + K`）**：点击文件树顶部的搜索框，或直接按 `Ctrl + K`（macOS 为 `⌘ + K`），输入关键词即可同时匹配当前项目内的**文件名**和**正文内容**。下拉结果会展示匹配片段，支持用 `↑` / `↓` 选择、按 `Enter` 打开、按 `Esc` 关闭。
- **文件树键盘导航**：当焦点位于文件树节点上时，可使用 `↑` / `↓` 在可见行之间移动，`→` 展开文件夹或进入第一个子节点，`←` 折叠文件夹或回到父文件夹，`Home` / `End` 跳至首尾行，按 `Enter` 或 `Space` 打开当前文件。

## 四、重命名与删除文件

- **重命名文件**：先在文件树中点击打开该文件，直接在中间编辑器顶部的**标题输入框**修改名称（最多 255 个字符，请勿把整段正文粘贴进标题框）。停止输入 3 秒自动保存或按 `Ctrl/Cmd + S` 保存后，左侧文件树会自动同步新名称并按章节序号重新排序。
- **删除文件**：将鼠标悬停在目标文件行上（触屏设备直接显示），点击右侧垃圾桶图标，在确认弹窗中点击**删除**。
- **被删文件的未保存草稿保护**：如果某个正在编辑的文件里还有尚未保存到云端的本地修改，而该文件被删除（例如在另一处或由操作移除），编辑器顶部会展开**文件《…》已被删除 — 未保存的草稿已为你保留**面板，你可以直接复制文本框中的草稿，或点击**下载草稿（.txt）**保存到本地。
