# 文件树与文件管理

文件树把正文、人物、提纲和参考笔记放在一个项目里。点击文件夹展开，点击文件在编辑器中打开。

## 新建文件

在文件夹旁点击新建，输入标题后按 Enter；Esc 取消。文件类型通常根据所在文件夹确定，例如“角色”创建角色文件，“正文”创建正文文件，“剧本”创建剧本文件。

编辑器的空白页也提供新建正文、大纲、角色、设定或剧本入口。创建前先选择用途，避免把写作备忘当作正文导出。

类型列表及填写示例见[文件类型参考](../reference/file-types.md)。

## 修改标题

打开文件，在编辑器顶部修改标题并保存。改标题不需要删除原文件，也不会把角色文件变成正文文件。

当前文件树没有拖拽移动或文件类型转换入口。需要调整归类时，在目标位置新建正确类型的文件，复制采用的内容并保存。新建副本有独立历史，确认采用前保留原文件。

## 导入已有文字

- 正文文件夹的上传入口支持 TXT 和 Markdown，按可识别的章节标题拆为正文文件。
- 素材文件夹的上传入口把参考文本加入项目，供对话附加使用。
- 工作台的素材库上传用于拆解参考小说，与把自己的稿件导入正文不同。

上传结束后检查文件树和错误提示。多文件导入可能部分成功，先看已经出现的章节，再补缺失内容。

## 搜索与引用

按 `Command/Ctrl + K` 打开当前项目的文件搜索，输入标题关键词。用上下方向键选结果、Enter 打开、Esc 关闭。

打开人物、提纲或正文后，可选中文字“添加到对话”。素材条目有自己的附加入口。重要资料先保存，再让 AI 读取。

## 删除

点击条目的删除图标，核对标题并确认。删除文件夹会影响其中的内容。目前没有独立的文件回收站入口，已删除的文件无法从历史恢复。

只需取回一段时，先查看[版本历史](version-history.md)，选择最小的恢复范围。
