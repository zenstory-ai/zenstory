# 技能系统

技能用于保存一套可复用的写作方法（如视角检查、人物塑造、开篇节奏或局部润色）。先选择适合当前任务的技能，再在对话中提供人物、原文与具体要求。

## 添加和使用技能

1. 在工作台顶部导航打开**技能管理**，默认进入**发现技能**标签页，可按名称搜索或按分类胶囊筛选官方与社区技能。
2. 阅读技能卡片上的名称和用途说明（社区技能可点击**展开指令**查看公开指令正文），点击**添加到我的技能**将其加入你的技能列表（按钮变为**已添加**）。
3. 回到项目工作区，在右侧 AI 输入框输入 `/` 从菜单中选择技能，或在项目左侧栏切换到**技能**标签并点击目标技能右侧的 `+`。
4. 在输入框中写清本轮要完成的任务与文件依据，再发送消息。

单条消息最多可主动挂载 **3 个**技能。未手动挂载时，AI 也会根据已启用技能的**技能名称**和**描述**按需调用合适的方法。

官方技能展示名称与用途说明，内部指令正文不公开，添加后即可在对话中调用；社区技能由创作者分享并经审核上架，在**发现技能**页点击**展开指令**可查看公开指令，添加后可在**我的技能**详情中查看其指令与附属资源文件。

## 管理我的技能

在**技能管理**页面切换到**我的技能**标签页，可按来源管理名下技能：

| 技能来源 | 可执行的操作 |
| --- | --- |
| **我创建的技能** | 点击开关启用或停用、**编辑**（名称、描述、标签、指令与资源）、**导出为 zip**、**分享到发现页**（或取消分享）、**删除** |
| **已添加的公共技能** | 点击开关启用或停用、查看详情（社区技能可看完整指令，官方技能仅展示用途说明）、从我的技能移除 |

已添加的官方技能不支持导出指令正文或资源文件；如果想在某种方法上增删规则，可新建一个自定义技能编写自己的指令。

## 创建自定义技能

在**技能管理**页面点击右上角**创建技能**（或在**我的技能**空状态点击创建），在弹窗中填写以下字段：

- **技能名称**（必填，最多 100 个字符）：简短说明这项方法的用途。
- **描述**（选填，最多 1,024 个字符）：告诉 AI 什么时候该调用这个技能，AI 会根据这段描述自动判断适用场景。
- **标签**（选填，多个标签用逗号分隔，最多 50 个、每个最多 100 个字符）：仅用于给技能分类和筛选，**不会影响 AI 何时调用该技能**。
- **指令内容**（必填，最多 50,000 个字符）：写明执行依据、步骤、输出格式与改动边界。

建议先从解决一项具体写作问题开始，例如：

```text
技能名称：有限视角检查
描述：检查场景中是否出现了当前视角人物尚未知晓的信息。
标签：视角, 审稿

指令内容：先读取作者指定的人物设定和引用段落。
列出问题原句、依据和最小替换建议。
区分作者已知与人物已知，缺少依据时提问。
先给建议，不修改文件，不新增人物背景。
```

保存后即可在项目对话中选择该技能并附上需要检查的段落。免费版最多可创建 **3 个**自定义技能，Pro 最多可创建 **20 个**；删除不再使用的自建技能可腾出名额。

## 导入、导出和分享

- **导入技能**：点击**技能管理**右上角的**导入**，可选择本地 `.md` 文件（含 YAML 头部的 `SKILL.md`，最大 256 KiB）或 `.zip` 技能包（最大 1 MiB）。导入后请先核对名称、描述、指令与资源文件。
- **导出技能**：在**我的技能**中打开自己创建的技能，点击**导出为 zip** 即可将 `SKILL.md` 及附属资源打包下载到本地备份。
- **分享到发现页**：对自己创建的技能点击**分享到发现页**会提交人工审核，审核通过后才会展示在公共**发现技能**列表中。提交分享前，请移除指令和资源中的私人稿件、未公开剧情与无权公开的文本。

关于指令编写结构、`references/` 与 `assets/` 资源文件管理及包格式规格，请参阅[自定义技能进阶](../advanced/skill-creation.md)。
