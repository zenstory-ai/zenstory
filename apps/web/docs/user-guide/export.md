# 导出正文

“导出正文”把当前项目已保存的正文和剧本合成一个 TXT，方便阅读、交稿或保留副本。需要提纲时，可选择“导出大纲和正文”。

## 下载稿件

1. 打开项目，保存要导出的修改。
2. 等 AI 写入和差异审阅结束，检查正文。
3. 从项目顶部选择“导出正文”或“导出大纲和正文”；手机端从菜单进入。
4. 打开下载的 TXT，核对开头、章节顺序和结尾。

浏览器通常使用项目名作为文件名。找不到下载时，检查浏览器下载记录及页面提示。

## 包含哪些内容

| 内容 | 是否导出 |
| --- | --- |
| 已保存、未删除的正文 `draft` 和剧本 `script` | 是 |
| 大纲 | 选择“导出大纲和正文”时包含 |
| 人物、设定和素材 | 否 |
| 聊天、AI 记忆和历史版本 | 否 |
| 编辑器中未保存的改动 | 否 |

导出按文件类型选择，不只看文件夹或标题。把角色文件改名为“最终正文”不会让它进入导出。

TXT 包含各文件标题和正文，文件之间用 `---` 分隔；选择带大纲的导出时，大纲排在正文前。章节、分集或场次编号会参与排序；使用一致的编号，并检查实际结果。

没有已保存大纲时，页面会说明本次只导出正文。下载后仍需打开 TXT 核对实际内容。

## 只交付部分章节

当前入口合并全部正文和剧本。需要送审前两章时，先下载完整稿件，再在本地另存送审副本并删去不需要的章节。保留完整下载稿，也不用临时删除项目章节。

## 离线修改后带回项目

下载的 TXT 不会自动与项目同步。回来后打开对应文件，比较现稿，再复制采用的修改并保存。整本合并 TXT 不应直接粘贴到一个章节文件中。

导出的 TXT 只包含所选入口支持的稿件和大纲。重要人物、设定和参考笔记需另外留存；需要 Word、PDF 或 EPUB 时，可在本地软件中排版转换。

下载失败、乱码或缺段，见[问题排查](../troubleshooting/common-issues.md)。
