# 导出正文

项目顶栏的**导出整本正文（TXT）**（短剧剧本项目中显示为**导出整部剧本（TXT）**）会将当前项目内所有已保存的正文或剧本按顺序合并下载为一个 UTF-8 `.txt` 文件，方便本地阅读、交稿或异地备份；若只需单独保存某一份大纲、角色设定或单章正文，可使用**下载当前文件（TXT）**。

## 下载整本正文或单个文件

### 1. 导出整本正文 / 整部剧本

1. 打开目标项目，确认编辑器底部的修改已显示为**刚刚保存**（或已保存状态），且 AI 写入和变更审阅均已完成。
2. 在桌面端点击项目顶栏右侧的**导出整本正文（TXT）**（短剧项目为**导出整部剧本（TXT）**）；在手机端点击右上角菜单选择同一入口。
3. 浏览器会以项目名称命名下载 `.txt` 文件；下载完成后请打开文件核对开头、章节顺序和结尾内容。

### 2. 下载当前打开的单个文件

如果你只想单独导出当前正在看的一章正文、一份大纲或一张角色设定卡：

1. 先在左侧**项目文件**中点击打开该文档，确认内容已保存。
2. 点击项目顶栏右侧的**更多功能**（`⋯` 图标，手机端在右上角菜单中），选择**下载当前文件（TXT）**。
3. 浏览器会以该文件的标题单独下载一个 `.txt` 文件。

## 整本导出包含哪些内容

| 内容类别 | 是否进入「导出整本正文 / 整部剧本」 | 如何单独留存 |
| --- | --- | --- |
| **已保存、未删除的正文（`draft`）与剧本（`script`）** | **是**（按章节/分集顺序合并，文件间以 `---` 分隔） | 也可打开单章后通过**更多功能 → 下载当前文件（TXT）**单独下载 |
| **大纲（`outline`）、角色（`character`）、设定（`lore`）、项目素材（`snippet`）** | **否** | 在编辑器中打开对应文件，点击**更多功能 → 下载当前文件（TXT）**单独保存 |
| **AI 对话记录、AI 记忆、文件历史版本** | **否** | 将已采纳的方案写入项目文件后再下载保存 |
| **编辑器中尚未保存的本地改动** | **否** | 先按 `Ctrl/Cmd + S` 或点击**保存**，确认保存成功后再导出 |

整本导出严格按文件的内部类型（`draft` / `script`）筛选，而不是只看文件标题。例如，把一份角色设定文件改名为“第一章”并不会让它进入整本正文导出。

合集 `.txt` 包含各章节的文件标题与正文，章节之间用 `---` 分隔，并结合文件树顺序与标题中的章节/分集编号（如“第一章”“第1集”）排列；日常命名章节时请保持编号格式一致，并在导出后打开文件核对顺序。

## 只交付部分章节与离线修改回填

- **只交付前几章**：**导出整本正文（TXT）**默认合并项目内全部章节。如需向编辑或平台送审前两章，可先下载完整合集副本并在本地另存一份送审稿删去后续章节，或者分别打开前两章通过**更多功能 → 下载当前文件（TXT）**下载，无需为此在项目里临时删除章节。
- **离线修改后带回项目**：下载到本地的 `.txt` 文件不会与云端项目自动同步。在本地软件中修改后，请回到工作台打开对应章节文件，对照现稿将采用的段落复制回编辑器并保存；切勿把包含多章的整本合集 `.txt` 直接整篇粘贴进单个章节文件中。
- **转换其他排版格式**：工作台直接导出标准 UTF-8 `.txt` 纯文本；如需 Word（`.docx`）、PDF 或 EPUB 格式，可在本地文字处理软件中打开该 `.txt` 文件后再另存转换。

遇到下载无响应、本地打开乱码或缺少段落时，请参阅[常见问题排查](../troubleshooting/common-issues.md)。
