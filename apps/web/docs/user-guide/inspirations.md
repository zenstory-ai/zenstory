# 灵感库（待开放）

灵感库目前待开放。

你可以直接在[工作台首页](https://app.zenstory.ai/dashboard)选择**长篇小说**、**短篇小说**或**短剧剧本**，输入一句话构想（或点击输入框下方的示例填入）并点击**开始创作**；若已有现成的 `.txt` 或 `.md` 稿件，也可点击创作框下方的**有现成的稿子？导入进来（txt / md）**直接建书。

还没有明确故事方向时，可以先在项目右侧 AI 对话中让 AI 给出几个不同走向的方案，选定一个后再保存到角色与大纲文件中。完整起步示例见[写第一篇短篇](../getting-started/first-project.md)。
