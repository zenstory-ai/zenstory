# 订阅权益

在工作台打开“订阅权益”，查看当前套餐、今日消息、项目数、自定义技能用量及 Pro 到期时间。未登录也可查看[定价页](https://app.zenstory.ai/pricing)。

## 免费版与 Pro

| 权益 | 免费版 | Pro |
| --- | --- | --- |
| AI 消息 | 每天 3 条 | 不限条数 |
| 项目 | 3 个 | 不限 |
| 自定义技能 | 3 个 | 20 个 |
| 素材拆解 | 不含 | 每月 5 次 |
| 正文导出 | TXT | TXT |

免费消息在北京时间每天 00:00 恢复。素材月度额度在每月 1 日恢复。自定义技能按当前拥有的自建技能计数，删除不再使用的技能可以腾出名额。

免费试拆入口开放时，没有素材库权益的账号可按页面提示试拆一本的前若干章；试拆不计入 Pro 月度额度，具体范围以入口说明为准。

今日消息用完后，先保存想法与稿件；额度恢复后可以继续，也可以开通 Pro。

## 对比套餐

定价页可切换月付与年付。“仅看差异”只隐藏双方相同的权益；如果当前展示的项目全都不同，开关前后内容相同是正常的。

价格、折扣和付款金额以页面与订单为准。

## 开通和续费

选择时长，按页面提示用支付宝付款。一次性付款，不会自动续费；月付权益为 30 天，年付为 365 天，续费会顺延到期日。

付款返回后检查套餐和到期时间。显示处理中时等待结果，避免重复付款；已扣款但权益未到账时，保留订单信息并联系支持。

有兑换码时，可以在订阅权益页兑换。
