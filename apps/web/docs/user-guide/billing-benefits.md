# 订阅与权益

本页介绍 zenstory 的套餐查看、配额理解、升级路径，以及积分/邀请码相关入口。

## 入口位置

- 仪表盘侧边栏：**订阅权益**
- 公开页面：**Pricing / 价格页**

## 你可以在这里做什么

## 1) 查看当前套餐

- 当前套餐名称
- 套餐状态（是否已开通）
- 到期/续费相关提示（如有）

## 2) 查看配额使用

常见会展示的维度包括：

- 可创作体量
- Agent 深度任务次数
- 可并行项目数
- 自定义技能数量（按你当前拥有的技能计算，删除技能即释放名额）
- 导出能力

不同套餐会对应不同上限。

## 3) 对比套餐差异

在套餐对比区可查看：

- 月付 / 年付切换
- 关键能力差异（可切换“仅看差异”）
- 适用人群建议（轻度创作 / 日更 / 团队协作）

## 4) 升级与兑换

在线支付启用时，主要通过支付宝开通或续费 Pro：

- 月付开通 30 天，年付开通 365 天；同套餐续费延长到期时间
- 金额以结账时的后端套餐配置为准
- 付款后由服务器确认到账并自动发放权益；返回页仅查询订单状态
- 返回页会在两分钟内自动确认到账；仍显示处理中时，服务器会主动向支付平台查询一次订单。已经付款时不要重复支付
- 兑换码仍可在「订阅权益」页使用，作为次要开通入口

管理后台「支付订单」可查看订单、支付状态和权益发放状态。未启用在线支付的部署仍可使用兑换码。

> 建议：先按你的创作目标（更新频率、项目数量、改稿强度）选套餐，再比较价格周期。

## 关于积分与邀请码

- 邀请成功可获得积分奖励
- 被邀请人通常可获得试用权益
- 积分相关活动和明细可在应用内对应页面查看

## 常见问题

### 为什么我看不到某些高级能力？

通常是当前套餐未包含该能力。请到「订阅权益」页查看能力对比与可升级方案。

### 导出能力受套餐影响吗？

会。当前版本导出以 `.txt` 为主，具体以你套餐中显示的能力为准。
