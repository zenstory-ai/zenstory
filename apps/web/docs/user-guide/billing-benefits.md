# 订阅权益

在工作台顶部导航打开**订阅权益**（或在项目顶栏点击**管理订阅**图标），即可查看当前套餐、今日 AI 消息、可用项目数、自定义技能、本月素材库拆解用量及 Pro 到期时间。未登录时也可访问公开[定价页](https://app.zenstory.ai/pricing)。

## 免费版与 Pro 权益对比

| 权益项 | 免费版 | Pro |
| --- | --- | --- |
| **每日 AI 消息** | 每天 **3 条** | **不限条数** |
| **可用项目数** | **3 个** | **不限** |
| **自定义技能数** | **3 个** | **20 个** |
| **参考小说拆解** | 不含月度额度（每个账号可**免费试拆前 3 章** 1 次） | 每月 **5 次**（单本最多 30 万字） |
| **单文件手动历史版本** | 每个文件 **10 个** | 每个文件 **100 个** |
| **导出与下载（TXT）** | 支持整本导出与单文件下载 | 支持整本导出与单文件下载 |

**额度计算与重置规则**：
- **每日 AI 消息**：免费版每日 3 条消息于**北京时间每天 00:00（UTC+8）**自动重置（同一网络环境下的免费账号共享每日免费网络额度）。系统判定本轮没有实质产出并退还时，界面会提示本轮不计入今日额度。当日免费消息用完后，可先保存手写草稿，等待次日 00:00 恢复或开通 Pro。
- **参考小说拆解**：Pro 每月 5 次拆解额度于**北京时间每月 1 日 00:00** 重置；免费版账号享有 1 次“免费试拆前 3 章”（最多 15,000 字）体验，提交即消耗，不计入 Pro 月度额度。
- **项目与自定义技能**：按当前拥有的可用项目和自建技能数量统计，删除不再需要的旧项目或自建技能即可腾出名额。

## 对比方案

在公开[定价页](https://app.zenstory.ai/pricing)或工作台**订阅权益**页面，可切换**月付**与**年付**查看对应方案。定价页顶部的**仅看差异**开关用于隐藏免费版与 Pro 相同的权益项；若当前展示的对比项本身全部存在差异，切换该开关前后显示内容保持一致属于正常现象。具体价格、折扣与实付金额以页面及订单结算页展示为准。

## 开通、续费与使用兑换码

- **在线开通或续费 Pro**：选择月付（30 天）或年付（365 天）方案，按页面提示通过支付宝完成一次性付款，**不会自动续费或自动扣款**。在 Pro 有效期内再次购买或兑换时长，新时长会在当前到期时间基础上顺延累加。付款返回后请核对套餐状态与到期时间；若页面显示正在确认支付结果，请稍候刷新，避免重复付款。如已扣款但权益未到账，请保留支付宝订单号并联系 [support@zenstory.ai](mailto:support@zenstory.ai)。
- **使用兑换码**：如持有 Pro 兑换码，请点击工作台或项目右上角齿轮图标打开**设置 → 订阅**，点击**兑换码**按钮输入兑换码并确认，兑换成功后即时生效。
