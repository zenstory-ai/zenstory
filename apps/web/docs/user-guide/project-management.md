# 项目管理

在 ZenStory 中，每一部小说、短篇故事或短剧剧本都以独立**项目**的形式组织，各自拥有独立的文件树、AI 记忆、对话记录与导出结果。

## 一、创建项目的三种方式

### 1. 在工作台首页选定类型开始

1. 在工作台首页创作框上方选择作品类型（**长篇小说**、**短篇小说**或**短剧剧本**）。在**我的项目**页面点击右上角**新建项目**也会回到工作台首页的这处创作框。
2. 在输入框写下故事构想（或点击下方示例直接填入），点击**开始创作**，工作台会打开作品并自动把构想发送给右侧 AI 助手；若留空直接点击**开始创作**，则会进入对应类型的空白作品工作区。新账号首次进入首页时，也可直接点击顶部卡片上的**打开作品**。

### 2. 在工作台首页直接导入现成稿件（`.txt` / `.md`）

如果手头已有写好的章节或旧稿，无需先建空项目再逐章粘贴：

1. 在工作台首页先选好目标作品类型（**长篇小说**、**短篇小说**或**短剧剧本**）。
2. 点击创作框正下方的**有现成的稿子？导入进来（txt / md）**，从本地选择一个 `.txt` 或 `.md` 文件（单个文件不超过 5MB、50 万字，支持 UTF-8 与 GBK 编码）。
3. 系统会以文件名创建对应类型的项目，自动识别正文中的章节标题（如“第一章”“第一回”“楔子”“序章”“番外”“Chapter 1”或“1. 标题”）切分为独立章节文件，并直接打开第一章。整个导入过程不调用 AI，也不消耗每日 AI 消息额度。

### 3. 在项目工作区左上角快速新建

在项目工作区写作时，点击左上角当前项目名称打开**项目切换器**，再点击底部**新建项目**，面板内会直接展开项目名称输入框（最多 100 个字符），输入名称确认即可创建并切入新项目。通过项目切换器快速新建的项目固定为**长篇小说**；若需创建**短篇小说**或**短剧剧本**，请点击左上角 Logo 返回工作台首页选择对应类型创建。

## 二、项目类型与预设目录

项目类型决定了作品的预设文件夹与 AI 助手的创作方式，创建后不支持中途更改：

| 项目类型 | 中文界面的预设文件夹 | 适用场景 |
| --- | --- | --- |
| **长篇小说** | 设定、角色、素材、大纲、正文 | 多卷多章网文连载、长篇故事 |
| **短篇小说** | 人物、构思、素材、正文 | 单篇或数章完结的短篇、中篇故事 |
| **短剧剧本** | 角色、设定、素材、分集大纲、剧本 | 分集短剧剧本，导出按钮对应显示为**导出整部剧本（TXT）** |

## 三、查找、筛选与切换项目

- **在「我的项目」筛选与搜索**：进入**我的项目**页面后，可通过顶部的类型胶囊（**全部 / 长篇小说 / 短篇小说 / 短剧剧本**）按体裁筛选，或在搜索框按项目名称、描述实时过滤。每张项目卡片都会标注项目类型、总字数与最近更新时间，点击卡片即可打开项目。
- **在项目内快速切换**：在编辑器左上角点击当前项目名称打开**项目切换器**，面板顶部始终提供搜索框，点击目标项目即可立刻切换。切换项目时，当前编辑器中尚未保存的改动会自动触发保存；若保存未完成，草稿也会按“账号 + 项目 + 文件”保存在当前浏览器本地。

## 四、重命名与删除项目

- **重命名项目（在项目切换器中操作）**：在项目工作区左上角点击项目名称打开**项目切换器**，将鼠标悬停在目标项目行上，点击编辑图标（**重命名**），输入新名称（最多 100 个字符）并按 `Enter` 或点击确认图标保存。重命名只更新项目标题，不影响内部文件、版本历史和对话。
- **删除项目**：可在工作台首页或**我的项目**页面将鼠标悬停在项目卡片上点击右上角删除图标，或在项目内左上角**项目切换器**中悬停目标项目行点击删除图标，并在确认弹窗中点击**删除**。删除后，该项目会从可用项目列表移除，目前没有回收站或恢复入口；如需留存稿件，请在删除前先点击项目顶部的**导出整本正文（TXT）**（或**导出整部剧本（TXT）**）保存本地备份。

## 五、项目数量上限

- **免费版**：最多可同时拥有 **3 个**可用项目。达到 3 个上限后，新建或导入项目时会提示数量已满；你可以删除不再需要的旧项目腾出名额，或升级至 Pro。
- **Pro**：项目数量**不限**。若 Pro 到期后回退为免费版，已创建的项目与内部文件仍会保留，可正常打开阅读、编辑和导出，只是在可用项目总数仍超过 3 个时无法继续新建项目。
