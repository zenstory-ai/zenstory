# 界面总览

登录 ZenStory 后，你会先后使用**工作台**（管理账号下的作品、参考小说、技能与订阅）与**项目工作区**（三栏写作环境）。

## 一、工作台顶栏与首页

### 1. 工作台顶部导航

- **左侧主导航**：包含**首页**、**我的项目**、**素材库**、**技能管理**、**订阅权益**。在手机端，点击左上角菜单图标可展开同一组导航。
- **右侧工具区**：显示今日免费 AI 消息额度胶囊（免费版可见，点击可前往订阅权益页）、**帮助**（打开文档中心）、**反馈**（提交问题描述并可附最多 3 张截图）、**设置**（齿轮图标）与个人头像菜单。

### 2. 工作台首页（`/dashboard`）

工作台首页按从上到下的顺序提供以下入口：

- **Pro 到期提醒横幅**：当 Pro 套餐距离到期不足 7 天时，顶部会提醒剩余天数或到期时间，可点击**续费 Pro** 延长有效期，或点击**暂时忽略**收起提醒。
- **创作启动框与第一部作品卡片**：先选择**长篇小说**、**短篇小说**或**短剧剧本**，输入一句话构想（或点击下方示例填入）并点击**开始创作**，工作台会打开作品并将构想发给右侧 AI 助手（留空直接点击则进入空白工作区）。新账号首次完成邮箱验证后，顶部还会显示**你的第一部作品已备好**卡片，可直接点击**打开作品**进入编辑器。
- **导入现成稿件入口**：点击创作框正下方的**有现成的稿子？导入进来（txt / md）**，即可上传本地 `.txt` 或 `.md` 稿件，系统会按文件名创建项目、按章节标题自动切分章节并打开第一章（不调用 AI，不消耗每日 AI 消息）。
- **最近项目**：展示最近编辑的作品卡片，点击卡片即可继续写作，悬停卡片可点击右上角删除图标移除作品；当项目总数超过 6 个时会出现搜索框，也可点击右上角**查看全部**进入**我的项目**列表。

## 二、项目工作区布局

打开任意项目后，桌面端采用顶部工具栏加左、中、右三栏布局：

### 1. 项目顶部工具栏

- **左侧**：点击 ZenStory 图标可**返回工作台**；点击右侧的项目名称下拉框可打开**项目切换器**，面板顶部始终提供搜索框，下方可点击切换项目、悬停项目行执行**重命名**或**删除**，或点击底部**新建项目**展开名称输入框快速创建长篇小说项目。
- **右侧（桌面端）**：依次提供今日 AI 消息额度胶囊（免费版）、**管理订阅**图标、**导出整本正文（TXT）**（短剧剧本显示**导出整部剧本（TXT）**）、**更多功能**菜单（打开文件时含**下载当前文件（TXT）**，以及**帮助文档**、**问题反馈**）、**设置**与用户菜单。在手机端，这些操作统一收纳在右上角菜单中。

### 2. 左侧栏：项目文件、技能与素材库

左侧栏顶部包含三个切换标签：

- **项目文件**：按树状目录管理当前作品的**大纲**、**角色**、**世界观**、**正文**（短剧为**剧本**）与**素材**文件夹，支持按 `Ctrl/Cmd + K` 搜索文件名或正文内容。
- **技能**：列出当前可用的内置技能与已启用技能；点击技能名称可查看详情，点击右侧 `+` 可将其挂载到下一条 AI 对话消息（单条消息最多挂载 3 个技能）。
- **素材库**：浏览账号下已完成拆解的参考小说，按角色、世界观、金手指、故事线、剧情等分类预览条目，并支持一键**添加到对话**或**添加到项目**（也可点击右上角勾选图标进入批量选择导入）。

### 3. 中间栏：编辑器与审阅视图

中间区域是正文与设定文档的编辑区：

- **未打开文件时**：展示**从一句话开始**引导页，提供**让 AI 帮你写开头**主按钮、**新章节**（或**新剧本**）与**新大纲**卡片、折叠的**更多选项**（**新角色**、**新设定**），以及**导入章节稿件（txt / md）**入口。
- **打开文件后**：顶部为可编辑的文档标题，中部为支持触控双指缩放（50%–250%）的纯文本编辑区，底部状态栏显示**字数**、**段落**、**历史**、**去AI味**、保存状态与**保存**按钮。当触发去AI味或并发修改冲突时，编辑区会切换为左右分栏的变更审阅视图。

### 4. 右侧栏：AI 助手

右侧面板用于与 AI 协作创作：

- **面板顶部**：提供**AI 记忆**（查看项目设定概览与维护跨会话生效的**写作约定**）和**新对话**按钮。
- **消息列表**：展示对话回复、可点击打开或撤销的文件修改卡片，以及本轮结束状态说明。
- **输入面板**：顶部可拖拽分隔条调整输入区高度，上方展示建议芯片及已挂载的引用、素材与技能标签；输入框支持 `/` 唤起技能菜单与语音输入；底部左侧切换**快速**与**高质量**生成模式，右侧为发送或**停止生成**按钮。

### 5. 移动端与平板竖屏视图

在窄屏设备上，项目工作区通过底部导航栏在**文件**、**编辑**、**AI** 三个视图间切换：在**文件**视图点击任意文档会自动切到**编辑**视图；未打开文件时在**编辑**视图点击**让 AI 帮你写开头**会直接切到 **AI** 视图并高亮起步卡片。

## 三、设置弹窗说明

在工作台或项目工作区点击右上角齿轮图标打开**设置**，常用标签页包括：

| 标签页 | 可执行的操作 |
| --- | --- |
| **个人资料** | 查看当前用户名与注册邮箱，或点击**退出登录** |
| **通用** | 切换界面语言（**简体中文 / English**）、开关当前浏览器的产品改进统计、切换**深色主题 / 浅色主题**，以及选择 6 种主题强调色（琥珀暖金、朱砂印泥、松烟青绿、靛青蓝墨、紫檀绛紫、赭石暖棕） |
| **订阅** | 查看当前套餐与有效期、点击**兑换码**输入兑换码、点击**开通 Pro** 或**续费 Pro**，以及查看**今日用量** |
| **API 密钥** | 创建、复制或吊销个人 API 密钥（支持读写或只读权限，并可设置有效天数），用于在 Claude Code、Codex、OpenClaw 等本地工具中接入 ZenStory CLI 与写作技能 |
