# 界面总览

工作台首页用于开始和管理作品；打开项目后，在项目页整理文件、写作和与 AI 对话。

## 工作台首页

首页可以输入想法、选择作品类型、创建项目，并打开最近项目。侧边导航提供“我的项目”“素材库”“技能”“订阅权益”等入口。手机端点击菜单展开导航。

- 我的项目：搜索和筛选作品，打开或删除项目。
- 素材库：上传参考文本，查看拆解结果。
- 技能：添加官方或社区技能，管理自己的写作方法。
- 订阅权益：查看套餐、用量和到期时间。

灵感库待开放；首页输入自己的想法不受影响。

## 项目页的三个区域

| 区域 | 常用操作 |
| --- | --- |
| 文件区 | 打开、新建、搜索文件；切换技能和素材标签 |
| 编辑器 | 手写、修改标题、引用选区、保存、查看文件历史 |
| AI 对话 | 提出任务，选择技能和参考资料，查看回复及文件操作结果 |

宽屏下三个区域并排显示，可拖动分隔条调整宽度。手机端使用底部“文件”“编辑”“AI”切换，切换面板会保留当前编辑和对话状态。

## 项目顶部

点击项目名称可以切换、创建或重命名项目。顶部提供导出正文、项目历史、设置和用户菜单；手机端从菜单中打开这些入口。

文件历史位于编辑器中，项目历史位于项目顶部。两者的恢复范围不同，见[版本历史](version-history.md)。

## 设置和输入

设置支持亮色、暗色、跟随系统、中英文界面及主题色。编辑器是纯文本写作区；文本选区工具可以引用内容或“去AI味”。

AI 输入框可以调整高度。语音入口可用时，先允许麦克风，再录音转文字，检查识别结果后发送。

常用快捷键是 `Command/Ctrl + K` 搜索文件、`Command/Ctrl + S` 保存。完整列表见[快捷键参考](../reference/keyboard-shortcuts.md)。
