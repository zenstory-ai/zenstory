# 写第一篇短篇

从工作台首页出发，完成一部作品的立项、大纲与角色设定、第一章起稿以及局部润色导出。

## 一、创建或打开第一部作品

在工作台首页，根据手头准备情况选择起步方式：

- **选择类型并开始创作**：在创作框上方选择**长篇小说**（预设**设定**、**角色**、**素材**、**大纲**、**正文**文件夹）、**短篇小说**（预设**人物**、**构思**、**素材**、**正文**文件夹）或**短剧剧本**（预设**角色**、**设定**、**素材**、**分集大纲**、**剧本**文件夹）。在输入框写下故事构想（例如：“现代都市悬疑，失忆法医在旧案卷宗里发现自己的签名”），点击**开始创作**即可打开作品并将构想自动发送给右侧 AI 助手；若留空直接点击**开始创作**，则会进入空白作品工作区。新账号首次进入首页时，也可直接点击顶部卡片上的**打开作品**。
- **导入现成稿件（`.txt` / `.md`）**：如果手头已有写好的章节或旧稿，先选好作品类型，再点击创作框下方的**有现成的稿子？导入进来（txt / md）**。系统会按文件名创建项目、识别“第一章”“Chapter 1”等标题自动切分章节并打开第一章，全过程不调用 AI、不消耗每日 AI 消息。

## 二、搭建大纲与角色设定

进入空白作品后，右侧 AI 助手会展示起步卡片。你可以先搭框架，也可以直接写正文：

1. **生成大纲与主角设定**：点击右侧起步卡片，或在输入框发送构想，让 AI 先生成故事大纲、核心冲突与主角档案。
2. **查看与微调设定文档**：AI 写入文件后，对话消息中会展示对应的文件卡片（标注新增或修改字数）。点击文件卡片即可在中间编辑器打开该文档，直接在编辑器中修改名字、动机或世界规则；停止输入约 3 秒后编辑器自动保存（也可按 `Ctrl/Cmd + S` 手动保存）。
3. **衔接写第一章**：当项目里已有大纲、角色或世界观设定，但还没有任何正文时，AI 对话底部会出现**写第 1 章**引导卡片，点击即可让 AI 基于刚确认的设定起草第一章（也可点击**先不用**收起卡片）。

## 三、起草第一章正文

1. **选择生成模式**：在 AI 输入框左下角可切换生成模式——**快速**模式写完不自动审稿、速度更快（默认）；**高质量**模式写完会自动审阅并在需要时修订，耗时更长。
2. **发送写作指令**：说明第一章的开篇场景、视角和字数目标（例如：“按大纲写第一章，从暴雨夜解剖室停电写起，使用主角有限视角，2500 字左右”）。
3. **生成中途补充要求**：AI 正在生成时，如果发现方向需要微调，可直接在输入框填写补充说明并点击**补充要求**，无需先停止再重发；若需立刻中止，点击右下角**停止生成**即可。

## 四、局部润色、版本回溯与导出

1. **选中段落引用改写**：在编辑器中划选需要调整的句子或段落，点击浮动工具栏的**引用**（或按 `Ctrl/Cmd + Shift + Q`），该片段会挂到右侧输入框上方，再输入具体改法（如“把这段对话改得更针锋相对”）。
2. **一键去AI味**：如果某段文字套话偏多，划选该段落（单次最多 6,000 字）后点击编辑器底部状态栏的**去AI味**（或按 `Ctrl/Cmd + Shift + R`）。在左右分栏对比审阅中逐处点击 `✓` 接受或 `✗` 拒绝改动，确认后点击顶部**完成审阅**写回正文。
3. **查看与恢复历史版本**：保存的正文改动与 AI 写入都会进入版本历史，短时间内连续保存可能合并为同一版本。点击编辑器底部状态栏的**历史**，即可查看各版本的创建时间、来源标签、总字数与增删行数，点击选中任意两个版本后点**对比**查看差异，或点击**恢复到此版本**回退内容。
4. **导出 TXT 备份**：点击顶部栏的**导出整本正文（TXT）**（短剧项目为**导出整部剧本（TXT）**）下载整部作品合集，或通过顶部**更多功能 → 下载当前文件（TXT）**单独保存当前文档。
