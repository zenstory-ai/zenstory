# 网页写作快速入门

创建一个项目，写下第一条请求，再把采用的文字保存为正文。你可以全程手写，也可以随时请 AI 帮忙。

## 创建项目

1. [登录工作台](https://app.zenstory.ai/login)，打开[工作台首页](https://app.zenstory.ai/dashboard)。
2. 选择长篇小说、短篇小说或短剧剧本。
3. 写下想法，点击“开始创作”。进入项目后，这段想法会作为第一条消息发送给 AI。

想先自己整理文件，可以留空想法再创建项目。类型决定初始文件夹，不会限制你只能写某种题材。

## 找到文件、编辑器和 AI 对话

桌面端左侧是文件区，中间是编辑器，右侧是 AI 对话。手机端通过底部的“文件”“编辑”“AI”切换。点击文件后即可阅读或手写；需要帮助时，在对话里说明任务。

例如，先讨论故事方向：

```text
我想写一篇失物招领站的悬疑短篇。
一个人说对了包的外观，却说错了内袋物件。
请给三个不同的故事方向，每个写清人物选择与结局。
先在对话中讨论，不创建或修改文件。
```

选好方向后，再要求把采用的提纲保存到指定文件。AI 可以操作项目文件；发送前说清这轮是讨论、写稿还是改稿。

## 写第一场

在“正文”文件夹中新建文件，打开它，并让 AI 先读取已确认的提纲与人物资料：

```text
根据已确认的提纲写第1场，使用值班员的有限视角。
写到认领人说错内袋物件时停止，不揭露原因。
将正文写入当前文件，不继续写第2场。
```

重要设定先保存。只改某一段时，选中文字并“添加到对话”，再说明要保留的事实和允许改动的范围。

## 保存和带走稿件

停止输入约三秒后会自动保存，也可点击“保存”或按 `Command/Ctrl + S`。离开前看保存状态，遇到冲突先比较两份文字。

项目顶部的“导出正文”下载 TXT，包含已保存的正文和剧本；需要提纲时选择“导出大纲和正文”。人物、素材、对话和历史版本需另行保留。
