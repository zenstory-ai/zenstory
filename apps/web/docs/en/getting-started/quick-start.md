# Web writing quick start

Create a project, send your first request, and save the text you choose as a draft. Write manually, ask the AI for help, or combine both.

## Create a project

1. [Sign in](https://app.zenstory.ai/login) and open the [workbench home](https://app.zenstory.ai/dashboard).
2. Choose Novel, Short Story, or Short Drama Script.
3. Enter an idea and choose **Start Writing**. Your idea is sent as the first chat message when the project opens.

Leave the idea empty if you want to organize files first. The format creates starting folders; it does not restrict your genre.

## Find files, the editor, and chat

On desktop, files are on the left, the editor is in the middle, and AI chat is on the right. On a phone, switch between **Files**, **Edit**, and **AI** at the bottom. Open a file to read or write, and describe your task in chat when you need help.

Start by exploring a premise:

```text
I am writing a mystery set at a lost-property desk.
Someone describes a bag correctly but names the wrong item in its inner pocket.
Give three different story directions, each with a character choice and ending.
Discuss them in chat first; do not create or change files.
```

Choose a direction before asking the AI to save the approved outline in a named file. The AI can operate on project files, so identify whether this turn is discussion, drafting, or revision.

## Draft the first scene

Create a file in **Drafts**, open it, and ask the AI to read your approved outline and character notes first:

```text
Draft Scene 1 from the approved outline in the desk attendant's limited viewpoint.
Stop when the claimant names the wrong item. Do not reveal the reason.
Write into the current draft file; do not continue to Scene 2.
```

Save important notes before sending. For a local edit, select the passage, choose **Add to chat**, and specify the facts to retain and the permitted changes.

## Save and take your manuscript with you

Autosave runs after about three seconds without typing. Use **Save** or `Command/Ctrl + S` to submit sooner. Check save status before leaving; compare both copies if a conflict appears.

**Export manuscript** in the project header downloads saved draft and script files as TXT. Choose **Export outline and text** to include outlines. Keep separate copies of characters, materials, chat, and history when needed.
