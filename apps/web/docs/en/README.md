# ZenStory workbench documentation

From your first outline to final revision and export, write in the [workbench](https://app.zenstory.ai/dashboard) and look up instructions here, or press `Ctrl/Cmd + K` to search by keyword.

## Getting started

- [Quick Start](getting-started/quick-start.md): Open or create a work, find your way around the three panes, write your first passage, and export a backup
- [Account Registration and Login](getting-started/installation.md): Register and verify your email, pick what you write, reset passwords, and manage settings
- [First Story](getting-started/first-project.md): Set up an outline and character sheet, draft Chapter 1, polish passages, and export to TXT

- [Common Issues](troubleshooting/common-issues.md): Step-by-step fixes for sign-in and verification, save conflicts, paused AI runs, uploads, and novel breakdowns
- [Error Messages](troubleshooting/error-messages.md): What workbench error messages mean and what to do next

If you run into unsaved edits or an interrupted generation, secure your draft text first and then follow the troubleshooting steps, or contact [support@zenstory.ai](mailto:support@zenstory.ai). To read and write cloud projects from local AI coding tools such as Claude Code, Codex, or OpenClaw using the `zenstory` CLI, create an API key in **Settings → API Keys** and see the [ZenStory CLI and writing skill guides](https://zenstory.ai/guides/) on the organization site.
