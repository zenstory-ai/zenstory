# Frequently asked questions

New to ZenStory? Start with the [Interface overview](../user-guide/interface-overview.md) to get oriented.

## Account and plans

### What if I forget my password?

Click **Forgot password?** on the sign-in page, enter your registered email to receive a 6-digit verification code, and set a new password within 10 minutes. Accounts created with Google sign-in can also set a password this way. If you cannot receive the code, email [support@zenstory.ai](mailto:support@zenstory.ai). See [Registration and sign-in](../getting-started/installation.md).

### What is included on the Free plan?

Free accounts get **3 AI messages per day** (resetting at 00:00 Beijing time, UTC+8), **3 active projects**, **3 custom skills**, **10 manual history versions per file**, and full TXT export. Reference novel breakdowns are a Pro feature, though eligible Free accounts can run **1 one-time free trial** on the first 3 chapters (up to 15,000 characters) of a `.txt` novel. See [Plans and benefits](../user-guide/billing-benefits.md).

### I completed payment—why hasn't Pro activated yet?

Wait a moment after returning from checkout and refresh **Plans & Benefits** to check your plan status and expiration date. Do not submit a duplicate payment. If your payment went through and Pro still has not activated after a few minutes, keep your order details and email [support@zenstory.ai](mailto:support@zenstory.ai).

## Writing and files

### Does the editor save automatically?

Yes. The editor auto-saves to the cloud roughly 3 seconds after you pause typing, and you can press `Command/Ctrl + S` anytime to save immediately. Check the status indicator in the editor status bar to confirm **Saved**. Note that consecutive manual saves within a short window merge into one history entry. For offline draft caching and conflict handling, see [Using the editor](../user-guide/editor.md).

### Does the AI read every file in my project automatically?

No. To keep context focused and within length limits, the AI does not read every file in full on every turn. Open the chapter you are working on, name the specific outline or character files it should consult, and quote key passages directly when needed. See [Collaborating with the AI assistant](../user-guide/ai-assistant.md).

### Why did the AI write prose in chat without updating my chapter file?

When you ask for options or do not ask the AI to edit a file, it replies with candidate text in chat first. You can copy the lines you want into the editor, or tell the AI explicitly which file to update—and whether to replace a passage or append to the end—then check the file.

### Does clicking Stop undo changes the AI already wrote?

No. Clicking **Stop** halts the rest of the turn, while any file edits completed earlier in that turn stay in place. Open the file (or check the chat edit card, where you can click **Undo** if needed) to see where it stopped, then ask only for the remaining section.

### Can I rename a file or switch its file type?

To rename a file, edit the title bar at the top of the editor and let it save. File types (`draft`, `outline`, `character`, etc.) cannot be converted in place—create a new file in the target folder, copy your text over, confirm it saved, and remove the old file if you no longer need it. See [File tree and file management](../user-guide/file-tree.md).

### Is there a trash bin for deleted files or projects?

ZenStory does not have a standalone trash panel for manual deletions. However, if a file was deleted by the AI during chat, its deletion card in chat provides a one-click **Restore** button; and if a chapter was overwritten by an edit, you can roll back via **Undo** on the chat card or from **History** ([Version history](../user-guide/version-history.md)). Avoid deleting real work just to test recovery.

### Does whole-work export back up my entire project?

**Export whole work (TXT)** (or **Export whole script (TXT)**) merges and downloads saved `draft` and `script` files only. Outlines, character sheets, worldbuilding notes, materials, chat threads, AI Memory, and version history are not included in whole-work export—open important planning files and click **More Actions → Download current file (TXT)** to keep local copies separately. See [Export your manuscript](../user-guide/export.md).

### Can I write offline?

Cloud saving and AI chat require an internet connection. While the browser caches unsaved edits in a single open file temporarily, ZenStory is not a full offline editor. If you plan to write without internet access, export your manuscript first, work locally, and paste revised passages back once you are online.

## Skills and materials

### Why can't I view the prompt inside an official skill?

Official skills show their description and usage guide so you can attach them right away, while keeping internal prompt text hidden. Custom skills you create or import are fully editable, and community skills shared in **Discover** let you read their instructions before adding them. See [Using skills](../user-guide/skills.md).

### How reliable are AI novel breakdowns in the Materials Library?

Treat breakdowns as a fast index, not infallible fact. Automated extraction can miss nuances or misread ambiguous scenes—use the chapter synopses and category tabs to find relevant sections quickly, then expand **Original Text** to verify details before building on them. See [Material analysis](../advanced/material-analysis.md).

### Where is the Inspirations Library?

The **Inspirations** tab on the dashboard is still under development and marked **Coming soon**. In the meantime, type a premise directly into the home prompt box or brainstorm story hooks with the AI inside a project.

## Privacy and support

### Can other users see the novels or materials I upload?

No. Both your account's Materials Library and each project's `Materials` folder are private to your account. When you attach materials or send messages, the AI processes that text to fulfill your request—see the [Privacy Policy](https://zenstory.ai/privacy-policy) for full data handling details. Before publishing a custom skill to **Discover**, double-check that its instructions and resource files contain no private manuscript excerpts.

### How do I report a bug or get help?

Use the feedback entry inside the app or email [support@zenstory.ai](mailto:support@zenstory.ai) with the error message, steps to reproduce, approximate time, and browser version. Redact private manuscript text and never include passwords or verification codes in screenshots.
