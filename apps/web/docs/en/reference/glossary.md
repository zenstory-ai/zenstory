# Glossary

Quick definitions for common terms you will see across the ZenStory workbench and documentation.

## Projects and materials

| Term | Meaning |
| --- | --- |
| Project | A self-contained workspace holding one work's files, AI chat threads, and AI Memory |
| File tree | The folder-and-file sidebar on the left side of a project |
| Draft / Script | Manuscript file types (`draft` / `script`) included when you click **Export manuscript** |
| Outline | Story direction, arc plans, and chapter or episode beat sheets (`outline`) |
| Character / Lore | Character sheets (`character`) and worldbuilding rules (`lore`) |
| Project material | Reference notes (`snippet`) stored inside a project's **Materials** folder that you can attach to chat |
| Materials Library | Your account-level Reference Library for uploading `.txt` novels and reading AI breakdowns across projects |

See [File types](file-types.md) and [Materials Library](../user-guide/materials.md).

## AI chat and skills

| Term | Meaning |
| --- | --- |
| Focused file | The file currently open in the editor, passed along as your active working file |
| Text quote | An editor passage highlighted and sent into chat with its source file attached |
| Material attachment | Up to 5 reference items pinned above the chat box for the current message |
| Context | The conversation history, files, quotes, and materials the AI reads on a turn, bounded by length limits |
| Skill | A reusable set of writing or editing instructions (and optional reference files) loaded on demand |
| AI Memory | Project-level summary, writing style, current stage, and **Writing Conventions** injected automatically |
| Tool operation | A concrete action taken by the AI—such as reading, creating, editing, or deleting a project file |
| Streaming | Real-time display of the AI's progress steps and text as a reply is generated |

See [Collaborating with the AI assistant](../user-guide/ai-assistant.md) and [AI Memory](../advanced/ai-memory.md).

## Saving, review, and recovery

| Term | Meaning |
| --- | --- |
| Save | Syncing the current file's title and body text to the cloud server |
| Local draft | Unsaved edits cached locally in your browser so a refresh or drop in connection does not lose text |
| Save conflict | A prompt shown when the server copy changed elsewhere, letting you compare and merge before saving |
| File version | A saved snapshot of a single file recorded in **History** |
| Diff review | Side-by-side or inline review where you accept or reject proposed edits block by block |
| Restore / Undo | Rolling a file back to a selected snapshot from **History** or an AI chat edit card |
| Export | Downloading all saved `draft` and `script` chapters in a project—or the open file—as a UTF-8 `.txt` file |

See [Using the editor](../user-guide/editor.md), [Version history](../user-guide/version-history.md), and [Export your manuscript](../user-guide/export.md).
