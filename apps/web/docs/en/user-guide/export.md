# Export your manuscript

**Export manuscript** combines the current project's saved draft and script files into one TXT for reading, submission, or a separate copy. Choose **Export outline and text** to include outlines.

## Download

1. Open the project and save changes you want to export.
2. Finish AI writes and diff review, then inspect the prose.
3. Choose **Export manuscript** or **Export outline and text** in the header, or the menu on a phone.
4. Open the downloaded TXT and check its beginning, chapter order, and ending.

The filename usually includes the project name. If the download is missing, check browser downloads and the page's message.

## What is included

| Content | Exported? |
| --- | --- |
| Saved, non-deleted `draft` and `script` files | Yes |
| Outlines | Included with **Export outline and text** |
| Characters, lore, and materials | No |
| Chat, AI Memory, and version history | No |
| Unsaved editor changes | No |

Selection uses file type, not just folder or title. Renaming a character file “Final draft” does not include it.

TXT contains each file's title and prose, separated by `---`. When included, outlines appear before the prose. Chapter, episode, and scene numbering can affect order. Use consistent numbering and inspect the result.

If there is no saved outline, the page reports that only prose was exported. Open the TXT to check what it contains.

## Deliver selected chapters

The current control combines all drafts and scripts. For the first two chapters, download the full manuscript, then save a separate submission copy and remove unwanted chapters locally. Retain the full download; there is no need to delete chapters from the project.

## Bring offline changes back

Downloaded TXT does not synchronize with the project. Open the corresponding file, compare the current draft, copy approved changes, and save. Do not paste an entire merged manuscript into one chapter file.

The TXT contains the manuscript and any outlines supported by the chosen export option. Keep important characters, lore, and reference notes separately. Use local software for Word, PDF, or EPUB formatting.

For failed downloads, encoding problems, or missing passages, see [troubleshooting](../troubleshooting/common-issues.md).
