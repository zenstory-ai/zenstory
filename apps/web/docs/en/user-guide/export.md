# Export your manuscript

Click **Export whole work (TXT)** in the project top toolbar (labeled **Export whole script (TXT)** in short-drama screenplay projects) to combine all saved draft or script files in your project into a single UTF-8 `.txt` file for reading, submission, or backup. To save an individual outline, character sheet, or single chapter on its own, use **Download current file (TXT)**.

## Export the full work or download a single file

### 1. Export the whole manuscript or script

1. Open the project and make sure the editor status bar shows your latest edits as saved, with no AI writes or diff reviews still in progress.
2. Click **Export whole work (TXT)** (or **Export whole script (TXT)**) in the top-right project toolbar on desktop, or open the top-right menu on mobile and choose the same action.
3. Your browser downloads a `.txt` file named after the project. Open the downloaded file to verify its opening, chapter order, and ending.

### 2. Download the currently open file

To save a single chapter, outline, character sheet, worldbuilding file, or project material note separately:

1. Click the file in **Files** so it is open in the center editor, and confirm it is saved.
2. Click **More Actions** (`⋯` in the top toolbar on desktop, or the top-right menu on mobile) and choose **Download current file (TXT)**.
3. Your browser downloads a standalone `.txt` file named after that document's title.

## What is included in whole-work export

| Content | Included in **Export whole work / script (TXT)**? | How to save separately |
| --- | --- | --- |
| **Saved, non-deleted `draft` and `script` files** | **Yes** (merged in order and separated by `---`) | You can also open a single chapter and use **More Actions → Download current file (TXT)** |
| **Outlines (`outline`), Characters (`character`), Worldbuilding (`lore`), and Project Materials (`snippet`)** | **No** | Open the file in the editor and click **More Actions → Download current file (TXT)** |
| **AI chat history, AI Memory, and file version history** | **No** | Save accepted decisions into project files before downloading |
| **Unsaved edits in the editor** | **No** | Press `Ctrl/Cmd + S` or click **Save** first, then export |

Whole-work export filters strictly by file type (`draft` and `script`), not by file title—renaming a character file to “Chapter 1” will not include it in the manuscript export.

The compiled `.txt` file includes each chapter's title and body text separated by `---`, ordered by your file tree and chapter/episode numbering (`Chapter 1`, `第一章`, `第1集`, etc.). Use consistent numbering across chapters and inspect the downloaded file.

## Delivering selected chapters and bringing offline edits back

- **Deliver only specific chapters**: **Export whole work (TXT)** merges every chapter in the project. To submit just the first two chapters, either download the full manuscript and trim a separate submission copy locally, or open each chapter and use **More Actions → Download current file (TXT)**—never delete chapters from your cloud project just to export a subset.
- **Bring offline changes back into your project**: Downloaded `.txt` files do not sync back automatically. After editing offline, open the matching chapter file in the workbench, compare it with your local copy, paste the approved changes into that chapter, and save. Do not paste an entire multi-chapter merged `.txt` file into a single chapter file.
- **Convert to other formats**: ZenStory exports UTF-8 `.txt` files; open the `.txt` file in your local word processor when you need `.docx`, PDF, or EPUB formatting.

For failed downloads, encoding issues, or missing passages, see [Troubleshooting common issues](../troubleshooting/common-issues.md).
