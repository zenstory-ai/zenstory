# Materials Library

ZenStory provides two distinct places for reference materials:

- **Account Materials Library (Reference Library)**: Opened from **Materials** in the top dashboard navigation. Upload a `.txt` reference novel here to have the AI break it down into chapter summaries, characters, worldbuilding, special powers, storylines, plot points, and plotlines that you can browse and cite across all of your projects.
- **Project `Materials` folder**: Located inside an individual project under **Files → Materials** (see [File tree and file management](file-tree.md)). Use this folder to upload plain-text reference notes scoped to that project (up to 2MB and 200,000 characters per file, free on all plans without running AI novel breakdown).

Note: To import **your own manuscript chapters** for continued writing, use **Have a draft already? Import it (txt / md)** on the dashboard home or the `+` button next to **Drafts** inside a project rather than uploading to the Reference Library.

## Free trial and Pro allowance

Reference novel breakdowns are a Pro benefit, with a one-time free trial for Free accounts:

- **Free (one-time 3-chapter trial)**: Each account includes **1 lifetime free trial** (**Try the first 3 chapters free** on the Materials page). When you upload a `.txt` novel, ZenStory retains and analyzes the **first 3 complete chapters** (up to **15,000 characters** in total). Submitting a trial permanently consumes the one-time trial (it is not restored on failure or deletion, and the free trial does not include a free retry; limited to one trial account per network per Beijing day). Completed trial results stay in your library permanently for reading and citing in chat.
- **Pro (5 breakdowns per month)**: Pro includes **5** reference novel breakdowns per month (resetting at 00:00 Beijing time on the 1st of each month) for `.txt` books up to **20MB** and **300,000 characters**. Each upload or **Retry** uses 1 monthly breakdown; if a platform failure occurs, that breakdown is refunded automatically. Even after you use all 5 breakdowns for the month, previously analyzed novels remain available to read and cite.

## Prepare and upload a reference novel

1. Open **Materials** in the top dashboard navigation and click **Upload Novel** (or **Try the first 3 chapters free** on eligible Free accounts).
2. Select a `.txt` file you have the right to use (UTF-8 or GBK encoding; PDF, Word, and EPUB are not accepted). The file must contain recognizable chapter headings on their own lines (such as `Chapter 1`, `第一章`, or `第一回`).
3. Check the book title and the chapter scope shown in the dialog, then confirm to start the breakdown.

## Read the breakdown results

After upload, the novel card tracks analysis progress in the background. Once complete, click the card to open its detail page and switch across the breakdown tabs:

- **Material overview**: High-level summary of the book's premise, hooks, and structure.
- **Chapters**: Per-chapter synopses with expandable **Original Text** so you can verify exact passages.
- **Characters / Plotlines / Plots / Storylines / Worldbuilding / Special Powers**: Structured entries extracted from the novel by category.

Categories vary by genre and book—an empty tab does not mean the source text lacks that element. Use summaries to locate scenes quickly, then check the original chapter text to verify details. If a breakdown task fails, check the error message on the card; Pro users with remaining monthly allowance can click **Retry**.

## Reference or import items in a project

Inside any project, switch the left sidebar to the **Materials** tab to browse all analyzed reference novels in your account:

- **Attach to the current chat turn**: Expand a category, click an entry to preview it, and click **Add to chat** to pin it above the AI input box (up to **5** attached materials per message). Then state what you want to analyze or borrow:

```text
Use the attached passage to analyze the action where the character changes their goal.
Separate source facts from interpretation. Do not continue my story yet.
```

- **Import into the project file tree**: Click **Add to project** in the entry preview (or click the multi-select icon in the top right of the pane to batch-import multiple entries) to copy those notes into the current project's **Files → Materials** folder for ongoing editing.

See [Material analysis](../advanced/material-analysis.md) for a worked example of turning reference reading into a new scene.
