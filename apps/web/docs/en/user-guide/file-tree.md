# File tree and file management

The file tree keeps drafts, characters, outlines, and reference notes in one project. Click a folder to expand it and a file to open it in the editor.

## Create a file

Use the create control beside a folder, enter a title, and press Enter. Esc cancels. The folder usually determines the type: Characters creates character files, Drafts creates prose, and Scripts creates scripts.

The empty editor also provides actions for Draft, Outline, Character, Lore, and Script. Choose the intended use first so writing notes do not appear in a manuscript export.

See [file types](../reference/file-types.md) for the full list and examples.

## Change a title

Open the file, edit its title at the top of the editor, and save. You do not need to delete it. Renaming a character file does not turn it into a draft.

The current tree has no drag-to-move or type-conversion control. To reorganize, create a correctly typed file in the target location, copy adopted text, and save. A new copy has separate history; retain the original until you have checked it.

## Import existing text

- The upload control in Drafts accepts TXT and Markdown and splits recognizable chapter headings into draft files.
- Uploading through the project Materials folder adds reference text you can attach to chat.
- The workbench Materials Library breaks down reference novels; it is different from importing your own manuscript into Drafts.

Check the resulting tree and errors. Multiple-file imports can partly succeed; inspect created chapters before filling gaps.

## Search and quote

Use `Command/Ctrl + K` to search file titles in the current project. Arrow keys select a result, Enter opens it, and Esc closes search.

Open a character, outline, or draft, select a passage, and choose **Add to chat**. Material items have their own attachment controls. Save important notes before asking the AI to read them.

## Delete

Choose the item's delete control, check its title, and confirm. Deleting a folder affects its contents. There is no separate file-trash interface, and deleted files cannot be restored from history.

For one lost passage, inspect [version history](version-history.md) and choose the smallest recovery scope.
