# Troubleshooting common issues

Retain unsaved text first, then address the specific issue. Reloading, clearing site data, or repeating generation are not universal fixes.

## Unsaved content or a conflict

1. Copy important local text to a separate document.
2. Check connection and editor status; try manual Save.
3. For a conflict, compare the newer server copy with local text, merge, then submit.
4. If a recovery prompt appears after reopening, check both copies before choosing.

If local storage fails, retain the draft as instructed. Reopen the page only after preserving your text. See the [editor](../user-guide/editor.md).

## Slow, disconnected, or stopped AI

Check progress, operation results, and file writes first. Task duration varies; there is no fixed “reload after 30 seconds” rule.

After interruption, inspect the target file and continue only the gap. Do not append completed chapters again. Address quota, access, or service errors first. See [error messages](error-messages.md).

## Login or verification problems

- Check the registered email or username and password case.
- Check spam and email spelling; wait for the resend countdown.
- Reset through an emailed code if you forgot the password. Google-created accounts without a password can use this too.
- For Google authorization errors, retain the message and re-enter the login flow; contact support if it persists.

Keep unsaved prose before logging in again. You do not need to allow all third-party cookies or clear local storage first. See [registration and login](../getting-started/installation.md).

## Unexpected file or project lists

Check account and project, then use the page's Retry control. Clear search and type filters for missing results. For creation errors, check the name, allowance, and specific message.

When imports partly succeed, inspect created chapters before handling failed files. Do not delete and recreate files just to rename them.

## Material analysis fails

Inspect task errors and quota status. Check TXT format, size, and chapter headings. If a completed task has an empty category, check its actual analysis scope; free trials process only the scope stated by the trial entry. Check the chapters actually retained for that task.

Follow Retry when offered instead of repeatedly uploading. See [Materials](../user-guide/materials.md).

## Failed downloads or garbled text

Confirm prose is saved and draft or script files exist. Check page errors and browser downloads. TXT uses UTF-8; open with that encoding and keep the original before converting.

Characters are outside the export scope. Choose **Export outline and text** when you need outlines, and check the download. See [export](../user-guide/export.md).

## Slow pages

Retain prose, close unrelated tabs, and check whether one long file is affected. Organizing long work by chapter helps editing. If it persists, report file size, browser version, and steps; clearing all browsing data is unnecessary.

## Contact support

Use in-app feedback or [support@zenstory.ai](mailto:support@zenstory.ai). Include the exact message, time, page path, steps, and browser version. Hide private text and never send passwords, verification codes, or tokens.
