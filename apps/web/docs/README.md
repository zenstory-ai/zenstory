# ZenStory 工作台文档

从第一份大纲到正文定稿与导出，在 [工作台](https://app.zenstory.ai/dashboard) 创作，在这里查阅操作说明，或按 `Ctrl/Cmd + K` 搜索功能关键词。

## 快速入门

- [网页写作快速入门](getting-started/quick-start.md)：打开或创建作品、使用三栏工作区、写下第一段并导出备份
- [账号注册与登录](getting-started/installation.md)：注册邮箱验证、选择创作方向、找回密码与个人设置
- [写第一篇短篇](getting-started/first-project.md)：搭建大纲与角色、起草第一章、局部润色并导出 TXT

- [编辑器使用](user-guide/editor.md)：正文编辑、自动保存、未保存草稿恢复、选中引用、去AI味与变更审阅

### 版本、导出与订阅
