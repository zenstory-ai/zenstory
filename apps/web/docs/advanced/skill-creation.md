# 自定义技能进阶

把反复使用的写作或审稿方法保存为自定义技能，可以省去每次在对话里重复解释规则的时间。一个好用的技能通常聚焦解决一项明确问题，并写清执行依据、步骤、交付形式和改动边界。

## 从一次真实任务提炼指令

建议先在对话中跑通一次你满意的局部任务，再把提示词提炼成通用技能。请勿将某部作品的专属人名、私密设定或未公开正文直接写进通用技能中。

例如，下面的“有限视角检查”可直接填入技能的**指令内容**框：

```markdown
# 有限视角检查

## 依据
先读取作者指定的人物资料、当前场景与引用段落。
缺少人物已知信息时，先提出问题。

## 步骤
1. 找出直接断言其他人物内心、身份或真相的句子。
2. 对照当前视角人物已经知道的事。
3. 区分确有矛盾与尚待作者决定的问题。

## 交付
列出问题原句、文件依据和最小替换建议。
保留已经确认的行动与结果。
先在对话中给建议，不修改文件，不补写人物生平。
```

技能用于提供写作与检查方法，本轮所需的具体资料仍需通过打开目标文件、选中文本点击**引用**或在对话中点名读取来提供；指令中写 `{{selectedText}}` 或 `{{currentFile}}` 等占位符不会自动替换为项目内容。

## 写清描述、标签与主动调用

- **描述（决定 AI 何时自动选用）**：在创建或编辑技能时，**描述**字段（最多 1,024 字符）用于告诉 AI 这项技能解决什么问题、在什么任务下应当调用。请用具体任务表述（如“检查场景中是否出现视角人物尚未知晓的信息”），避免写成“改文”“润色”等过于宽泛的词。
- **标签（仅用于分类整理）**：**标签**字段（英文或中文逗号分隔，最多 50 个）仅用于在技能管理列表中分类和筛选，**不会影响 AI 何时调用该技能**。
- **在对话中主动挂载**：若本轮明确需要使用某个技能，直接在 AI 输入框输入 `/` 选择该技能，或从项目左侧**技能**标签点击 `+` 挂载（单条消息最多挂载 **3 个**技能）。复杂任务可按“规划 → 起草 → 审稿”分阶段选用不同技能。

## 添加与管理资源文件

保存自定义技能后，可在编辑弹窗底部维护附属**资源文件**，把较长的检查清单、格式范例或设定模板放在 `references/` 或 `assets/` 目录下，并在**指令内容**中说明何时读取哪份资源。

| 字段或项目 | 规格限制 |
| --- | --- |
| **技能名称** | 必填，最多 100 字符 |
| **描述** | 选填，最多 1,024 字符（供 AI 判断适用场景） |
| **标签** | 选填，最多 50 个，每个最多 100 字符（仅用于分类整理） |
| **指令内容** | 必填，最多 50,000 字符 |
| **附属资源文件** | 最多 20 个文本文件，单个不超过 64 KiB，总计不超过 256 KiB |

资源文件支持 `references/` 或 `assets/` 目录下的 `.md`、`.txt`、`.json`、`.yaml`、`.yml` 和 `.csv` 文本格式。技能仅提供写作方法与参考文本，不会在工作台内执行任何脚本文件。

## 导入标准技能包

点击**技能管理**右上角的**导入**，可上传单个 `.md` 文件（最大 **256 KiB**）或 `.zip` 压缩包（最大 **1 MiB**）。标准技能包根目录需包含 `SKILL.md`（不超过 256 KiB），且 YAML 头部至少包含 `name` 和 `description`：

```markdown
---
name: viewpoint-check
description: Check a scene against the viewpoint character's knowledge.
---

Read the specified scene and character notes.
List inconsistent sentences, evidence, and suggested replacements.
```

`.zip` 包内可包含 `references/` 或 `assets/` 文本资源目录。导入完成后请留意页面提示：脚本文件与不支持的二进制文件会被自动跳过，YAML 中的 `allowed-tools` 字段也不会改变工作台权限。

## 验证和迭代

新建或修改技能后，先用一段短正文测试它能否准确定位问题，再分别测试一次“资料缺失时是否先提问”和“存在事实冲突时是否只改指定范围”。如果输出不符合预期，优先调整指令中最相关的那一条规则；当一份技能指令过长、同时塞入多种互斥要求时，建议拆分为两个独立技能。分享到公共发现页前，请先用**导出为 zip** 留存本地副本，并确认已移除私人稿件或无权公开的内容。

基础添加与启用操作见[技能系统](../user-guide/skills.md)。
