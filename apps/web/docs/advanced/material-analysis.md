# 素材深度分析

带着一个具体的写作问题去阅读参考小说，再把提炼出的方法迁移到自己的故事场景中。素材库拆出的分类条目用于快速定位，章节原文则用于验证你的判断是否准确。

## 先选定一个具体问题

阅读参考书时，先聚焦一个可观察的技法问题——例如：“人物是如何通过具体动作改变目标的，而不是突然站出来讲一段大道理？”先在素材库中找到相关章节或短片段，避免一次性要求 AI 归纳整本书的全部优点。

建议把阅读笔记分为三层：**原文明示的事实**、**有依据的解读**、**尚需补读确认的问题**。人物标签和章节梗概只能帮助定位，不能替代原文中的具体动作与对话。

## 示例：什么改变了人物的选择

下面是一段原创教学片段：

> 方遥把旧演出录音剪到第三遍，母亲的独奏仍被椅响盖住。听音会节目单写着“她最好的演奏”。朋友建议删掉杂音，接上后面重复的小节。
>
> 方遥来回播放。后面一遍快了一点。椅响之后，母亲轻声说：“别急，等他坐稳。”
>
> 方遥撤掉拼接，划掉节目单那行字，改成“那天，她停了一下”。

可以按三层结构拆解这段文字：

| 分析层次 | 本段依据 |
| --- | --- |
| **原文事实** | 反复剪辑录音、听见椅响后的一句话、撤掉拼接、修改节目单字样 |
| **有据解读** | 她的目标从“呈现无瑕的最佳演奏”转向“保留一次有人情味的停顿” |
| **尚未证明** | 听众的反应、母亲的生平背景，以及方遥此后是否彻底改变 |

注意：她改变了评判成功的标准，但杂音和被盖住的独奏依然存在，选择所付出的代价并没有消失。

## 请 AI 核对你的解读

在项目左侧**素材库**标签中点击目标条目选择**添加到对话**，或在项目素材文件中选中文本点击**引用**，再发送分析请求：

```text
只分析这段原文，列出人物起初的目标、改变目标的依据、实际选择和剩余代价。
每个解读附短引文。资料不足的地方写明缺哪段上下文。
不补人物生平，不续写故事，不修改项目文件。
```

读完 AI 的回复后回到原文核对引文。没有原文证据支撑的推断先留作待考问题，不要直接写进自己作品的正式设定。

## 把方法迁移为自己的新场景

借鉴“重新选择成功标准，同时保留代价”这一结构时，应当为自己的角色设计完全不同的处境与行动，而不是只换人名或把“录音”改成“录像”：

例如：岑一只剩十分钟小车练习时间。他可以独自跑完一圈全速练习，也可以询问第一次来的陶陶想不想试一次左转。如果他决定把时段让给陶陶，就通过询问、递交控制器和在旁等待来表现，且最终他自己的全速练习依然没有完成。

先确定人物目标、具体动作和保留的代价，再让 AI 起草候选场景：

```text
写岑一把剩余练习时段交给陶陶的场景。
用询问、交出控制器和等待表现变化，不写总结道理。
结尾陶陶自己完成一次左转，岑一的全速练习仍未完成。
先在对话中给候选正文，不写入文件。
```

## 保存自己的阅读与创作成果

将参考书的原文位置、短引文和技法解读保存在项目的**素材**笔记中；而自己作品的**大纲**（或**构思**）文件夹里只放入已确认采用的新场景设计。当候选正文确认采用后，再写入**正文**文件并更新进度。

参考小说的上传与引用操作见[素材库](../user-guide/materials.md)，日常推进节奏见[高效写作工作流](workflow-tips.md)。
