# 文件类型参考

文件类型用来区分每份文档在项目中的用途。虽然文件标题、所在文件夹和文件类型彼此对应，但仅修改标题并不会改变文件的内部类型。建档时选对类型，后续整理资料和导出整本正文都会更省心。

## 类型与导出范围

| 类型 | 用途与导出规则 |
| --- | --- |
| 大纲 `outline` | 记录故事走向、分卷规划与单章目标；不计入整本导出，可单独下载为 TXT |
| 正文 `draft` | 长篇小说或短篇故事的章节正文；包含在**导出整本正文（TXT）**中 |
| 角色 `character` | 人物目标、关系、过往经历与当前知情范围；不计入整本导出 |
| 设定 `lore` | 地点、力量体系、历史背景与规则限制；不计入整本导出 |
| 素材 `snippet` | 上传到当前项目的参考文本与读书笔记；不计入整本导出 |
| 剧本 `script` | 短剧分集场次、动作与台词；包含在**导出整部剧本（TXT）**中 |
| 文件夹 `folder` | 在文件树中归类组织文档；不含正文，不参与导出 |

所有文档均使用纯文本编辑器编写，不设固定必填表单，也不会自动校验全部设定字段。

## 大纲示例

```text
第1场 认领
目标：沈敏认领包；林禾核对依据。
阻力：她说错内袋物件。
变化：林禾暂停交付，进一步询问。
待定：报错原因和最终归属。
```

正式大纲里只放已经拍板的故事走向；还没定下来的备选方案单独标明“待定”，正文写完后再按实际改动同步更新。

## 角色与设定示例

角色卡可以先记下对眼下这场戏有用的核心信息，不必一上来写满生平小传：

```text
林禾：失物招领值班员。
目标：关闭窗口前处理认领。
边界：不能只凭口头说明交包。
已知：外观描述吻合，内袋描述不符。
未知：沈敏为什么说错。
```

世界观设定同样优先记录会直接影响人物行动的规则与代价，无需先把整套百科全书铺完；同时注意把“角色当下知道什么”和“作者私下设定的底牌”分开记。

## 素材与剧本

项目内的**素材**文件夹适合存放短篇参考文本或摘录笔记，写作时可随时挂载到当轮对话；整本参考小说的 AI 拆解结果则在账号级的**素材库**中独立查阅。

剧本文件可按“场次、地点、人物、动作、对白”自由排版。`script` 类型用于组织和导出文字剧本，工作台本身不直接渲染视频画面。

## 选错文件类型怎么办

新建文档时，请先看清目标文件夹的用途，或直接从空编辑器的快捷卡片中选择对应类型。工作台目前不支持直接转换已有文件的类型：如果建错了类型，请在正确的文件夹下新建一份文档，把需要保留的内容复制过去并确认保存成功，再决定是否删除旧文件。

新文件拥有独立的文档 ID 和版本历史。具体管理方法见[文件树与文件类型](../user-guide/file-tree.md)，导出规则见[导出正文](../user-guide/export.md)。
