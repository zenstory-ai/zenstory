# 文件类型参考

类型说明文件的用途。标题、文件夹和文件类型互相关联，但改标题不会转换类型。选对类型，能让资料组织和正文导出更清楚。

## 类型与用途

| 类型 | 内容与导出 |
| --- | --- |
| 大纲 `outline` | 故事方向、章节目标、场景变化；选择“导出大纲和正文”时导出 |
| 正文 `draft` | 小说或短篇的叙事文字；导出 |
| 角色 `character` | 人物目标、关系、背景、已知信息；不导出 |
| 设定 `lore` | 地点、规则、历史与能力限制；不导出 |
| 素材 `snippet` | 参考文本和阅读笔记；不导出 |
| 剧本 `script` | 分场、对白和动作；导出 |
| 文件夹 `folder` | 组织文件；不导出 |

各内容文件都使用文本编辑器。类型不会自动检查所有设定，也不要求你填固定表单。

## 大纲示例

```text
第1场 认领
目标：沈敏认领包；林禾核对依据。
阻力：她说错内袋物件。
变化：林禾暂停交付，进一步询问。
待定：报错原因和最终归属。
```

只把选定方向放入正式提纲。未选方案另列待定，写完后按实际变化更新。

## 角色与设定示例

角色卡可以先写对当前场景有用的几项：

```text
林禾：失物招领值班员。
目标：关闭窗口前处理认领。
边界：不能只凭口头说明交包。
已知：外观描述吻合，内袋描述不符。
未知：沈敏为什么说错。
```

设定文件记录会影响行动的规则及限制，不必先造完整百科。人物知道什么与作者知道什么分别记录。

## 素材与剧本

素材条目适合存参考文本，并通过附加入口提供给对话。素材库的拆解结果另在账号素材库中查看。

剧本可以按“场次、地点、人物、动作、对白”写。剧本类型用于组织与导出文字，不直接生成视频。

## 类型选错时

新建时确认文件夹用途，或从编辑器空白页选择明确类型。当前没有直接转换类型的界面；需要调整时，在正确类型下新建文件并复制采用的内容，检查保存后再决定如何保留原文件。

复制会产生独立文件和历史。操作方法见[文件管理](../user-guide/file-tree.md)，导出范围见[导出正文](../user-guide/export.md)。
