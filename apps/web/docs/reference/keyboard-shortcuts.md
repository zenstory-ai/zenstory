# 快捷键参考

macOS 使用 `Command`（`⌘`），Windows 和 Linux 使用 `Ctrl`。快捷键对当前获得焦点的区域生效；使用输入法选词确认时按 `Enter` 不会直接发送消息。

## 文件与编辑器

| 快捷键 | 功能 |
| --- | --- |
| `Command/Ctrl + K` | 打开当前项目的文件搜索 |
| 搜索中的 `↑`、`↓` | 上下选择匹配结果 |
| 搜索中的 `Enter` / `Esc` | 打开所选文件 / 关闭搜索面板 |
| `Command/Ctrl + S` | 立即保存当前文件 |
| `Command/Ctrl + Shift + Q` | 将选中的正文片段引用到 AI 对话 |
| `Command/Ctrl + Shift + R` | 对选中段落执行去AI味，并打开结果预览 |

常规撤销与重做直接沿用浏览器的文本输入快捷键（`Command/Ctrl + Z` 等）。注意：每次保存都会更新云端正文，但短时间内连续保存可能会合并到同一条历史版本中。

## AI 输入框

| 按键 | 功能 |
| --- | --- |
| `Enter` | 发送消息 |
| `Shift + Enter` | 在输入框内换行 |
| 输入框为空时按 `Tab` | 直接填入第一条推荐提示 |
| `/` | 打开技能选择菜单 |
| 技能菜单中的 `↑`、`↓` | 上下选择技能 |
| 技能菜单中的 `Enter` / `Tab` | 挂载当前选中的技能 |
| 技能菜单中的 `Esc` | 关闭技能菜单 |

选好技能后，继续在输入框写明本轮的具体任务即可。手机软键盘的回车行为因输入法而异，建议直接点击右侧发送按钮。

## 差异审阅

当焦点位于差异审阅区域时，可使用以下按键逐处处理改动：

| 按键 | 功能 |
| --- | --- |
| `↑` / `K`、`↓` / `J` | 跳转到上一处、下一处差异 |
| `Y` / `N` | 接受或拒绝当前改动 |
| `U` 或 `R` | 将当前项重置回待确认状态 |
| `L` | 在正文中定位当前差异 |
| `Shift + Y` / `Shift + N` | 全部接受 / 全部拒绝 |
| `Enter` | 完成审阅并保存结果 |

点击完成审阅时，尚未拒绝的待审改动都会一并采用。如果想放弃本轮全部候选改动，请先按 `Shift + N`（或点击**全部拒绝**），再完成审阅（或直接按 `Esc` 退出）。

## 快捷键未生效时

请先确认鼠标焦点已落在对应区域，并检查当前是否正处于输入法拼写状态或差异审阅模式；必要时可直接点击界面上的对应按钮。工作台暂不支持自定义快捷键，文件树也不设 `F2` 重命名或 `Delete` 删除快捷键。

详细操作说明见[编辑器使用](../user-guide/editor.md)和[AI 创作助手](../user-guide/ai-assistant.md)。
