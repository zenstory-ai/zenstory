# 术语表

这里汇总了 ZenStory 工作台常用的界面名称与核心概念。遇到不熟悉的术语时，可顺着下方链接查看详细用法。

## 项目与资料

| 术语 | 含义 |
| --- | --- |
| 项目 | 一部独立作品的工作空间，包含各自的文件树、对话记录与 AI 记忆 |
| 文件树 | 项目左侧按文件夹层级排列的文档目录 |
| 正文 / 剧本 | 会被合并进整本 TXT 导出的作品正文文件（`draft` / `script`） |
| 大纲 | 已确定的故事主线、分卷结构或单章/分集安排 |
| 角色 / 设定 | 人物档案卡与世界观规则说明 |
| 项目素材 | 存放在当前项目**素材**文件夹中的参考文本，可按需挂载到对话 |
| 素材库 | 账号级的参考小说库，保存整本或试拆小说的结构化拆解结果 |

详见[文件类型详细说明](file-types.md)和[素材库](../user-guide/materials.md)。

## AI 对话

| 术语 | 含义 |
| --- | --- |
| 焦点文件 | 当前在中间编辑器打开的文件，发送消息时 AI 会默认感知这份已保存文档 |
| 文本引用 | 在编辑器中划选并挂到输入框上方的原文片段及其来源文件 |
| 素材附件 | 本轮对话手动勾选附加的项目素材或参考小说拆解条目 |
| 上下文 | 单轮对话实际提供给 AI 的消息、文件与参考资料，受总长度预算限制 |
| 技能 | 封装好的可复用写作、审稿或改编方法（支持附带参考资源文件） |
| AI 记忆 | 跨对话保留的项目简介、写作风格、当前阶段与写作约定 |
| 工具操作 | AI 在本轮对话中读取、新建、编辑或删除项目文件的实际操作记录 |
| 流式输出 | AI 回复与正文写入随生成进度实时逐字呈现 |

详见[AI 创作助手](../user-guide/ai-assistant.md)和[AI 记忆与上下文](../advanced/ai-memory.md)。

## 保存与版本恢复

| 术语 | 含义 |
| --- | --- |
| 保存 | 将编辑器当前的标题与正文提交到云端服务器 |
| 本地草稿 | 尚未同步到云端前暂存在当前浏览器中的文字，不等同于云端已保存 |
| 保存冲突 | 本地编辑期间云端文件已产生新版本，需先分栏对照合并后再保存 |
| 文件版本 | 单个文件在版本历史中留存的一次快照 |
| 差异审阅 | 左右分栏对照原文与新内容，逐处选择接受或拒绝改动 |
| 恢复 / 回滚 | 用选定的历史版本替换当前文件的正文内容 |
| 导出 | 将项目内已保存的正文或剧本按顺序下载为本地 UTF-8 `.txt` 文件 |

详见[编辑器使用](../user-guide/editor.md)、[版本历史](../user-guide/version-history.md)和[导出正文](../user-guide/export.md)。
