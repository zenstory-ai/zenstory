# 术语表

这些术语说明工作台中的内容与操作。遇到不熟悉的标签，可以从这里找到对应指南。

## 项目和资料

| 术语 | 含义 |
| --- | --- |
| 项目 | 一部作品的文件、对话与项目记忆的容器 |
| 文件树 | 文件和文件夹的层级列表 |
| 正文 / 剧本 | 进入 TXT 稿件导出的文字类型 |
| 大纲 | 已选故事方向与章节、场景安排 |
| 角色 / 设定 | 人物资料及故事规则 |
| 项目素材 | 文件树里的参考文本，可附加到对话 |
| 素材库 | 账号中的参考小说及拆解结果 |

见[文件类型](file-types.md)和[素材库](../user-guide/materials.md)。

## AI 对话

| 术语 | 含义 |
| --- | --- |
| 焦点文件 | 当前打开的文件，发送请求时标明的目标 |
| 文本引用 | 选中的文字及其来源文件 |
| 素材附件 | 本轮明确附加的参考条目 |
| 上下文 | 本轮 AI 使用的消息、文件和参考资料，受长度预算约束 |
| 技能 | 可复用的写作方法与参考资源 |
| AI 记忆 | 项目简介、风格、进度和备注的简短记录 |
| 工具操作 | AI 对文件或项目执行的读取、创建、修改等操作 |
| 流式输出 | 回复与进度随生成过程逐步显示 |

见[AI 创作助手](../user-guide/ai-assistant.md)和[AI 记忆](../advanced/ai-memory.md)。

## 保存和恢复

| 术语 | 含义 |
| --- | --- |
| 保存 | 把当前标题和内容提交到服务端 |
| 本地草稿 | 浏览器保留的尚未保存文字，不等于云端保存 |
| 保存冲突 | 服务端内容更新过，本地提交需要先比较合并 |
| 文件版本 | 一个文件已保留的历史状态 |
| 项目快照 | 一个时点的项目文件状态及版本引用 |
| 差异审阅 | 对旧文与候选新文逐项接受或拒绝 |
| 恢复 / 回滚 | 用选定历史替换当前文件或项目状态 |
| 导出 | 下载已保存的正文和剧本 TXT 副本，可选择包含大纲 |

见[编辑器](../user-guide/editor.md)、[版本历史](../user-guide/version-history.md)和[导出正文](../user-guide/export.md)。
