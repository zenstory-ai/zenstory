# Agent Note: 项目统计改为单页事实概览

## Problem

用户指出项目统计过度设计、页面不清楚，并要求邀请产品角色重新设计，且不改后端。现有页面先给五个标签，总览再重复七张卡；健康评分、自动待办和按章节号猜测继续写作对象，把没有作者确认的推断与真实统计并列。用户另提供导出菜单截图：长标签在窄菜单中折行，并挤压图标。

证据为现有页面、七个统计组件、统计接口类型和两份既有统计口径决策。用户项目链接需要登录，本轮未复用日常 Chrome 登录态、未操作用户项目内容；视觉检查使用本地合成项目。产品设计角色提出方案，独立 critic 审查后补齐净字数、规划分母、懒加载与旧字段兼容边界。

## Decision

- 单页只保留一个概览和三个默认折叠的详情：总字数、可切换今日/本周/本月的周期字数、已写章/篇/集数；章/篇/集对应的内容明细、手写趋势、更多记录。取消五个标签以及健康评分、自动待办、算法推荐章节和泛化建议。概览不再与下方重复展示相同字数。
- 页头写「项目统计」，项目名为上下文。保留唯一「返回创作」入口和轻刷新；初始 loading/error/retry、背景刷新保留旧数据，不把失败说成零。
- `words_* + ai_words_*` 保留既有周期字数合计，「你写 / AI 写」拆分常显。以 `2026-10-10-project-stats-range-outline-remaining-ai-day-net-words.md` 为准：AI 统计是周期净变化求和后最低截为 0，不恢复更早的逐版本正新增算法。旧接口缺 AI 字段按 0，缺作品类型按长篇。页面只解释一次北京时间日界。
- 概览已写数 = completed + in_progress，复用 `writtenChapters()`；计划有值才显示计划 M，未知不显示百分比。分章详情展开后才呈现三状态计数与完成率，完成率以已完成/计划数为口径，不以「已写」作分子。`not_started_chapters` 可能包含尚未建文件的规划项，列表只列接口实际给出的 `chapter_details`，不冒充全部未开始。行导航优先 draft_id、其次 outline_id，无 ID 为不可交互文本。
- 手写趋势保留原组件但瘦身成事实型 disclosure：展开后才请求，日/周/月窗口保持 14/84/365 天，负值照实呈现；标注「仅手写净字数，不含 AI」。展开时刷新同时更新总览与当前趋势；趋势有独立 loading/error/retry/empty，不把请求失败伪装成无记录。
- 更多记录只保留连续写作当前/最长天数和上次写作日期，以及本项目作者发给 AI 的累计/今日消息数与对话次数。口径保留、不引入配额或建议。原生日历日用既有 `formatCalendarDate()`，不因用户时区回退一天。
- 迁移回归后删除唯一生产消费者已移除的六张旧卡片，清理 exports 与仅验证旧推断 UI 的测试；保留 `statsUnits`、趋势组件及真实 query 生命周期回归。只改前端、现有中英文翻译、设计合同和本 note，不动 API、后端、数据或依赖。
- 菜单文案缩短为「导出大纲与正文」/「Export outline & manuscript」，桌面菜单按内容限宽、桌面及手机导出项图标禁止压缩；TXT 导出格式、范围和成功提示不变，不改成含糊的「导出全部」。

## Alternatives considered

- **保留标签与七张卡，仅调整颜色和间距。** 迁移小，但依然要求作者在重复入口和主观结论之间判断，不解决信息结构问题。
- **给健康度、待办和进度增加更多解释。** 可揭示算法来源，但将统计页变成说明书，且不能把未经作者确认的判断变成事实，拒绝。
- **只显示三个总数，删除所有明细。** 最短，但损失分章核查、趋势与口径追溯；采用默认简洁、按需展开。
- **新增后端聚合或预测接口。** 可支持最近编辑、预计完稿等能力，但违反用户明确边界，也不是解决当前信息过载所必需。

## Consequences

页面从操作/评分仪表盘回到事实统计，主次清楚且仍能查看真实明细。旧推断型 UI 被移除是有意的产品变化，不改变后端计算、草稿或写作流程。初始少请求趋势。复制、换语言、触控、键盘及深浅主题仍需验证；不宣称已检查用户私有项目的实际数据。

## Verification

先补统计口径与新交互回归，再迁移页面、删除旧卡片。验证包括三种作品单位、已知/未知规划、旧字段、精确文件导航、趋势按需请求/负值/刷新/错误，以及中英文 390/768/1440px 的几何、可展开状态、44px 控件与截图；最后运行 lint/token/i18n、前端类型检查和构建。菜单已有先失败后通过的独立浏览器几何回归，导出范围与 TXT 行为测试保留。


结果：新交互回归在实现前 13 项全部失败，实现后完整前端套件 296 个文件、4660 项通过、1 项既有跳过；最后补手机图标的 class 后，相关页头、统计与 query 生命周期 84 项再次通过。Chromium/WebKit 覆盖 390/768/1440px、中英文、深浅主题，展开详情、负趋势、刷新与 axe serious/critical 检查全部通过；另补 390/768px 中英文菜单，手机先失败于 flex-shrink=1，修复后通过。lint、token、i18n、类型检查及构建通过；保留既有 useAgentStream 无效 eslint-disable warning，不顺手改无关文件。
