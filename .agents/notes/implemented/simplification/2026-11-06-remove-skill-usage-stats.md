# 移除技能使用统计

## Problem

作者不再需要技能使用次数、排行和每日趋势。只隐藏技能页入口仍会让每次显式选择或工具加载技能执行额外的统计写入，并留下无人使用的接口、弹窗和请求级去重状态。

本决策撤销 [标准技能架构](../architecture/2026-09-27-standard-skills-without-execution.md) 中的用量统计部分；技能加载、资源读取和聊天内的技能提示继续保留。

## Decision

- 删除技能页统计按钮、弹窗、客户端请求方法、类型和中英文统计文案。
- 删除 `/api/v1/skills/stats/{project_id}`、统计服务和运行时 `SkillUsage` 模型。
- 删除显式选择和 `load_skill` 的统计写入，以及仅用于统计的请求级去重状态。技能加载权限、正文预算、资源读取、显式注入和 SSE 技能提示去重不变。
- 额度扣费、后台模型调用指标和邀请统计各有独立用途，不属于本次清理。
- 保留历史 Alembic 迁移及已有数据库的 `skill_usage` 表和数据；不执行 DROP 或线上数据清理。新建的 `create_all` 数据库不再注册该表，旧数据库无需迁移即可运行本次代码。

## Alternatives considered

- **只隐藏入口**：改动最小，但统计写入、接口和维护成本仍在，不能完成用户要求的功能代码清理。
- **同时删表**：数据库也能清理干净，但会不可逆丢失历史数据，并扩大本次发布和回滚范围；本次没有必要。

## Consequences

技能选择和加载不再为统计提交数据库事务，旧统计 URL 返回 404。仍使用旧前端的标签页需刷新后移除入口。已有表的外键约束保持原状，直接 SQL 硬删除用户或项目时仍需处理历史关联行。

混合测试保留技能 CRUD、导入导出、权限、内容预算、提示注入及会话状态断言；补充加载和选择不提交统计事务、统计接口不存在的回归，删除仅针对已移除统计功能的测试。
