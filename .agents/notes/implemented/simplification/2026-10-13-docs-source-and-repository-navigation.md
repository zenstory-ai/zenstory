# 工作台文档单一来源与仓库目录整理

## Problem

官网的 25 个双语文档页面与仓库 docs/ 的用户文档分别维护，重复副本已出现注册、配额、保存、恢复、技能和素材说明不一致。仓库入口把用户操作、开发规则、历史方案与发布记录混在一起。

## Decision

清理范围限于文档和导航，不改变产品权限、存储或发布规则。逐篇更新 apps/web/docs/ 的 25 对中英文内容，保留现有公开 URL。仓库用户文档复用这一来源，移除 48 个重复的叶文档；docs/README.md 与英文入口链接到内容源。现有内部 Markdown 引用同步修正，已发布历史记录的固定提交链接保留。

当前文档逐篇按五步精修流程复核，README、CLI技能和双语帮助中的路由、只读、审稿、版本合并/恢复、导出与可配置免费试拆说明按代码对齐。CI 文档以实际 workflow、job 和触发条件为准，未接线的历史脚本不再作为推荐入口。Prefect 的重复部署指南合并为单一入口，见 [部署说明纠错](../bug-fix/2026-10-15-prefect-deployment-document-source.md)。

docs/ 保留当前开发、部署、发布与内容维护指南；日期化计划、设计和 QA 记录明确标为历史证据，集中目录导航。冗长内容批次台账从维护说明移到同目录历史文件，原始记录与 CSV 保留。

内容已按当前 owning code 更新。复核中英文内容、307 个仓库相对链接、25 个无 JS 页面、50 张手机首屏截图；同时覆盖 App 阅读器与语言切换。手机目录默认收起，英文正文的相邻文档链接保留 #en。SEO 复核保留全部 25 个公开地址、canonical、站点地图、双语 TechArticle 与无 JS 正文；摘要提取使用链接文字，去掉 Markdown 目标 URL。浏览器回归使用独立生成的静态页面 fixture，避免把 Vite SPA 当作静态站验证。CI、预发布验证与生产 tag 按 release-ci-cd.md 执行。


组织开源项目的当前帮助范围继续覆盖结构化内容：6 个项目页、17 篇入门与流程指南、11 个术语和 1 份环境选择说明；419 篇文章均复核技能入口，并按读者用途补审 49 篇视频、1 篇 CLI 和 87 篇其他操作或混合教程全文。其余 282 篇以创作练习为主的正文按案例用途保留，不把关键词命中当成当前操作手册，也不声称已逐篇重写。旧固定来源与发布时间保留，现行事实追加实际提交证据，修订日期反映本次修改。

纠正的事实包括规划与正文追踪的启动时机、白盒验证与正式构建的先后、公开扫榜数据与作者后台数据的区别、TTS 保留完整文本、独立配音及环境声跨切点的原生能力。电话戏按当前单份剧本交接，不重新要求已退役的录音表。原案例、坏例、配对、台词和代码块保留；仅将一处案例导言中与表格不符的“三句配音”改为“四句”，DSH 普通安装命令更新为已发布的宿主与插件版本。

`llms.txt` 的概览由人工复核，指南目录用现有 `update-guide-directory.mjs` 从 436 条 canonical 内容记录、10 个主题生成，避免另养摘要副本。E2E 旧进度文档只标明历史状态并指向当前入口，原计划、数字和代码块保留。此轮只涉及公开文档与导航，不修改应用内技能或内部提示词。

## Alternatives considered

- 同步复制两套用户指南：原路径可直接阅读，但每次修改需双份提交，容易再次漂移。
- 所有历史文档重写成当前指南：目录一致，但会篡改当时的设计和验证证据。
- 保留重复目录而加更多状态提醒：链接稳定，但用户仍需判断哪个版本有效。

## Consequences

App 和组织站保留阅读入口，公开文档只有一套可维护内容，开发文档与历史记录各有入口。旧仓库叶路径将移除，Git 历史仍可查；内部引用改为实际来源。此次不删除截图、CSV 或发布证据，不增加依赖。


## Verification

补查后的 251 处文本字段与逐篇修改包一致；独立审阅分开验证文案和包的集成。原固定来源、公开路由、发布日期、所有代码围栏和 7023 行引用保持原文。新增来源经过固定提交文件、行界与所属仓库核对。现有站点测试首轮发现引用格式及星标日期缺失，修正文档数据后 68/68 通过，未放宽测试。CSS token、i18n key、ESLint（零错误，保留原有一条 warning）、TypeScript、完整前端和组织站/帮助页构建通过；无付费模型调用。
