# 写作约定保存冲突后显示处理入口

## Problem

手机编辑 AI 记忆时，409 冲突提示出现在滚动区域底部之外。草稿虽保留，作者只能看到保存按钮禁用，难以发现下一步。

## Decision

首次进入冲突状态后，将现有冲突区域滚入最近可视位置，焦点移至「查看最新版本」。仅在冲突状态变化时执行，不在编辑、读取最新值或普通重渲染时抢焦点。保留现有草稿、expected_notes 比较和双版本处理流程，不新增文案或弹窗。

沿用 [写作约定设计](../simplification/2026-10-26-memory-current-turn-agreements.md)。

## Alternatives considered

只聚焦处理按钮改动更少，但浏览器可能只保证按钮可见，冲突原因仍在视野外。对整个冲突区滚动后再聚焦，能同时显示原因和下一步。

## Consequences

手机作者不必自行寻找冲突处理入口，桌面键盘操作也可直接继续。浏览器回归在 390×844、768 和 1440 宽度验证提示与按钮完整可见、焦点正确且草稿保留；修复前手机测试因提示可视比例为 0 失败。
