# Agent Note: 路由技术故障保留原任务与手动重试（#265）

## Problem

router 和 writing_graph 在解析/枚举失败后都曾固定降级 writer/quick，丢掉只读、禁写正文和交付范围。生产三次非法枚举未留下原值，不能推断具体格式根因，也没有证据证明已发生越权改稿。Prompt 的 JSON 示例确实用管道拼成非法枚举，可修正，但不能说它造成了历史三次。

本批初稿又把四个范围字段全部改成必填、取消两行格式，导致已有成功契约退化。按用户纠正，回到最小修复：已知格式尽量直接继续；不能恢复的系统故障不要求作者重新解释。

## Decision

- 严格生产者、兼容消费者：Prompt 继续要求完整 JSON。解析保留外层空白、围栏/说明中的完整对象、精确两行已知枚举、已知 agent 缺 workflow 时的原映射，以及原有 bool/0/1/明确字符串转换。可选范围字段缺失仍采用既有 RouterDecision policy，不新增四字段必填；这不是新的作者授权证明。显式限制必须保留，显式 null、未知布尔、错误 scope/类型列表不吞成默认。
- 继续寻找后续有效 text block；所有块均失败才结束。已知完整对象的单引号/尾逗号复用既有 parse_json_object，合成矩阵验证 agent/workflow 和全部显式限制值不变；不增加修复库或解析框架。明确 finish_reason=length、未完成对象/权限值不补猜，未知枚举不拼接、不模糊匹配或新增别名。
- 缺失/未知 agent、未知 workflow、空输出或无法恢复的协议失败，不进入任何 agent/工具；移除 router 与 graph 的 writer/quick 失败兜底，也不改成泛泛只读回答。真实任务歧义继续走已有结构化澄清，不为本故障新增澄清状态机或 LLM 调用。
- 原有 resume/inherit 路径仍只按既有结构化契约延续；新范围指令走正常路由，不在失败后追加历史恢复。缺少合法历史 agent/owner 时返回正常路由，不猜 writer；合法历史限制和原请求继续保留。
- 路由前技术失败使用专用 ERR_AGENT_ROUTING_FAILED、retryable=true、refundable=true，文案“这次没能处理你的要求，作品没有改动。可以稍后重试。”仅从已验证无 agent/tool/file mutation 的出口发出。复用现有错误卡/手动重试，不修改全局生成失败文案、不自动重试付费请求。原有成本保护与已分类供应商错误保持原码及 flags。
- 原消息保留；现有重试复用原请求/附件/技能，不新增用户气泡，服务端按既有末尾未回答消息规则避免重复。退款提示只来自真实 quota_refunded 帧，失败码本身不承诺已退款。
- 只有一个 ERROR 终态。保留已发生的 router 台账；内部 MESSAGE_END 只把真实 usage 交给 StreamAdapter，不伪造成功路由。router thinking 不保存成空助手历史。
- 在已有 request_id 链路只补固定 stage/category、预定义失败字段名、固定 parse_path、规范化 finish_reason 和 has_usage；不记录原字段值、正文、模型原文、敏感标识或原异常。无新表、框架或仪表盘。

## Alternatives considered

- **所有缺字段与旧格式一律拒绝。** 最强理由是契约最严格；未采用：改变已有合法路由 policy，已由基线/候选合成矩阵证实会引入新失败，不是修复三次未知故障的必要条件。
- **把坏枚举映射到 writer，或用用户文本关键词猜权限。** 最强理由是少打断用户；未采用：会扩大范围，正是已证缺陷。安全边界不能靠猜。
- **失败后沿用上一轮写权限，或转只读 reviewer。** 最强理由是还能给出回复；未采用：新指令不能由旧权限授权，降格回答也不是完成原任务，还可能增加付费调用。
- **要求用户重新选择规划/写作/审稿，或新增澄清系统。** 最强理由是能重新收集结构化意图；未采用：系统格式故障不代表作者没说清楚，现有原请求与手动重试已足够。
- **恢复任意截断的启发式补全。** 最强理由是兼容更宽；未采用：没有无损证据，权限字段可能未完成。本批只验证具体完整格式兼容，不泛化承诺。

## Consequences

已证的静默 writer 降级被移除；可恢复的既有格式仍直接完成，不能恢复的技术故障保留原任务、零作品写入并允许用户主动重试。真实模型成本仍记账，退额结果如实呈现。

兼容旧可选字段的代价是继续保留历史默认语义，而非重新设计全局权限契约。两种语法修复的合成样例成功也不解释历史三次非法枚举。#265 的真实格式根因、后续兼容修复和线上失败分布仍待安全观测；不得把观测、暂停或本批测试写成稳定性已恢复。不使用真实正文、不调用计费模型、不 tag、不发布生产。
