# 隐藏助手回复中回显的作者改动上下文

## Problem

可恢复编辑版本的 staging 真实模型验收中，写章与撤销正常，但助手总结直接显示了 `<author_edits>无</author_edits>`。这是给模型理解作者改动的内部上下文，不应出现在作者看到的回复里。现有回复规范已要求不回显内部字段，仅靠提示未避免这次外露。

## Decision

在实时消息与历史消息共用的 `stripThinkTags` 展示清理入口，精确移除完整的 `<author_edits>…</author_edits>` 块；流式内容出现已完整打开但尚未闭合的该标签时，暂不展示其后内容。沿用现有展示清理方式，不添加关键词、意图或权限判断。

助手回复之外的用户消息保持原样；普通正文及其他标记不受此规则影响。数据库原始消息、模型输入和文件正文不变。回归覆盖相邻正文、多块、其他标记、未闭合块和用户消息同名示例。

## Alternatives considered

- **只加强提示。** 不影响展示代码，也可减少模型回显，但现有规范下已经发生外露，不能修复已保存消息的展示。
- **过滤全部 HTML/XML 标记。** 能隐藏更多标记，却会误伤作者讨论的示例和合法正文，超出此次观察到的问题。
- **改写数据库历史。** 可清除已有记录中的标签，但会改变模型上下文与原始证据；统一展示清理即可覆盖旧消息，无需迁移数据。

## Consequences

已保存消息和新流式回复在显示时使用同一规则。这个修复不改变可恢复编辑的操作记录、撤销顺序或模型自检行为；staging 中观察到的过度字数微调另行记录。
