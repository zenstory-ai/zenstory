# Agent Note: 模型大段原样重复时截停这一轮，正文只留重复之前的部分

Status: implemented

关联：[无进展停止](2026-10-08-agent-no-progress-guard-and-soft-cap.md)（同一套收尾：先入账、再以 ERROR 结束）、[流结束时补全未闭合正文](2026-10-05-agent-stream-abort-flushes-file-capture.md)。

## Problem

生产 10-26 02:41（`[audit]` 测试项目，MiniMax 主用）：作者要一篇 8000 字左右的短篇。存下的文件有 61,430 个字符（汉字 44,659 个）：前约一万二千字正常推进，之后一段约 5,012 字逐字重复了 9 遍（相邻两遍相似度 0.999），一直写到 780 秒的单轮时限才被截断，最后半句话没写完。作者下一轮让 AI 删掉重复，AI 读全文就把这一轮的时间用完了，一个字也没改。

这是模型陷入循环，不是正常写长；按字数设上限挡不住它，也会误伤真要写长的作品。

## Decision

- `find_repetition_start`（`core/stream_processor.py`）：文本末尾 800 个字符（`REPEAT_WINDOW_CHARS`）按同一间隔连续出现第三遍时算循环（只出现两遍可能是「修改前 / 修改后」对照或引用）；以上一次出现的位置推出一遍的长度，往前逐字与上一遍对照，截在第二遍开头，保留一遍。只由少数字符组成的片段（不足 30 种非空白字符，例如分隔线）不算。
- runner：一次模型调用的回复文字每多 256 个字符检查一次（`response.created` 时清零）。命中时立即取消这次 run，之后不再转发文字；先发 MESSAGE_END（`stop_reason=repetition_loop`）让用量入账，再发 ERROR（`ERR_AGENT_REPETITION_LOOP`，不可重试），整条工作流结束，不再交接、送审或续写。stream_billing 把 `reason=repetition_loop` 当作失控停止：本轮没有写入成功就退还额度（只在对话里打转的不收费），存下了正文照常计费；`repetition_loop` 加入 `RESUMABLE_STOP_REASONS`，作者回复「继续」时接着上一轮的 agent 做。
- StreamAdapter：收到 `stop_reason=repetition_loop` 的 MESSAGE_END 时，先把正在写的正文截到重复开始之前（`StreamProcessor.trim_repeated_tail`），再按既有的流结束补全规则落库（覆盖保护照旧）。
- 作者看到的说明（中英文，`core/error_codes.py` 与前端 `errors.json`）：AI 开始大段重复，这一轮停下，正文里重复的部分没有保存，回复「继续」接着写。

回归：`tests/test_agent/test_repetition_loop.py`（检测位置不受检查时机影响、分隔线不误判；适配器只存重复之前的正文；真实 SDK run-loop 对本地假模型在第二遍途中截停，以 MESSAGE_END + ERROR 结束）。

## Alternatives considered

- **按要求字数设上限（例如超过三倍就停）**。最强理由：实现最简单，这次能挡住。被否：作者常常不写字数，也会要长篇；字数多不等于失控，失控也可能发生在字数上限以内。
- **只截正文、不停模型**（截到重复处后丢弃剩下的输出直到 `</file>`）。最强理由：不新增停止原因和错误码。被否：循环中的模型不会自己收尾，这一轮会一直等到单轮时限，作者白等十几分钟。
- **第二遍开头就停**（初版做法）。最强理由：停得更早。被否：独立审查用「修改前 / 修改后」对照（中间一千多字未改）复现了误停，正常回复最多把一段写两遍。
- **按相似度（例如 95%）判定重复，覆盖有小改动的循环**。最强理由：更灵敏。被否：相似度计算比子串查找贵得多，且会误判正常的排比、复沓；逐字相同的 800 字已足以在第二遍刚开始时命中（本例每遍只有约 5 个字不同）。

## Consequences

- 收益：模型陷入循环时在第二遍开头就停下，作品里不留重复段落，作者不用白等到单轮时限。
- 代价：截下的正文停在循环开始之前，可能是半句话；作者需要回复「继续」。要等第三遍开头才停，比第二遍就停多写一遍（本例约五千字）。
- 代价：被取消的那次模型调用不经过 on_llm_end，用量不进账本（与其他取消路径一致）。
- 代价：极少数作品如果逐字重复 800 字以上（例如整段引用前文），会被误判截停；这种情况下保存的是重复之前的内容，作者可以继续或调整要求。
