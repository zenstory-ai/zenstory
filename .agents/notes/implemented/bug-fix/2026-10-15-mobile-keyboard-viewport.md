# Agent Note: 移动端输入使用真实可视视口

## Problem

用户的 iPhone Safari 截图显示，聊天输入框聚焦后出现外层滚动条，整块界面被抬高，输入框与键盘间留下大片空白。工作台只跟踪 `visualViewport.height`，没有跟踪 Safari 聚焦时产生的 `offsetTop`。首页、项目列表、素材详情、后台和弹窗同样有固定高度／定位的输入场景；登录注册等长表单则需要保留自然文档滚动。

先补真实页面的合成键盘几何回归：320/390px 聊天、首页创作框、项目搜索、素材搜索、后台搜索、项目切换器、设置与技能编辑弹窗，以及短屏登录／注册／找回密码／验证码页。前五项在修改实现前均失败：聊天的高度变为 400px 但 top 仍是 0；首页、项目列表与素材页仍是 844px 而不是可视的 420px。

## Decision

- React App 统一将可视视口高度与顶部偏移写入 CSS 变量，合并 resize/scroll 事件到动画帧；卸载恢复原值。无 VisualViewport 时使用 window 尺寸。缩放时用 height × scale 消除缩放对布局尺寸的影响、top 归零，平移交给浏览器；键盘识别同样使用归一高度，避免放大时收起键盘后仍保持小窗口与隐藏导航。
- 小于 1024px 的固定页面壳和共享 Modal 采用同一可视视口矩形，覆盖手机横屏，保留 768/1024px 面板断点。仅全屏应用壳存在时锁住 html/body 的外层滚动，正文、聊天、列表与弹窗正文仍独立滚动。自然文档页不套全屏壳。横屏粗指针设备的输入保持 16px，避免聚焦自动放大，非触屏平板宽度的字体不变。
- 项目切换器跟随可视顶部，搜索、列表和创建入口采用可收缩布局；弹窗内容不得高于其可视容器。桌面断点与既有状态、草稿、焦点、额度规则不变。
- 文档搜索抽屉复用可视视口覆盖层，但不套全屏应用壳，关闭后继续正常阅读。文件和文档搜索结果限高同样按可视高度计算。
- 运行组件回归、Chromium/WebKit 几何与自然文档滚动检查、前端 lint/typecheck/build 和 PR 必需 CI，再合并 main。不操作生产分支或发布。

## Alternatives considered

- **只隐藏滚动条。** 改动最小，但只遮住症状，输入框仍可能离开可见区域，拒绝。
- **只用 `dvh`。** 不依赖 JavaScript、适合普通地址栏变化，但软键盘可能仅改变 visual viewport，无法处理其平移，拒绝作为唯一修复。
- **每个输入框聚焦时 scrollTo/scrollIntoView。** 能直接干预当前焦点，但会与 Safari 自动平移、内部列表和正文滚动竞争，还需要遍历所有输入入口，拒绝。
- **全站固定 body。** 容易统一锁滚动，但会破坏登录注册、文档等长页面阅读与表单可达性，拒绝。

## Consequences

新增一处 App 级视口同步与共享 CSS，而不是为每个输入框添加键盘事件。固定壳锁滚动依赖现代浏览器的 `:has()`，与当前 Safari/Chrome 支持面一致；1024px 以上桌面保持原布局。自动化模拟 visual viewport 的缩放与平移，不等于真机系统键盘验证，必须明确保留该验证边界。

进一步回归确认文件搜索结果底边曾到 650px，超过可视底边 520px；文档抽屉仍高 844px 而不是 400px；横屏工作台仍高 390px 而不是 240px；放大后收键盘仍停在 400px/top160 而不是 844px/top0。均先失败后修复。正文与标题键盘变化／面板切换保留输入，登录、注册、找回密码和验证码页保留自然滚动，不发送表单、不调用模型。最终浏览器与 CI 结果随 PR 记录。

## Verification

- 新增键盘回归 17 场景 × Chromium/WebKit，共 34 项全部通过；包含 320/390px、844px 横屏、放大后收键盘和草稿保留，实际查看聊天可视区域与技能编辑弹窗截图。
- 全量前端单测 297 文件、4677 项通过（1 skipped）；最终视口／Layout 受影响单测另跑 44 项通过，其中视口 hook 为 5 项。站点生成器 68 项通过；完整 ESLint、token/i18n 检查、TypeScript 和构建通过，保留既有 lint 警告和 chunk 体积提示。
- 扩展响应式浏览器检查 108/114 通过；失败的 6 项分别是 macOS Chromium 768px 搜索框宽 199px、旧断言要求 200px，以及 WebKit 桌面／平板空输入框占位符 scrollHeight 断言。另建干净 `5252125b` worktree 在相同浏览器重跑，全部复现（基线额外还有一项同类 WebKit 失败）。不削弱旧断言，不把它们说成本批回归或本批已修复。
- 独立代码审查通过，未发现剩余阻断项。PR 精确源 CI 是合并门禁；生产发布不在本次授权范围。
