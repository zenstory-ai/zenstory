# Agent Note: 根图标与按语言加载，减少 CDN 请求

关联：[静态文件缓存头与 README logo](2026-10-29-cdn-request-caching.md)。本条延续旧客户端静态缓存兼容，并重新选择此前暂缓的按语言合并加载方案。

## Problem

2026-11-03 的滚动十二小时只读请求明细样本共 16,983 次：`/favicon.ico` 6,213 次（36.6%），`/assets/*` 3,247 次（19.1%），`/locales/*` 2,367 次（13.9%），`/version.json` 647 次（3.8%）。组织站根 ICO 实测返回 404、`max-age=0`；App 根 ICO 被 SPA 兜底为 HTML。图标请求多带 Edge 标识，但来源身份和触发机制未知，不据此封禁浏览器或住宅网络。

10 月 29 日的浏览器缓存已生效，但冷启动仍逐 namespace 拉取翻译；英文同时加载中文回退。版本定时检查为三十分钟，切回页面和恢复联网仍可每分钟请求一次。

## Decision

- 从已有 `public/favicon.svg` 转换真实多尺寸 ICO，静态根目录保留它；`/favicon.ico` 浏览器缓存七天，不使用未版本化 URL 的 immutable 承诺。SVG 入口不变。
- Vite virtual module 插件在构建时读取原有公开翻译 JSON，生成按语言划分的懒加载模块；i18next 同语言并发读取共用一次加载，加载失败清除 Promise 缓存并保留默认有界重试和显式 reload。保留 namespace、中文回退、语言检测、Suspense 和原 `public/locales` 文件与 URL，供旧客户端和既有工具继续使用。删除被替代的 HTTP backend 依赖和旧的翻译目录整体版本计算。
- 自动更新检查在成功比较后的三十分钟内不重复；失败仍保留一分钟间隔，显式检查和既有 chunk 恢复、草稿保护流程保持原有行为。`version.json` 继续重新验证。
- 不增加依赖，不修改云防火墙或生产部署。

## Alternatives considered

- **仅继续延长翻译 HTTP 缓存。** 改动少，回访有效；无法减少冷启动逐 namespace 请求，已有一年缓存后没有同等收益。
- **按页面逐个懒加载 namespace。** 可缩小首次载荷；会扩大 Suspense、回退和路由加载时机的改动，本批保留原预加载范围，先合并请求。
- **根 ICO 使用一年 immutable。** 回访省请求最多；稳定 URL 可能原地更换，选择有限七天缓存，接受图标更新最多延迟七天。
- **封禁 Edge 或来源 IP。** 可能立刻降低计数；不能证明这批是恶意客户端，且分散 IP 封禁容易误伤，本批不采用。
- **所有更新检查直接改为三十分钟节流。** 实现最短；会延长临时网络失败后的恢复，区分成功和失败间隔。

## Consequences

图标请求得到可缓存的有效图像；应用冷启动翻译请求目标为中文一个、英文含回退最多两个。首次图标请求和不遵守缓存的客户端仍计费，不把路径占比当作保证节省比例。按语言整包加载保留 namespace 结构，单个翻译修改将更新该语言模块哈希。自动更新提示可能更晚出现，旧 chunk 失败与未保存草稿保护仍由现有恢复流程处理。实际 CDN 用量变化须在授权发布后观察，不能用本地构建和测试代替生产收益证明。

本地验证：前端 318 个测试文件、5,092 项通过（1 项原有跳过），站点生成器 83 项通过；ESLint 零错误、2 条既有警告，token/i18n-key 检查和 `build:typecheck` 通过，随后完成 Vercel 域名布局生成。生产构建浏览器实测中文 1 个语言 chunk、英文 2 个，namespace HTTP 请求为零，来回切换语言复用已有模块；模拟一次语言 chunk 网络失败后由既有恢复流程恢复。两域名布局根 ICO 为 5,412 字节真实图标，本地响应 200 和七天缓存。此处域名响应为本地成品路由验证，未声称已在 Vercel 生产生效。
