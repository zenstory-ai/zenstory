# Agent Note: 文章去生硬词、/projects 文案、子页面统一设计语言、首页记住语言

Status: implemented（承接 [home-carousel-dedupe-and-skill-guides](2026-10-10-home-carousel-dedupe-and-skill-guides.md)；四项均由用户 2026-10-10 提出）

## Problem

- 用户指出指南文章里有生硬、自造的说法，例如“去AI味怎么改：三遍改稿与删改刹车”。全站扫下来同类问题很多：自造标签（删改刹车、局部结果、知情范围、执行边界）、工具内部用语进了读者正文（落盘、产物、门禁、回填、口径、签认、降级）、名词堆叠的翻译腔标题，英文里也有 “deletion brakes”“local outcome”“knowledge scope” 这类自造词。
- /projects 首屏说明和项目卡读起来像规格说明，卡片文字过密。
- /projects、/guides 等子页面沿用旧的衬线标题、方角卡片和独立配色，和首页（Geist、圆角卡、青色星标 eyebrow）像两个站。
- 英文 `/` 与中文 `/zh` 是两个 URL，中文读者每次从 `zenstory.ai` 进来都落在英文首页。

## Decision

- **去生硬词**：先按页面可见字段（title、seo_title、description、answer、小标题）分五组由子代理提候选，再由一个子代理对正文按词条给规则（每个词什么时候保留、换成什么）并列出逐处修改；所有候选人工审读后应用。可见字段 1138 条候选中采用 1125 条，否决 13 条（会改变原意或与 skill 自身术语冲突的，如“关系条件”“记账式的冷”“资产边界”，以及新文章沿用 skill 原词的“内置知识”“传播引擎”“安静窗口/融合时间线”），4 条改写后采用（如宫斗标题改为“规矩、证据与裁决怎样你来我往”）。正文 281 处按规则替换，另手改 36 处残留（FAQ 问题、一个小标题、来源链接文字与可复制的 skill 提示）。故事内真实用法保留：门禁记录、刹车线、契约婚姻、宫斗里的裁决、“不知情”等。统一用词：局部结果→阶段性结果、知情范围→人物所知/谁知道什么、结构义的交接→承接、配额→硬指标/凑数、产物→生成的文件/结果、动作链→连续动作。共改 349 篇文章与全部 17 个工作流指南，其中 42 个标题；`llms.txt` 同步 36 条标题/摘要。这是表述修改，不刷新 `updated_on`/`checked_on`；章节锚点来自内容 id，不受小标题改动影响。
- **/projects 文案**：H1 改为“写网文、改短剧、做游戏、剪解说：六个开源项目”，组织简介按“用 Agent 写 → 改编 → 剪辑 → 不装 Agent 用网页版”的顺序重写，六个项目 tagline 改成说清在哪用、能做什么的一句话；卡片只留标题、一句话和一行 `格式 · N 个 skill · ★star`。
- **统一设计语言**：`org-pages.css` 的根变量换成首页调色板（亮/暗），全站用 Geist + Geist Mono、16px 卡片/12px 框圆角、无下划线 h2、药丸形页头、带青色星标的等宽 eyebrow、48px 按钮；子页面 hero 去掉底色块。首页自己的 eyebrow 不加星标。
- **首页记住语言**：页头语言切换被点击时写 `zs_lang` cookie（一年、仅本主机、https 下 secure）。`build-site-layout.mjs` 生成两条只在组织站主机上生效的临时重定向：cookie 为 zh 时 `/`→`/zh`，为 en 时 `/zh`→`/`。其他 URL 不跳转，不按 Accept-Language 猜。

## Alternatives considered

- **只改用户点名的“删改刹车”**：最强理由是改动面小、GEO 风险低。没有采用：同类词遍布数百篇，用户要的是一批找出来改掉；GEO diff 确认链接、canonical/hreflang 全部不变。
- **把术语表里的 skill 原词也一并口语化**：最强理由是全站说法最统一。没有采用：读者装上 skill 后会在其输出里看到原词（内置知识、传播引擎、安静窗口），文章与工具对不上更糊涂。
- **按 Accept-Language 自动跳转首页**：最强理由是首次访问也能落到中文。没有采用：会让爬虫和分享链接看到不确定的页面，与“一 URL 一语言、x-default 英文”的设定冲突；只认用户亲手选过的语言。
- **用 localStorage + 前端跳转记住语言**：最强理由是无需改 Vercel 配置。没有采用：页面先渲染再跳会闪一下，且 DESIGN 约定语言不依赖脚本；cookie 让边缘直接 307。
- **子页面保留衬线标题作为“文档感”**：没有采用：用户明确要求子页面与首页设计语言统一。

## Consequences

- 349 篇文章、17 个指南的标题/摘要/正文措辞变化，搜索结果摘要会随重新抓取更新；URL、日期、结构化数据类型与内链不变。
- 选过中文的访客再打开 `zenstory.ai` 会被 307 到 `/zh`；清 cookie 或点切换回英文即可。爬虫不带 cookie，不受影响。
- 子页面观感与首页一致；以后新增子页面组件应复用站点级 `.eyebrow`、`.btn`、卡片圆角变量。
