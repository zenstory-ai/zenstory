# Agent Note: 按创作任务组织指南，合并重复与薄文章

Status: implemented

## Problem

线上首页和指南索引平铺 1,061 篇内容。批次后段大量文章仅三段通用建议，重复同一主题，并使用项目名充当不存在的 skill 目录。作者难以找出能解决当前问题的文章。用户要求全部审查、修订，并明确拒绝冷门、自造术语选题。

## Decision

保留有具体方法、原创案例和 skill knowhow 的文章；常用且欠缺的已有题目重写为完整教程；同题薄页合并，缺乏对应 knowhow 的扩展题目撤下。逐 URL 的处理记录存 CSV；只有同一读者问题才做永久跳转，不相关页面保持真实 404。首页只列精选与任务入口。指南索引提供任务分类、学习路径及渐进增强搜索；分类为独立静态双语路由。每篇加入分类、已核实存在的固定版本 skill 文件链接与方法来源。分类页每页 24 篇，搜索可恢复 URL 中的关键词。

后续批次先查已发布目录和首轮处置记录，再读对应方法。常见但原稿薄的题目在原 URL 重写恢复；同题旧 URL 合并到恢复的主篇，已有完整指南不另换说法新增。人物背景、配角、对白提示语与不可靠叙述者采用此恢复方式；AI 写作简报、场景一致性、口型与闪帧修复新增完整双语文章。每篇提供按题填写的例子和修订办法，模型输出相关方法保留实际检查步骤，不把提示词写成生成效果保证。批次逐篇问题、来源与 URL 处置记录放在 `docs/content/2026-09-29-quality-batch-02.csv`。

结构类补充在原 URL 重写三幕结构、剧情因果与主题表达，提供同一原创图书馆故事在三个不同写作问题上的具体用法；主题寻找与表达合并为一篇，另一旧 URL 永久跳转。三幕按功能与转折组织，不把字数比例写成硬规则；因果检查区分于事实一致性检查；主题通过选择和后果呈现。逐篇来源和区别记录在 `docs/content/2026-09-29-quality-batch-03.csv`。

## Alternatives considered

- 保留全部内容，只加项目筛选：能保持旧索引数量，但不解决重复、薄页与无效 skill 来源，因此不采用。
- 全部旧页重定向到项目首页：配置简单，但对应不了读者问题；只合并同题，其余撤下。

## Consequences

作者按当前任务选择，常用方法优先；文章数量减少，分类和来源需要随内容维护。已有外链指向撤下的非同题页面会得到 404。原稿可从 Git 基线 91a0bc5 恢复。

用户后续明确提出 2000 篇目标，独立文章按内容条目计数，不以双语 URL 翻倍。首轮为 170 篇；全库 1061 条记录包含 156 条修订、14 条重写、43 条同题合并和 848 条撤下。持续补充的编辑规则见 `docs/content/README.md`。
