# 订阅页：聚焦一个 Pro 购买决策

Status: implemented — 订阅页本地实现已完成；价格、权益和支付规则不变，未部署。

## Problem

用户认为[上一版](../../proposed/feature/2026-10-17-subscription-page-hierarchy.md)不够简洁，也缺乏付费吸引力，要求邀请商业化 PM 优化；随后明确兑换码入口应弱化，避免用户围绕找码而不是产品价值决策。

商业化 PM agent 已评审原型与现有页面：只有一个可购买的 Pro，却用两张同权重大卡让用户选方案；管理信息、兑换按钮和付费动作竞争；强调折算月价又让用户在结算前重新理解实际总额。上述判断是设计评审，不是实测转化结论。套餐与支付事实复用上一提案的仓库和只读目录证据。

## Decision

1. 免费用户只展示一个 Pro 购买卡，前面用一句具体价值表达：少被额度打断，按自己的节奏写下去。免费身份和剩余消息为弱状态行，不再占用套餐卡。
2. 重点解释三项真实变化：AI 消息每天 3 条到不限条数、项目 3 个到不限、素材拆解每月 5 次。自定义技能 20 个、每文件历史版本 100 个退到短行和详细权益；实际展示全部取目录，不新增产出、模型或质量保证。
3. 周期放卡内，年付默认。主价格为实际支付 ¥399／365 天，辅以折合 ¥33.25／月及比 12 次月付省 ¥189；月付 ¥49／30 天。主按钮同步实际金额，附近保留「支付宝一次性付款，不自动续费」。
4. 兑换入口从购买卡附近完全移除。放到所有权益、规则和用量折叠项之后的页尾「帮助与支持」，默认关闭；展开后为「使用兑换码」普通文字入口，并复用既有兑换流程。正常可读、键盘可操作，不用低对比或不可见样式隐藏。购买区不放码输入框、优惠暗示或找码引导。
5. 保留低强调的「继续免费创作」，不以隐藏免费路径换取点击。完整权益、价格与使用说明、当前用量为次级折叠内容。支付不可用时维持真实状态说明与兑换可达性，不伪造可支付按钮。
6. 已付费用户优先到期、续费与可见用量，不展示免费账户的购买卡；兑换仍位于页尾帮助。本轮不扩套餐。

原型：`.omx/design/subscription-commercial-v2/index.html`。桌面、390px 手机和帮助展开截图由同一份 HTML 生成；浏览器校验脚本为同目录 `capture.cjs`。仅模拟交互，不请求 API，不创建订单、不兑换权益。效果图是浅色设计，不代表真实结算或深色主题验收。

按用户要求，设计完成后由 UI/UX agent 再做一轮原型打磨：提高次要文字字号和对比度、收紧手机端留白、强化价格与 CTA 层级、主按钮提升至 48px，同时保持兑换入口的折叠位置。已运行并通过独立浏览器检查：390×844 首屏包含购买按钮与付款说明；320／390／768px 无横向溢出；月年金额、期限与 CTA 一致；兑换默认不可见，展开后键盘可触发；无浏览器错误或 HTTP 请求。未执行真实支付／兑换、服务端权益、深色主题或转化效果验证。

## Alternatives considered

- **继续对称免费／Pro 大卡。** 比较差异最直观，适合公开定价页；但已登录免费用户已经处于免费方案，本页应回答是否升级，因此免费权益移入展开对照。
- **折算月价最大。** 降低年付的心理门槛，适合长期成本比较；但不是实际扣款额，容易产生结算落差。改为总额优先，保留折算和节省信息。
- **兑换码放购买按钮旁。** 持码用户最容易发现，步骤少；但会提示普通用户先找优惠码。按用户最新偏好移到页尾帮助中，不删除入口或降低可访问性。
- **彻底删除兑换入口。** 购买区最干净，但会让持码用户和支付不可用场景失去既有路径；选择渐进披露。

## Consequences

预期减少并列选择与优惠干扰，让价值、实际价格和付费动作成为连续决策。代价是持码用户多一次展开操作；目前没有数据证明收入或转化提升。实现已覆盖支付启用／关闭／请求失败、目录缺失／失败、月年选择传递与归因、免费／Pro、双语及浅深主题回归；未做真实付款或线上验收。


实现文件：`BillingPage.tsx` 负责账户状态、查询和既有结算入口；`BillingProOffer.tsx` 只负责目录驱动的购买展示。保留免费用户当前用量入口与错误重试；已付费管理直接显示真实用量。支付弹窗同步按目录生成 AI／项目／素材权益摘要，字段缺失不再回退承诺「不限」；当前 AI 额度不限时不展示每日恢复说明。

验证：相关组件、查询与支付回归；Chromium 真实页面、mock API 下的 390px 首屏、320／390／768／1440px 边界、深浅主题、英文购买和管理员发布／关闭／新版重现／停用流程。前后图 `.omx/design/development-comparison/`；截图使用同一合成账户和目录，不是转化或真实结算证明。
