# Agent Note: Open Graph 图片使用 1200×630 PNG 卡片，是 GEO diff 唯一放行的元数据变更

Status: implemented

## Problem

社交与聊天工具在展开链接时读取 `og:image`。组织页面原本把 32px 的品牌 SVG 标记当预览图，多数平台要么不渲染 SVG，要么把它放大成模糊的小图标，链接卡片看起来像没有配图。同时，站点重设计的硬规则是"元数据零变化"，任何 `og:*` 改动都会被 GEO diff 判为回归。

## Decision

所有静态页面的 `og:image` 指向 `public/brand/og-zenstory-ai.png`，1200×630 的 PNG 卡片，由 `site-shell.mjs` 统一写入 head。这是重设计相对旧页面唯一有意的元数据变化，GEO diff 的允许清单明确放行 `og:image`，其余 title、description、canonical、JSON-LD 节点 must 与基线一致。品牌标记 `zenstory-ai-mark.svg` 继续用于页面内 logo 与 favicon，never 作为社交预览图。

来源：2685721 (#58)

## Alternatives considered

- **沿用 32px SVG 标记作为 `og:image`**（重设计所替换的做法）。最强理由：零元数据变化，GEO diff 天然零差异，也不需要新增二进制资源。被否：平台不渲染或渲染成模糊小图，等于没有预览图；为了保住"零差异"而保留一张无效图片本末倒置。

## Consequences

- 收益：链接卡片有可辨认的品牌配图；变化范围被限定为一个字段，GEO diff 仍然是"其余全部零差异"。
- 代价：多了一个 1200×630 的二进制文件，品牌更新时要同步重做；未来任何再想改 `og:*` 的人 must 先扩展 GEO diff 的允许清单并在 DESIGN.md 记录，否则 diff 会红。门禁细节见 [site-generator-change-gates](../process/2026-09-12-site-generator-change-gates.md)。
