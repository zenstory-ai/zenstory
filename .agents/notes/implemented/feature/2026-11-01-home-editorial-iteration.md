# 组织站首页纸墨编辑式迭代

Status: implemented locally for owner review; not merged or deployed.

## Problem

用户对照 Zen Browser 指出组织站首页质感差距，随后明确要求在新 git worktree 制作可预览版本。实际中英桌面/手机截图显示：原著、规则卡、游戏与悟空立绘争夺首屏注意力，后续连续目录结构较重。现有真实来源与多项目组织定位必须保留。

## Decision

- 独立 worktree `zenstory-home-editorial-20261101`，分支 `feat/org-home-editorial-20261101`，从 `f1e543be` 开始；不合并、推送或部署。
- 首屏以“故事，不只一种形态 / Stories take more than one form”为主张，系统衬线展示字搭配现有 Geist 正文，保留纸墨/青色，不增加依赖或外部字体下载。
- 只展示现有《西游记》真实 QA 图片，去掉浮动立绘、伪浏览器栏、编号与文档叠层。原著、规则、原文和固定提交来源保留在紧邻图说的原生 details 中。
- 本次替代 [原首屏舞台](2026-10-03-homepage-manuscript-to-world.md) 的“完整案例塞进首屏”目标：现在要求真实画面在 1440×900 和 390×844 首屏开始，而不是所有证据同时完整出现。
- 案例区改纸色画廊，统一奶油色衬框；写作演示为主，三个不同媒介案例为辅。视频内容、原生控制、点击播放、不自动下载、直达来源不变。
- 三条路径仍可直接操作，改编分支不再重复展示已出现的案例图片。六个项目保持直接可见，详细知识链接收进四个原生展开区，目的说明、搜索与完整知识库入口保持可见。组织内页、工作台、计费和云配置不在范围。

## Alternatives considered

- **复制 Zen Browser 的字体和古典画背景**：能最快接近参考气质。但会失去自身资产、中文排版与组织定位，故只借鉴主次、留白与连续性。
- **工具与知识库全部折叠**：能显著缩短页面。但重要能力过度隐藏，路径到工具的锚点也更复杂；故六个工具保持可见，只渐进展示详细知识和证据。
- **给现有舞台加动画**：能增加动势。但未解决多个视觉主角，且增加脚本/加载负担；本轮不加自动播放、滚动显隐或动画依赖。

## Consequences

首屏更聚焦，页面不再承诺第一屏讲完案例。来源需要一次展开，但无需 JavaScript；新增静态内容保护与无脚本键盘展开回归。系统衬线的字形会因操作系统略有差异。视觉结论等待用户预览，本地测试通过不等于用户审美认可或发布授权。

- 原基线 24 项首页测试通过；新增原生证据/知识展开静态保护先红后绿。展开状态额外检测发现标题跳级，加入浏览器回归后将规则标题改为正文强调，避免首个 h2 之前出现 h3。
