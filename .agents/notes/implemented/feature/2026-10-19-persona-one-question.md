# 画像页只问一个问题，一点就进工作台

Status: implemented

第二批引导改动之一，整体方案见 `proposed/feature/2026-10-19-onboarding-to-first-message.md`。

## Problem

新用户注册、验证邮箱后，会被强制带到画像页。旧画像页要做三个决定：

- 7 类创作者，最多选 3 个；
- 5 个目标，可多选；
- 3 档经验。

「跳过」在页底，选完还要再点「保存并进入工作台」。默认配置下，这些答案几乎只用来决定工作台默认打开哪种作品类型（`serial` / `short_story` / `screenwriter` 三项）。

2026-10-19 的走查里，手机上赶时间的短剧编剧最可能在这一页流失。车主要求整体不能太长、太复杂，用户没有耐心。

## Decision

**页面**

- 只问一个问题：「你想写什么？」，选项是长篇连载、短篇小说、短剧剧本，每个选项带一句说明。
- 点一下就保存，直接进入工作台，没有单独的提交按钮。
- 每个选项右侧有一个箭头，表示点了就进入；副标题是「点一个就开始，之后随时能换。」，跳过按钮写作「先跳过」。这是 2026-10-19 看过截图后改的，原文案偏生硬，手机上副标题还会单字折行。
- 「跳过」放在标题右侧。
- 删除创作者、目标、经验三组题，以及只在默认关闭的开关下才显示的推荐预览。
- 文案 `onboarding.json` 只保留 `start.*`、`hero.restore`、`actions.skip` 和 `errors.*`。

**保存**

- 后端接口不变，答案按原来的映射存成身份：长篇 → `serial`，短篇 → `short_story`，短剧 → `screenwriter`。
- 以前存下的其他身份、目标和经验保留，作者重新作答时一起提交，身份最多 3 个。
- 页面不再展示的题，作者从没答过经验时不发送，由服务端给默认值。
- 旧服务端不认新身份时，仍按原逻辑退一次重试。

**作品类型偏好**

- 点了哪个类型，就把它设为工作台的默认类型（`setPreferredProjectType`）。
- 落地页选过的类型只用来高亮对应选项。以前的做法是保留落地页的选择、不覆盖；现在这一页问的就是「写什么」，作者在这里点的才是最新、最明确的选择。
- 这一条修订了 `bug-fix/2026-10-14-first-work-preference-account-scope.md` 中「明确入口选择优先于身份推断」的前提：画像页的选择不再是由身份推断出来的类型，而是作者明确点的类型。该记录里的账号隔离规则不变：A 的偏好不会带给 B，匿名公开入口只领取一次。作者跳过这一题时，仍沿用公开入口或该账号已有的类型记忆。`FirstWork.preferenceAccount.test.tsx` 按这条规则改写。

**其他**

- 「已带入你上次的选择」只在以前选过类型时显示。
- 服务端答案返回后，仍会同步到本机缓存，其他页面要读。
- 埋点 `persona_submitted` 改为带 `skipped` 和 `project_type`。

**没做**：原方案里的「我手上已有稿子」勾选。导入入口已经放进工作台、编辑器和聊天起手卡，作者带着稿子来，在那里一点就能导入，这一页不再多加一个决定。

## Alternatives considered

- **按原方案保留勾选「我手上已有稿子」**
  - 最强论据：提前知道作者带了稿子，起手卡可以把「看看我的稿子」排到第一个。
  - 不选的原因：多一个控件，就得有单独的提交按钮，失去「一点就走」。作品里有没有正文，可以直接从项目进度读到，信号更准。
- **把画像页挪到第一条消息之后，或者整页删掉**
  - 最强论据：注册后直接进工作台，最短。
  - 不选的原因：首部作品初始化要等画像完成或跳过（`first_work_service.py`），新用户强制跳转也依赖这条记录。缩成一题、一点就走，成本接近于零，改动面也小得多。
- **保留多选身份，只删目标和经验**
  - 最强论据：身份数据更细。
  - 不选的原因：默认配置下，只有三种类型身份有用途，其余只用于默认关闭的推荐，不值得让每个新用户多做选择。

## Consequences

**收益**

- 新用户在画像页只需点一下。
- 进入工作台后，默认打开的就是作者自己点的类型。

**代价**

- 新注册用户不再提供目标、经验和其他身份。后台画像分布与默认关闭的推荐面板只能用到老数据。
- 旧版 e2e 里的多选、上限和预览场景已删除。

**测试**

- 单元测试：`OnboardingPersonaPage.test.tsx`、`.hydration.test.tsx`、`.continuation.test.tsx` 改写，覆盖：
  - 一点保存并跳转；
  - 保留旧的身份、目标和经验；
  - 落地页类型高亮；
  - 跳过；
  - 失败后可以重试；
  - 连点只保存一次；
  - 旧服务端回退；
  - 服务端答案同步到本机。
- e2e：`onboarding-persona.spec.ts`、`app-layout-details-mocked.spec.ts`、`responsive-pages-mocked.spec.ts` 跟随新页面更新。
