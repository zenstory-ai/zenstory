# Agent Note: 首页窄屏锚点、免安装入口与改编分支卡

Status: implemented（同批的官网进应用交接见 [org-site-app-handoff](2026-10-09-org-site-app-handoff.md)）

## Problem

2026-10-09 对 zenstory.ai 首页做 1440 / 390 / 375 / 360 宽度与暗色走查：

- 360–375px 时页头的品牌、语言切换和“打开工作台”放不下一行，折成三行（134px），而 `--top-h` 仍是 94px。首屏主按钮“选一条创作路径”和所有页内锚点跳过去后，标题被吸顶页头盖住一半。360px 是国内安卓最常见的宽度。
- “只有一个想法”路径三步都教 Agent skill 包，网页工作台只是“或 ZenStory 工作台”一个跳到表格行的小链接；手机上的网文作者装不了 Agent，没有能马上做的一步。
- “已经有小说”大卡跨两行，两张改编分支卡被 `flex:1` 拉到约 374px 高，里面只有一行标题和工具名，是桌面首页最显眼的空白；暗色模式下这张纸色卡更扎眼。
- 展示区末尾“看看从哪里开始 ↓”独占深蓝带底部一行小字，像漏了内容。
- 英文知识库标题 “A knowledge library, not a link dump” 是防御式写法，中文标题已经说清楚这一节做什么。

## Decision

- **窄屏页头**：≤400px 收紧行间距、品牌间距、工具间距与语言切换内边距，“打开工作台”去掉装饰箭头，360px 起页头保持两行 94px；<360px 时控件仍会折到第三行，`--top-h` 改为 134px 与之对应。`geo-domain-smoke.spec.ts` 新增 360px 中英文首页用例：页头 ≤96px，点主按钮后 `#start-h` 在页头下方。
- **免安装入口**：路径的起步工具含 `workbench` 时，卡片底部多一个直达注册的按钮（“不装 Agent，在浏览器里直接开写 ↗”，`source=org_home_path`）；目前只有路径 01 满足。改编与解说路径不出现，因为工作台不做这两件事。“起步工具”链接仍指向工具表行（10-03 决策未变）。
- **改编分支卡**：每张分支卡显示该工具在展示区的第一个案例媒体（短剧用竖屏 poster，游戏用 RPG 大地图截图，均为已在 `public/org/demos` 的本地文件），`alt=""`、懒加载；媒体 `flex:1` 吃掉多余高度，手机上最小 104px。
- **展示区到路径的过渡**：保留 10-03 决定的那条下一步，改为虚线故事线中间的胶囊按钮。
- **英文标题**：改为 “From first steps to fixes, layer by layer”，与中文“从上手到排错，按层次找到方法”同义。

## Alternatives considered

- **窄屏隐藏 “ZenStory AI” 字标**：最强理由是一次就能省出最多宽度，320px 也能保持两行。没有采用：品牌字标是页头唯一的文字身份，DESIGN 也要求不靠隐藏文字来腾空间；去掉装饰箭头与收紧间距已覆盖 360px 以上。
- **用脚本量页头高度写进 `--top-h`**：最强理由是任何折行都精确。没有采用：官网约定不依赖脚本完成阅读和导航，CSS 两档已覆盖实际宽度。
- **分支卡不拉伸，让大卡底部留白**：最强理由是改动最小。没有采用：空白只是从卡内挪到卡底，而首页原则是先看到真实成果，分支本身就是在两个成果之间选。
- **手机端展示区横滑或折叠以缩短 3300px 长度**：最强理由是手机上要滑四屏多才到路径区。本批没有做：DESIGN 规定除代码与表格外不横向滚动、不用 CSS 隐藏文字，改动需要另行决定；压缩间距只能省约 4%，不值得。
- **首屏图说挤进 1440×900**：图说底边在 917px。没有做：真实浏览器在 1440×900 屏幕上可视高度约 790px，压缩 hero 留白也露不出来。
- **首屏大图提供 800px 小图**：没有做：主流手机 DPR ≥2.75，按 `sizes` 计算仍会选 1200px 原图，收益接近于零。

## Consequences

- 360px 以上手机页头两行，锚点落在页头下方；<360px 页头三行，锚点按三行留位。≤400px 的“打开工作台”没有箭头。
- 想法路径多一个出站按钮，链接带 `lang` 与 `source`；首页多加载一张已存在的短剧 poster（98 KB，懒加载，位于首屏之外）。
- GEO diff（main 与本分支各自全量生成 975 页）：标题、描述、canonical、hreflang、JSON-LD 零变化；链接变化只有应用入口改址与首页新增入口；文本变化只有新按钮与英文知识库标题。

## Verification

- `node --test apps/web/scripts/__tests__/*.test.mjs` 通过；新增断言：想法路径恰有一个直达注册入口且其他路径没有、两张分支卡都有本地展示媒体。
- 360px 用例对本地构建（系统 Chrome）通过；把 `org-pages.css` 换回 main 版本时失败（页头 134px）。
- 本地预览 1440 / 390 / 360 / 320 宽度、亮暗两种配色截图检查：分支卡、胶囊按钮、免安装入口显示正常，无横向溢出。
