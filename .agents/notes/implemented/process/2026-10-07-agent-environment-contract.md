# Agent Note: 精简代理说明并统一环境与巡检边界

Status: implemented

## Problem

根 CLAUDE.md 重复列举组件与路由，并错误声明没有自动测试；隔离测试环境、正式晋级和三天巡检的权限缺少共同入口。用户要求精简说明，并明确环境规范。

## Decision

AGENTS.md 成为项目级共同操作规范，CLAUDE.md 只保留入口与专属架构文档链接。保留决策记录、DESIGN.md、数据完整性和有意义验证要求。环境详情复用 docs/ops/release-ci-cd.md；三天巡检仅更新 GEO 和汇报，不改产品、不部署。本批仅测试环境验证正文恢复和上传对象存储，正式版本维持现状。

清理按单次文档编辑进行：先检查实际 CI、命令、云环境基线与原决策记录约定，再精简重复和过时叙述；独立只读审查核对最后合同。文档变更不引入产品行为，无需镜像实现的测试。

## Alternatives considered

- 在两个文件重复完整规范：每个代理可独立读取；但重复内容容易出现不同发布边界，因此 CLAUDE.md 明确要求先读 AGENTS.md。
- 保留旧说明并只追加环境章节：改动小；但错误的无测试声明与组件目录仍会误导操作，因此移除可从代码检索的目录。

## Consequences

收益是统一发布边界和可执行验证入口；代价是代理需要按链接读取专项架构或运维细节。历史操作收据保存在 GEO，不用过时部署状态占据长期合同。
