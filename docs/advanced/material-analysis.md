# 素材深度分析：从参考原文到自己的场景

> 仓库文档快照（2026-09-13）。[当前官网指南](https://zenstory.ai/docs/advanced/material-analysis)以网页工作台文档为准；本页正文复用[此版本的官网内容源](https://github.com/zenstory-ai/zenstory/blob/1773af4781996363496f47268cce0e7c640108c8/apps/web/docs/advanced/material-analysis.md)，保留可在仓库中直接阅读的说明与示例。此日期只说明本页所用版本，不表示其他仓库文档已同步。

素材分析最有用的结果，不是一长串“果断、温柔、反转”标签，而是一个可以解释的创作选择：**人物原来想做什么，哪条信息让他改变做法，改变以后仍要付出什么。** 在 ZenStory 工作台，可以先查看素材拆解，再把选定条目或原文片段带入对话，服务于自己的写作问题。

本文用原创录音片段演示阅读，再把其中一种写作方法用于遥控小车练习场景。两段都是为教程编写的虚构例子，不是上传记录、AI 分析结果或实际生成正文。

## 1. 带着问题看结果，不把分类当结论

先选一个问题，例如“怎样写人物改变目标，而不是突然说一段道理？”不要一开始就要求“分析全书所有优点，并帮我写一本类似的”。如果只读过一段，就把结论限定为这一段；要判断长篇人物弧，仍需读取相应的前后文。

素材库上传、任务状态与查看入口见[素材库入门](../user-guide/materials.md)。实际结果可能提供以下线索；字段存在不代表每章都已完整提取，也不代表分析正确。

| 可查看的内容 | 适合追问什么 | 不能仅凭它断言什么 |
|---|---|---|
| 章节摘要、情节点与原文 | 哪个动作使局面变化？摘要漏掉了什么？ | 摘要包含全部伏笔，没提到的事就没发生 |
| 人物名称、别名、描述等 | 性格判断落在哪个具体选择上？ | 一个标签能解释人物一生的动机 |
| 剧情、故事或故事线及关联章节 | 目标、阻力、选择、后果怎样连接？ | 情节点数量越多越精彩，章节跨度就是阅读节奏 |
| 世界观、特殊能力及其演化信息 | 哪条限制真正挡住了行动？改变它会改变哪一步？ | 每个故事都需要等级体系，缺失字段等于没有限制 |

原文是核对推断的依据，分析条目是导航。关系与时间线也不要被想象成所有材料都具备的完整可视化图谱。遇到空项、概括不清或任务错误，先确认实际读到了什么，再决定补读范围。

## 2. 原创参考：同一声杂音，为什么改变了决定？

**参考片段《错过的独奏》：**

> 方遥把旧演出录音剪到第三遍，母亲的独奏有一处仍被一声椅响盖住。今晚是她为母亲办的小型听音会，节目单上写着“她最好的演奏”。朋友建议删掉椅响，接上后面重复的同一小节。
>
> 方遥把两处来回放。后面的速度快了一点。椅响之后，母亲在麦克风旁轻声说：“别急，等他坐稳。”
>
> 方遥撤掉了拼接。她划掉节目单那行字，改写“那天，她停了一下”，把椅响前的两秒也留进去了。

先写三种不同性质的阅读笔记：

| 层次 | 本段可写的笔记 |
|---|---|
| 原文明示 | 节目单写着“她最好的演奏”；方遥反复剪辑并一度采用朋友建议的拼接；两个位置的速度不同；母亲说等人坐稳；方遥撤销拼接并改节目单。 |
| 有依据的解读 | 节目单与剪辑行为支持“方遥起初以呈现最佳演奏为目标”的判断。杂音原先是要去掉的瑕疵，随后的话让那次停顿有了新的意义。她改了呈现母亲的标准，而不是修好了录音。 |
| 这段没有证明 | 母亲已经去世、方遥走出了悲伤、听众喜欢成品、母亲一生总是牺牲自己，或拼接在技术上绝不可能。 |

“母亲很温柔”可以是阅读印象，但它不能替代上面的因果过程。**椅响没有消失，被盖住的乐句并没有恢复，听音会的反应也没有写出来。** 新选择没有让旧代价自动归零。

可以这样要求分析，直接引用片段，或附加对应素材条目并给出原文：

```text
只讨论我提供的《错过的独奏》片段，不推断整部作品。
列出：方遥起初的目标、促成改变的原文、她实际做的选择、仍未解决的代价。
每个解读附上短引文；把“原文事实”“解读”“需要更多上下文”分开。
不要给人物补生平，不续写听音会，也不要修改项目文件。
最后用一句不包含录音、椅子或节目单的描述，概括这次选择的作用。
```

示范概括：**一条具体信息改变了人物对“做好这件事”的理解，他改换行动，但仍承担放弃原目标的代价。** 这是一种可讨论的写法，不是所有反转或人物弧的公式。

## 3. 学习作用，不只更换人名和道具

把录音改成录像、椅响改成咳嗽，再照样撤掉剪辑、修改片名，仍沿用了参考片段的主要事件组织。要写自己的戏，先决定新人物真正面临的选择，而不是要求“按原文节奏仿写”。

下面是另一篇原创故事**《另一条起跑线》**的候选设计。它与参考片段没有共同的故事世界；这些设定是新的作者决定，不是素材分析“提取”出来的。

- 岑一只剩自己的十分钟小车练习时段，想完成一次不中断的全速练习。
- 初次来玩的陶陶想试控制器，却说“我只会停，不知道怎么往左”。她还没有完成一次左转。
- 岑一可以继续自己的训练，也可以问陶陶是否愿意用剩下的时段练一次转弯。他不能两件事都做完。
- 本例不写正式比赛规则、危险操作或奖项；只是虚构的练习时段。

两条方向都能成立，但作用不同：

| 候选 | 人物怎么做 | 成功标准与代价 |
|---|---|---|
| A：保留原目标 | 岑一继续全速练习，说明本时段不教学。 | 仍以自己的训练为目标；陶陶这一回没有获得练习机会。可以写边界或疏离，不等于坏故事。 |
| B：改变这一次的目标 | 他询问陶陶，得到愿意尝试的回答后，把剩余时间让给她；只提示，不替她操作。 | 改为让陶陶自己完成一次左转；自己的全速练习没有完成。结尾不补一个意外夺冠来抵销代价。 |

**本教程选择 B。** 它借用“重选成功标准且保留代价”的作用，但行动从编辑旧记录变成与另一个人当场协作，反馈来自对方实际操作，而不是给同一个物件换名字。变了题材也不自动等于有了自己的故事；还要看具体人物选择、事件组织与表达。

## 4. 从已选设计走到正文，而不是继续堆标签

先确认自己要 B，再请求正文。以下请求不假定项目已经存在这些文件：

```text
采用上面的《另一条起跑线》方案 B，写一个中文 500—700 字的候选场景。
人物目标：岑一开始想完成自己的全速练习，之后决定把剩余时段让陶陶尝试。
陶陶须自己同意尝试；岑一不能替她完成转弯。
转变要通过询问、交出控制器和等待呈现，不加一段“他终于懂得了”的道理。
保留代价：结束时陶陶完成一次左转，岑一的完整全速练习没有做成。
不添加比赛获奖、亲属关系或“从此成为高手”。不要复用参考片段的特色句子。
先在回复中给候选正文，不写入文件，不更新项目记忆。
```

“只在回复中给候选”是工作要求，不是强制只读权限。文件操作的边界见 [AI 创作助手](../user-guide/ai-assistant.md)。如果希望直接入稿，先指定目标文件与允许修改的范围，避免让“分析素材”悄悄变成“改写现稿”。

下面只示范一个**原创收尾片段**，不是上述字数要求的完整输出：

> 陶陶的拇指停在键上。“你帮我按？”
>
> 岑一把伸到一半的手收回去。“还是你来。先慢一点。”
>
> 小车碰了一下边线，退开，再向左转过去。练习时段结束的提示音响了。岑一看了一眼自己还没跑过的整圈，把控制器留在陶陶手里：“刚才那一下，是你转的。”

这段用“伸手又收回”表现岑一没有代做，用提示音与未跑的一圈保留损失。它不证明陶陶已掌握全部操作，也不替读者宣布岑一从此改变。若完整正文前面没有写清原目标、陶陶愿意尝试以及时段限制，这个结尾单独出现仍缺少支撑。

## 5. 看节奏，看的是选择怎样发生

参考片段里，重复播放、听到一句话、撤销拼接、改节目单的作用不同。若删掉母亲的话，决定会少一个支点；若一开头就解释“方遥早已不在意完美”，后面的变化会变弱。分析这种前后关系，比把它统计成“两段动作、一段对话”更能帮助本次写作。

小车场景需要给陶陶尝试、岑一忍住代做留出篇幅；不必照抄参考片段的段数、句长或停顿位置。也没有“每5—10章必须中冲突、每20—30章必须大高潮”的通用安排。长篇、短篇和不同类型的叙事，仍要按各自问题与读者已知的信息作取舍。

## 6. 把参考笔记与作品事实分开保存

如果要留档，可以自行创建以下文件；这些是建议名称，不是系统自动生成的分析卡片或特殊命令：

- **《参考阅读——目标的改变》**：记录素材名、原文位置、短引文、解读与尚未读到的范围。
- **《另一条起跑线——场景提纲》**：只写自己已接受的设计，包括人物同意、选择和仍然存在的代价。
- **《第1场 练习时段》**：只放实际选用的正文。候选尚未入稿，就不要在项目记忆里写“第1场已完成”。

素材库展示结果不等于可直接编辑或导出分析卡片；自己的阅读笔记也不是素材原文的替代品。下次引用时，附加需要的条目或短引文，并说明要解决哪个问题；不要假定全库、全本或上次分析已自动进入每轮聊天。

继续写作可接[决策到正文的工作流程](workflow-tips.md)，接续状态见[项目记忆填写示例](ai-memory.md)。需要把已有手稿恢复为续写项目，而不是把它当参考阅读时，可另看 [Oh Story 导入与续写](https://zenstory.ai/oh-story/import-and-continue)；那是另一个项目的工作流，不是素材上传按钮的同义词。
