第十三批已完成 [30 项编辑工作](2026-09-30-quality-batch-13.csv)：3 篇新增、18 篇实质修订、9 篇来源与模板修正。新增悲伤场景的投入、告别与反应；内心戏限制痕迹能支持的结论，误会补实际撤下与延期，喜剧补字面规则的持续与解除，去 AI 味保留作者选择和叙事功能，动作重复检查表保留真实先后。另修单集结构、分集大纲、付费卡点、第一集、改编价值和分镜六篇：案例补明知情、保管、实际取回与回复，分镜保留完整四镜但撤下统一秒数保证，开篇比较加入明确冷开，分析限于已读范围。新增横竖屏混剪，区分实际显示方向、交付画幅与等比留边/裁切，自动中间画幅不冒充叙事裁切；修游戏反馈的先选路后执行，菜园故事缩到实际幼苗与受损箱。玩法三案、自由输入、剪辑节奏与调研保留已有主体，整理来源和两列表。新增封面裁字，给出原图到上传版的尺寸演算；封面教程从大纲移入新的小说封面分类。卡点改用可核对的周年展板证据交接并补付费首段；题材选择、盐言和双男主补实际查证、交付及知情范围。流派循环、隐藏实力与封面提示保留主体并补精确方法。最后三项题材修订，末世与日常作实质修订，娱乐圈保留试镜主体计来源/模板修正；收益、恢复和温馨体验不强加每章代价或晋升配额。目录 298 篇，全批经 PR #101 统一合并并上线；CI 与 CodeQL 均首次通过，无重跑。

文章面向作者与内容创作者。题目用他们实际会问的话：怎么写开头、怎么做大纲、对白为什么生硬、AI 视频角色怎么保持一致。优先解决常见任务和明确问题，不为数量扩展到 skill 没有方法的领域，不把内部字段、流程标签和新造的词当选题。

一篇合格文章要能让读者开始做：开头直接回答问题；正文提供有取舍的具体方法；有按本题填写的模板、原创场景或改前改后对照；写清常见失败怎样修；链接到确实存在的 skill 与相关方法文件。案例不冒充真实用户成绩，方法的数字默认值不写成所有题材的硬规则。

补充前检查已有目录、[首轮逐篇修订记录](2026-09-29-guide-review.csv)和[第二批质量记录](2026-09-29-quality-batch-02.csv)、[第三批质量记录](2026-09-29-quality-batch-03.csv)、[第四批质量记录](2026-09-29-quality-batch-04.csv)、[第五批质量记录](2026-09-29-quality-batch-05.csv)、[第六批质量记录](2026-09-29-quality-batch-06.csv)、[第七批质量记录](2026-09-29-quality-batch-07.csv)、[第八批质量记录](2026-09-29-quality-batch-08.csv)、[第九批质量记录](2026-09-29-quality-batch-09.csv)、[第十批质量记录](2026-09-30-quality-batch-10.csv)和[第十一批质量记录](2026-09-30-quality-batch-11.csv)。首轮记录保留当时的处置事实；后续恢复与同题合并以批次记录和当前目录为准。同一问题的不同说法合并到主文章；新文章必须有新的读者问题和实际方法。不要用“题材 × 技法”排列组合批量扩写，也不要把三个通用段落当完整教程。站内来源与方法不能用泛用项目说明替代。

`skill.url` 指向固定提交的真实 `SKILL.md` 文件。不同仓库的目录结构不同，DSH 的打包技能在 `packages/knowledge/.../skills/`。`sources[]` 提供正文所用的具体方法文件；实际方法只存在于技能 Python 脚本时，可以引用固定提交的 `skills/.../scripts/*.py`，但须读过实现并核验路径，不能虚构同名参考文档。提交前对所引用提交运行 `git cat-file -e COMMIT:PATH`；链接校验是来源存在性检查，文章的方法是否对应来源仍需编辑判断。

文章在十个常用任务分类中只选一个主类，使用 `topic` 字段。首页展示精选，`/guides` 提供学习路径与搜索，分类页每页 24 篇。文章量增长时增加分页，不增加首页列表长度。更新目录运行 `node apps/web/scripts/update-guide-directory.mjs`。

同题合并记录在 `guide-redirects.json`，生成中英文永久重定向；撤下的非同题文章不跳到无关页面。修改映射后运行 `node apps/web/scripts/build-site-layout.mjs --write-config`。

验证运行 `cd apps/web && npm run test:site && npm run build:vercel`。涉及布局或搜索时，检查 390px 溢出、键盘搜索、无脚本分类分页和 axe。测试与可访问来源不替代作者视角的内容审读。
