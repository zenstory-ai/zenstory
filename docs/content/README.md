# 创作指南编辑规则

目标是 2000 篇独立、可用的创作文章。`guides.json` 和 `articles.json` 中的一条内容算一篇；中英文版本不重复计数。当前已合并上线目录为 353 篇（首轮修订 170 篇，后续新增或重写恢复 183 篇）。第十二批完整30项经PR #100合并，PR的CI与CodeQL均首次运行成功、无重跑，60个线上双语页面与已核验构建一致。第十一批完整 30 项（13 篇新增、2 篇重写恢复、12 篇实质修订、3 篇来源与模板修正）经 PR #99 合并；CI 与 CodeQL 均首次运行成功，无重跑，60 个线上双语页面与已核验构建一致。后续继续累计较大批次再统一提交。第十批累计 30 项统一提交（6 篇新增、2 篇重写恢复、20 篇实质修订、2 篇来源与模板修正）。第九批累计 30 项编辑工作后统一提交：4 篇新增、1 篇重写恢复、21 篇实质修订、4 篇来源与模板修正。来源修正不冒充完整重写，旧稿修订不重复计入新增数量。第八批 20 篇已统一 PR、CI 和合并；后续按用户要求积累较大批次再提交，30 项只作本地检查点，继续积累更大批次再统一 PR 和合并，不在到达检查点时自动发布。本地检查随需要运行，不为三五篇内容单独触发 CI。

第十九批（2026-10-10）新增 [6 篇教程](2026-10-10-quality-batch-19.csv)，补齐此前没有文章的 skill：长篇扫榜（单本只当线索、重复样本才写观察，分观察/线索/假设/验证）、短篇选题（无采集脚本时手动抄榜，样本少时可行性不给“高”）、短篇拆文（导语、情绪线、反转与铺垫回看，只迁移机制）、小说改游戏的原著设定集（带原文位置的规则与玩家动作，四种改编边界）、解说前看懂素材（场景、转写、逐场观察与融合时间线，回原片核对模型补出的动作），以及参考解说片的节奏测量（量化对照，不带走画面、旁白与段落）。每篇依据固定提交的 skill 文件，配完整原创例，表格标明为手写简表；视频理解为内部阶段，指令改由 `$video-recap` 运行到简报暂停点。扫榜术语的“怎么做”链到新文章。目录 430 → 436 篇。

第十二批完成 [30 项编辑工作](2026-09-30-quality-batch-12.csv)：9 篇新增、12 篇实质修订、9 篇来源与模板口径修正，净增 9 篇，生成目录 295 篇。新增解决确认关系后的续写、亲情和解、AI 视频负面提示词、多人表演、无旁白交付、互动角色提前知道秘密、二周目设计、一镜到底和空镜提示词；旧稿修订选择、取证、行动与后果，并校正具体方法来源及可选模板口径。完整批次经 [PR #100](https://github.com/zenstory-ai/zenstory/pull/100) 合并并上线；当前继续本地积累下一批，不为发布状态文档单独推送或触发CI。

第十三批已完成 [30 项编辑工作](2026-09-30-quality-batch-13.csv)：3 篇新增、18 篇实质修订、9 篇来源与模板修正。新增悲伤场景的投入、告别与反应；内心戏限制痕迹能支持的结论，误会补实际撤下与延期，喜剧补字面规则的持续与解除，去 AI 味保留作者选择和叙事功能，动作重复检查表保留真实先后。另修单集结构、分集大纲、付费卡点、第一集、改编价值和分镜六篇：案例补明知情、保管、实际取回与回复，分镜保留完整四镜但撤下统一秒数保证，开篇比较加入明确冷开，分析限于已读范围。新增横竖屏混剪，区分实际显示方向、交付画幅与等比留边/裁切，自动中间画幅不冒充叙事裁切；修游戏反馈的先选路后执行，菜园故事缩到实际幼苗与受损箱。玩法三案、自由输入、剪辑节奏与调研保留已有主体，整理来源和两列表。新增封面裁字，给出原图到上传版的尺寸演算；封面教程从大纲移入新的小说封面分类。卡点改用可核对的周年展板证据交接并补付费首段；题材选择、盐言和双男主补实际查证、交付及知情范围。流派循环、隐藏实力与封面提示保留主体并补精确方法。最后三项题材修订，末世与日常作实质修订，娱乐圈保留试镜主体计来源/模板修正；收益、恢复和温馨体验不强加每章代价或晋升配额。目录 298 篇，全批经 PR #101 统一合并并上线；CI 与 CodeQL 均首次通过，无重跑。
