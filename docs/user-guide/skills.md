# 技能系统

技能系统是 ZenStory 写作工作台的核心功能：把一套写作方法（人物设计、大纲结构、场景描写等）预先写成指令，交给 AI 在合适的时候使用。

## 什么是技能？

技能由「名称 + 描述 + 指令内容」组成。启用一个技能后，AI 在对话开始时只会看到它的名称和描述（相当于一份目录）；当你的请求确实需要用到某个技能时，AI 会自己去读取它完整的指令内容再执行，不需要你说出固定的口令来"激活"它。

因为 AI 是靠描述来判断"这个技能是否用得上"，**描述写得越清楚，AI 找到并正确使用技能的概率就越高**。

**核心优势**：
- 把复杂指令沉淀成技能，不用每次重新描述
- 确保 AI 输出风格的一致性
- 可根据个人习惯定制专属技能
- 发现和使用社区分享的优质技能
- 需要时也可以手动指定这次对话用哪个技能，结果更可控

## 发现技能

[截图: 发现技能页面，展示技能卡片网格、分类筛选和搜索框]

在「发现技能」页面浏览和添加来自官方和社区的优质技能：

**功能操作**：
- **搜索**：输入关键词快速找到所需技能
- **分类筛选**：点击分类标签（写作、角色、世界观、情节、文风）筛选
- **添加技能**：点击「添加到我的技能」将技能加入个人库
- **展开查看**：点击展开按钮查看完整指令内容

**技能来源**：
| 来源 | 说明 |
|------|------|
| 官方 | ZenStory团队精心打造，经过充分测试优化 |
| 社区 | 用户创建并分享，经审核后发布 |

## 我的技能

[截图: 我的技能页面，分为「自定义技能」和「已添加技能」两个区域]

管理所有个人技能，分为两类：

| 类型 | 说明 | 权限 |
|------|------|------|
| 自定义技能 | 亲手创建的技能 | 可编辑、删除、分享 |
| 已添加技能 | 从公共库添加的技能 | 只读，可移除 |

**管理功能**：
- 搜索：按名称或描述快速定位技能
- 批量操作：勾选多个技能后批量删除
- 导入：点击顶部「导入」，选择 `.zip` 技能包或单个 `SKILL.md` 文件（不超过 1 MB）
- 导出：点击技能卡片上的下载图标，导出为 `.zip` 技能包

## 创建自定义技能

[截图: 创建技能表单，包含名称、描述、触发词、指令内容四个输入字段]

### 基本信息

- **技能名称**（必填）：简洁明了的名字
- **描述**（选填）：说明用途和使用场景——**这是 AI 判断"什么时候该用这个技能"的主要依据，请认真填写**

**描述写作建议**：
- 说清楚"适用场景"而不是复述技能名称，例如"当用户需要为反派角色设计合理动机时使用"，而不是"角色设计技能"
- 包含用户可能提到的关键词或同义说法，帮助 AI 在语义上对上号
- 避免空泛的描述（如"很有用的写作技能"），越具体，AI 匹配得越准

### 触发词设置

[截图: 触发词输入框]

触发词是一个辅助标签字段，用于你自己整理和检索技能，**不会用来自动激活技能**——AI 是否使用某个技能，由它的名称和描述决定。设置要点：
- 多个触发词用英文逗号分隔
- 可以填几个能概括技能用途的关键词，方便日后搜索
- 不必追求覆盖所有可能的说法

**示例**：`创建角色, 新建人物, 角色卡`

### 指令内容

[截图: 指令编辑器]

AI 需要用到该技能时会读取的完整方法，支持 Markdown 格式。

**编写建议**：
- 明确 AI 的角色和任务
- 提供输出格式要求
- 使用 Markdown 结构化内容

**示例指令**：

```markdown
# 角色创建专家

你是一位专业的小说角色设计顾问。请按以下格式生成角色设定：

## 基础信息
- 姓名、年龄、性别、身份

## 外貌特征
详细描述角色的外貌特点。

## 性格特点
- 核心性格、行为习惯、语言风格

## 背景故事
简要描述成长经历和重要事件。

请确保角色设定与故事风格保持一致。
```

### 资源文件

[截图: 技能编辑弹窗中的资源文件区域]

先保存技能后，才能为它添加资源文件——供 AI 按需查阅的文本参考资料（如术语表、参考大纲、写作规范），AI 只有在需要时才会读取，不会占用每轮对话的篇幅。

**规则**：
- 路径必须以 `references/` 或 `assets/` 开头，例如 `references/glossary.md`
- 仅支持文本格式：`.md` `.txt` `.json` `.yaml` `.yml` `.csv`
- 单个文件不超过 64 KB，一个技能最多 20 个文件，全部文件合计不超过 256 KB
- 从公共库添加的技能，其资源文件为只读，仅可查看

## 编辑与删除技能

**编辑**：点击自定义技能卡片上的编辑图标修改内容。已添加的公共技能为只读，无法编辑。

**删除**：点击删除图标，确认后永久删除。支持批量删除多个技能。

**注意**：删除操作无法撤销，请谨慎操作。

## 在对话中手动指定技能

大多数时候不需要手动干预，AI 会自己判断是否需要用到某个技能。但如果你想让 AI 明确使用某个技能，可以在发送消息前手动选择，最多同时选择 3 个：

- 在左侧栏「技能」标签页或技能详情弹窗中，点击技能旁的 **+** 按钮
- 或在聊天输入框中输入 `/` 打开技能快捷菜单，用上下键选择、回车确认

选中的技能会以标签形式显示在输入框上方，消息发送后自动清空，下一条消息需要重新选择。

[截图: 聊天输入框上方显示已选技能标签]

## 技能的开放格式

ZenStory 的技能遵循开放的 Agent Skills 格式（`SKILL.md`），因此：

- **导入**：可以导入符合该格式的 `.zip` 技能包或单个 `.md` 文件（最大 1 MB）。导入时会自动忽略技能包中的可执行脚本和非文本文件，并在结果中列出被跳过的文件——**ZenStory 不会执行技能携带的任何脚本**。
- **导出**：可以把自己的技能导出为 `.zip` 包，用在其他支持 Agent Skills 格式的工具中（例如 Claude Code）。

## 分享技能

[截图: 分享技能弹窗，包含分类选择]

创建有价值的技能后可分享到公共库：

1. 点击分享图标
2. 选择分类（写作、角色、世界观、情节、文风）
3. 提交分享

分享的技能会提交管理员审核，通过后出现在公共库中。

## 技能使用统计

[截图: 技能统计弹窗]

点击「使用统计」查看当前项目的技能使用情况。统计的是 AI 实际加载某个技能完整指令的次数（包括你手动选择使用的次数），而不是简单的关键词命中。

**统计指标**：
- 总使用次数
- 内置技能 vs 自定义技能的使用次数

**时间范围**：7天 / 30天 / 90天

**可视化**：
- 最常用技能排行（Top 5）
- 每日使用趋势柱状图

## 使用技巧

**描述编写**（最重要）：
- 用一两句话说清楚"什么情况下用它"，而不是"它是什么"
- 覆盖用户常见的提问方式和关键词
- 定期回顾使用统计，根据实际使用情况调整描述

**触发词**：
- 作为个人检索用的标签，不影响 AI 是否使用该技能
- 每个技能 2-5 个即可，方便自己搜索定位

**指令编写**：
- 使用 Markdown 结构化组织
- 包含期望的输出示例
- 根据 AI 输出持续优化

**技能管理**：
- 定期清理不再使用的技能
- 使用统一的命名规范
- 有价值的技能及时分享
