# 素材库：上传、查看与引用参考文本

> 仓库文档快照（2026-09-13）。[当前官网指南](https://zenstory.ai/docs/user-guide/materials)以网页工作台文档为准；本页正文复用[此版本的官网内容源](https://github.com/zenstory-ai/zenstory/blob/1773af4781996363496f47268cce0e7c640108c8/apps/web/docs/user-guide/materials.md)，保留可在仓库中直接阅读的说明与示例。此日期只说明本页所用版本，不表示其他仓库文档已同步。

ZenStory 的素材库把参考小说拆成可浏览的章节、人物、剧情、世界观等结果，帮助作者定位想读的内容。它与作品的正文文件不同：**上传参考材料，不等于导入一份可继续写作的项目，也不等于每轮 AI 对话都已读取整本材料。**

要学习怎样从原文走到自己的故事，可直接看[素材分析原创示例](../advanced/material-analysis.md)。本页说明实际使用路径，不承诺分析速度、完整性或成稿质量。

## 1. 准备并上传 TXT

在工作台打开素材库，使用上传入口选择文件，核对标题后提交。只上传自己有权使用的文本，并独立保留原文件。

| 限制 | 当前实现 |
|---|---|
| 文件格式 | `.txt`；此入口不直接接收 PDF、Word 或 EPUB。 |
| 文件大小 | 不超过 100MB（实现为 100 × 1024 × 1024 字节）。 |
| 文本长度 | 解码后的文本不超过 300,000 个字符；与文件大小同时检查，不是 30 万英文单词。 |
| 使用条件 | 需要登录，并受素材功能权限与分解额度约束；以当前账户界面与返回提示为准。 |

保留清楚的章节标题与顺序。如果超限而只选择部分章节，要标明这份材料的范围，不能把分段所得分析称作整本已读。不要为了凑文件大小删掉会改变人物选择的关键上下文。

## 2. 区分上传成功与分析完成

上传提交成功后，后端创建异步分解任务。`pending` 表示等待处理，不是已经得到全部结果；`processing` 表示仍在进行。本页不给“多少万字几分钟”的固定时长表。

任务状态还包括 `completed`、`completed_with_errors` 与 `failed`。这是实现中的状态名，不保证每个界面逐字显示同样标签。完成时间本身不能证明每章、每个分类均已完整且正确地分析。查看当前状态、错误说明及实际结果，再决定能用哪些内容。

失败卡片提供重试入口时，可以重新提交任务；重试会创建新的分解任务，不是保证从上次精确断点续跑，也不保证免额度。运行中的任务不能重复重试。先看错误信息，不要把删除原材料、反复重传当作默认修复步骤。

## 3. 打开分类，回到具体原文

进入素材详情，展开需要的分类，再选择条目查看。分类内容按需加载；刚打开页面或尚未展开时，不能把未加载误判为不存在。

| 结果类型 | 查看重点 |
|---|---|
| 章节 | 摘要、情节点与可用原文；核对关键动作有没有被概括掉。 |
| 人物 | 名称、别名、描述等；把性格解读对应到实际行为。 |
| 剧情、故事、故事线 | 描述、类型与关联章节；按需要补读前后文。 |
| 世界观与特殊能力 | 可用的体系、结构、势力或能力演化信息；关注限制如何影响选择，而不只是标签。 |

这些是展示能力，不是所有材料都具备所有结果的承诺。关系、时间线等分类也不意味着完整交互图谱。结构化描述可能遗漏或误读；“分析没有列出某条规则”不等于“原文没有这条规则”。

本页不把结果浏览器描述为可直接编辑、批量导出分析卡片的工具。想保存自己的解读，可以另建阅读笔记，标明素材、原文位置和推断；不要把笔记改动说成已修复素材库分析。

## 4. 在聊天中附加必要条目

在项目的 AI 对话里使用素材附加入口选择相关条目，确认已附加；必要时再提供短引文。素材附件和文本引用会参与上下文组装，但还有预算与选择范围，不是全库自动注入。

一个范围清楚的请求是：

```text
参考已附加条目，并只分析下面引用的原文片段。
我想学习人物为什么改变行动：区分原文明示、你的解读和需要补读的部分。
暂不生成我的故事，不修改项目文件。若条目不足以支持判断，请指出缺哪段依据。
[在这里放入原文片段与章节位置]
```

“只分析”是任务范围，不是强制只读权限。具体上下文与文件写入边界见 [AI 创作助手](ai-assistant.md)。不要只写一个素材名字，就假定模型已读完它；实际使用了哪些片段比附加了多少本更重要。

## 5. 让阅读变成一次创作决定

接下来不必继续收集更多标签。[素材深度分析](../advanced/material-analysis.md)用一段原创录音场景展示：从短引文找人物改变目标的依据，再设计一个不同的小车练习场景，保留新选择的代价。

先选择要借鉴的作用，再决定自己的角色、行动与结果。把参考笔记与已接受的作品提纲分开；正文真正入稿后，再按[项目记忆示例](../advanced/ai-memory.md)记录进度。
