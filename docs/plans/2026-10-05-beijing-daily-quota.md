# 北京时间每日权益与月度配额审计

## 目标与边界

- 每日 AI 对话额度按 `Asia/Shanghai` 自然日计算，00:00 恢复；数据库仍存 UTC。
- 注册、首次使用和多日未访问后的下一次访问，都归入当前北京时间自然日，不再形成滚动 24 小时窗口。
- 旧窗口在下一次访问时校正：同一自然日保留已用次数，上一自然日的计数清零。无需数据库迁移或定时任务。
- 素材上传、素材拆解等月度额度按北京时间每月 1 日 00:00 恢复；长期未访问一次跳转到当前月份，避免逐月补重置。
- 同月旧 UTC 窗口保留用量后校正边界；并发重置不能抹去新月消费；旧月失败任务不得退还新月用量。
- 扣费操作原子返回实际消费周期，素材任务保存到现有 billing JSON；对话和素材退款匹配此周期，不能用任务创建/完成时间代替。
- 不改套餐额度、会员有效期或支付逻辑；购买及续费不清零月度计数。
- 扩展审计所有日权益：每日签到、连续签到、签到积分与管理后台今日签到；`/suggest` 独立每日限流也统一北京零点，小时/分钟风控保持原规则。
- 套餐对比展示真实每日对话额度，不再从每日额度编造月度任务次数/字数。付费计划缺失旧字段时，检查、扣费、快照与管理员详情采用同一套餐默认值。

## 权益/额度周期清单

| 权益/额度 | 真实周期/规则 | 处理 |
| --- | --- | --- |
| AI 对话、润色 | 北京自然日 | 日边界修正、并发重置及实际扣费周期退款 |
| 自动建议独立上限 | 北京自然日 | 从滚动 86400 秒改日期桶；Redis/内存一致 |
| 每日签到/连续签到/当日积分 | 北京自然日 | UTC 日期修正，兼容旧日记录避免同日重复领取 |
| 素材上传/拆解、灵感复用 | 北京自然月 | 月初零点，多月未访问跳至当前月；退款匹配扣费月 |
| 项目/自定义技能/每文件版本 | 当前拥有数量上限，非周期额度 | 保持现有规则，不按天/月清零 |
| 会员月付/年付 | 购买/续费起算 30/365 天有效期 | 保持独立有效期，不改为自然月 |
| 请求小时/分钟限流、邀请反重复风控 | 短窗口风控，非每日权益 | 保持原规则 |
| 套餐月度字数/Agent 任务投影 | 未作为运行时额度执行 | 移除广告展示，替换为真实每日 AI 对话额度；不新增限制 |
| 写作字数/趋势/使用统计 | 分析统计，非权益额度 | 本次不改变统计口径 |

## 实施与验证

1. 先添加确定性回归测试，覆盖北京零点前后、UTC 零点、月/年边界、长期未访问、旧窗口和 naive UTC 时间。
2. 统一创建及重置的自然日边界；以条件更新避免并发重复重置覆盖新一天的用量。
3. 添加月初、跨年、闰年、跨多月和并发的回归测试；按当前北京时间月份重置月度额度，退款校验任务所属月份。
   - 审查发现任务创建与扣费可能跨月，对话失败也可能跨日；补上实际消费周期守卫及上传/重试预调度退款的边界测试。
4. 订阅页添加中英文每日/每月零点重置说明，修正 README 的滚动窗口描述。
5. 验证配额服务、订阅 API、会员服务以及订阅页测试，再运行后端静态检查、前端 lint/typecheck/build。

## 完成标准

- 北京时间 00:00 前保留当天用量，00:00 起恢复额度；返回的 `reset_at` 是下一个北京零点，带 UTC 时区。
- 同日旧记录保留用量，并发第二次重置不清除新日消费。
- 每月 1 日北京零点后月度额度恢复，无过期 `reset_at` 或跨月误退款。
- 会员到期时间不受影响，未跨日/月的用量保留；原工作目录的未提交文件不变。
